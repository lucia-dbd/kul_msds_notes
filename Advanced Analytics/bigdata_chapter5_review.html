1. Unsupervised Learning – Overview

Core idea: No labels or target variable. The goal is to describe, discover, and explain patterns in data without any pre-defined output. Unlike supervised learning, we do not correlate features to a target — but we still need to define what kind of patterns we are looking for.

Contrast with Supervised Learning

AspectSupervisedUnsupervised
Labels required?YesNo
Primary goalPredictive (future outcomes)Descriptive / Exploratory
EvaluationAccuracy, AUC, RMSE vs. labelInternal indices, visual inspection, domain judgment
Common outputsClass predictions, probabilities, valuesCluster memberships, rules, projections, anomaly scores

Main Techniques Covered

  • Clustering — hierarchical, k-means, DBSCAN, EM/GMM, mean-shift
  • Dimensionality reduction — PCA, t-SNE, UMAP
  • Anomaly detection — statistical, clustering-based, isolation forest, LOF, (V)AE, CADE
  • Association rules — Apriori algorithm, support, confidence, lift
⚠ Unsupervised results can serve as input to supervised pipelines: cluster labels and distances used as features, or anomaly scores used as a risk signal.

2. Hierarchical Clustering

Builds a tree of nested partitions (a dendrogram). Two variants: agglomerative (bottom-up — start with singletons, iteratively merge) and divisive (top-down — start with all data, iteratively split). In practice only agglomerative is implemented: divisive is computationally far more expensive.

The dendrogram can be cut at any height to produce any desired number of clusters, and also reveals potential outliers as long isolated branches.

Distance Metrics (between two points \(a\) and \(b\))

Euclidean: \(\|a-b\|_2 = \sqrt{\sum_i (a_i - b_i)^2}\)     Manhattan: \(\|a-b\|_1 = \sum_i |a_i - b_i|\)

Maximum: \(\|a-b\|_\infty = \max_i |a_i - b_i|\)     Squared Euclidean: \(\|a-b\|_2^2 = \sum_i (a_i - b_i)^2\)

A valid metric must satisfy: symmetry \(d(a,b)=d(b,a)\), self-similarity \(d(a,a)=0\), positivity \(d(a,b)\ge 0\), and the triangular inequality \(d(a,b)\le d(a,c)+d(c,b)\).

Linkage Criteria (between two clusters \(A\) and \(B\))

LinkageFormulaResulting cluster shape
Single (minimum)\(D(A,B)=\min_{a\in A,b\in B} d(a,b)\)Long, skinny — prone to chaining
Complete (maximum)\(D(A,B)=\max_{a\in A,b\in B} d(a,b)\)Tight, compact, roughly equal diameter
Average (UPGMA)\(D(A,B)=\frac{1}{|A||B|}\sum_{a\in A,b\in B}d(a,b)\)Balanced; robust to noise — recommended default
Centroid\(D(A,B)=d(a_c, b_c)\)Robust; needs a centroid concept
Ward's\(D(A,B)=SSE(AB)-(SSE(A)+SSE(B))\)Minimises within-cluster variance; similar to k-means
Ward's linkage measures the increase in total within-cluster SSE caused by a merge — analogous to ANOVA. It tends to produce compact spherical clusters and is closely related to the k-means objective.

Properties & Practical Notes

AdvantageDisadvantage
No need to pre-specify \(k\)Not very scalable (\(O(n^2)\) to \(O(n^3)\))

⚠ Always normalise features before hierarchical clustering — distance measures are scale-sensitive.

3. Partitional Clustering & Other Methods

3.1 K-Means

Places each instance in exactly one of \(k\) clusters. Objective: minimise total SSE.
\(\min\; SSE = \sum_{k=1}^{K}\sum_{i=1}^{n_k}\|x_{ki} - \mu_k\|^2\)

Algorithm: (1) Choose \(k\). (2) Initialise \(k\) centroids. (3) Assign each point to nearest centroid. (4) Recompute centroids. (5) Repeat 3–4 until convergence.

⚠ Weaknesses: requires the mean to be defined (numeric features only); sensitive to outliers; prone to local optima; cannot handle non-convex shapes; \(k\) must be specified in advance; requires feature normalisation.
Elbow method: plot SSE vs \(k\). The "elbow" (point of diminishing returns) suggests a suitable \(k\). Python: kneed package. Practical tip: start with a higher \(k\) than intuition suggests and post-process — human intuition about the number of segments is often too low.

3.2 K-Means++ Initialisation

Selects initial centroids with probability proportional to \(d(x,c)^2\) (squared distance to the nearest already-chosen centroid). This spreads centroids out, reducing the risk of poor local optima. Most k-means implementations use K-means++ by default.

3.3 DBSCAN

Density-Based Spatial Clustering of Applications with Noise. Groups closely packed points; marks sparse outliers as noise. Does not require \(k\); handles non-convex shapes; hierarchical versions (HDBSCAN) exist.
Point typeDefinition
CoreHas ≥ MinPts neighbours within radius \(\varepsilon\)
BorderFewer than MinPts neighbours within \(\varepsilon\) but density-reachable from a core point
NoiseNot reachable from any core point — treated as outlier

3.4 EM-Based Clustering (Gaussian Mixture Models)

Makes soft (probabilistic) assignments via alternating E-step (compute cluster membership probabilities) and M-step (re-estimate Gaussian parameters). More flexible than k-means but still requires specifying \(k\) and struggles with non-convex shapes.

E-step: \(r_{ik} = P(\text{cluster}=k \mid x_i)\)     M-step: update \(\mu_k,\, \Sigma_k,\, \pi_k\) using weighted responsibilities \(r_{ik}\)

3.5 Mean-Shift Clustering

Based on Kernel Density Estimation (KDE). Places a kernel (typically Gaussian) on each data point; clusters emerge around density peaks. Does not require \(k\); the bandwidth parameter controls the number of clusters found.

4. Cluster Validation & Domain Knowledge

Internal Validation Indices

A good clustering has high intra-cluster similarity and low inter-cluster similarity. Internal indices quantify this without reference to external labels.
Davies-Bouldin Index: \(\displaystyle DBI = \frac{1}{N}\sum_{i=1}^{N} R_i \quad\text{where}\quad R_i = \max_{j\neq i}\frac{S_i + S_j}{D_{ij}}\)

\(S_i\) = mean intra-cluster distance for cluster \(i\)    \(D_{ij}\) = distance between centroids of \(i\) and \(j\)

Lower DBI = better clustering.

Other measures: Silhouette coefficient, Calinski-Harabasz index, k-means SSE. Given the descriptive nature of clustering, validation is inherently somewhat subjective.

Incorporating Domain Knowledge

  • Must-link constraints: two points must be in the same cluster.
  • Can't-link constraints: two points must be in different clusters.
  • Warm start: provide a partial clustering solution as initialisation.
⚠ Too many constraints can make the problem infeasible. Constraints should reflect genuine domain knowledge, not arbitrary preferences.

Distance Metrics for Non-Numeric Data

Most metrics above apply to numerical features. For text and categorical data: Levenshtein distance (edit distance based on insertions, deletions, substitutions), Jaccard similarity, cosine similarity, and Gower distance (mixed numerical/categorical).

5. Dimensionality Reduction

5.1 PCA — Principal Component Analysis

Linear technique. Finds orthogonal directions of maximum variance via eigenvector decomposition of the covariance matrix. Each eigenvalue \(\lambda_j\) represents the variance explained by that component. PCs are uncorrelated by construction.
\(PC_j = e_j^\top X = e_{j1}X_1 + e_{j2}X_2 + \cdots + e_{jp}X_p\)

Eigenvalue \(\lambda_j\) = variance explained by \(PC_j\)
AdvantageDisadvantage
Powerful data reduction — removes multicollinearityLinear only — misses non-linear structure
Components are uncorrelatedComponents are hard to interpret
Parametric — new points can be projectedSensitive to feature scale (normalise first)

5.2 t-SNE — t-Distributed Stochastic Neighbor Embedding

Non-linear, manifold-based. Preserves local structure (small pairwise distances). Main hyperparameter: perplexity (effective neighbourhood size, typical range 5–50). Output is usually 2D or 3D.

Step 1 — High-dimensional similarities:

\(p_{j|i} = \dfrac{\exp(-\|x_i - x_j\|^2 / 2\sigma_i^2)}{\sum_{k\neq i}\exp(-\|x_i - x_k\|^2 / 2\sigma_i^2)}\)     \(p_{ij} = \dfrac{p_{j|i} + p_{i|j}}{2N}\)

\(\sigma_i\) is set per-point so that the perplexity of \(p_{\cdot|i}\) equals the user-specified value.

Step 2 — Low-dimensional similarities use the Student-t distribution (heavier tails than Gaussian — reduces the crowding problem):

\(q_{ij} \propto \left(1 + \|y_i - y_j\|^2\right)^{-1}\)

Minimise \(\displaystyle KL(P\|Q) = \sum_{i\neq j} p_{ij}\log\frac{p_{ij}}{q_{ij}}\) via gradient descent.
⚠ t-SNE pitfalls: (1) Cluster size in the 2D plot has no meaning. (2) Distance between clusters has no meaning (only local topology is preserved). (3) Random data can appear structured. (4) Non-parametric — cannot embed unseen test points without retraining. (5) Different perplexity values give very different layouts — always try multiple.
t-SNE is not a clustering algorithm. A second step (e.g. k-means on the 2D output) is needed to assign cluster labels — but clustering in the original high-dimensional space is preferable; t-SNE output should only be used for visualisation.

5.3 UMAP — Uniform Manifold Approximation and Projection

Non-linear, manifold-based, parametric by default. Generally better global structure preservation than t-SNE, scales better computationally, supports output dimensions >3, and can incorporate supervised labels in the embedding.

6. Anomaly Detection

Identification of instances that do not conform to expected patterns. Also called outlier detection or novelty detection. Uses a mix of unsupervised, supervised, and statistical techniques. Applications: fraud, structural defects, medical problems, data errors.

Isolation Forest

Based on random forests but splits are chosen completely at random (not entropy-driven). Anomalies require fewer splits to isolate (shorter average path length from root to leaf). Normal points are embedded deep in the data and need many splits to separate.

Local Outlier Factor (LOF)

\(\text{LOF}_k(x) = \dfrac{\text{mean local reachability density of }k\text{-NN}(x)}{\text{local reachability density of }x}\)

\(\text{LOF} \gg 1\) → point has substantially lower density than its neighbours → outlier.

CADE

Classifier-Adjusted Density Estimation: (1) label original instances \(y=0\), generate uniform synthetic data \(y=1\). (2) Train any classifier. (3) Instances where the model predicts high \(\hat{P}(y=1)\) are flagged as outliers. Works with any classifier that produces probabilities.

7. Association Rules

Discovers interesting co-occurrence relations in transactional data. Pioneer: Apriori algorithm (Agrawal, 1993). Standard association rules do not consider order of items (sequence mining, e.g. GSP, does).

Key Measures

\(\text{Support}(X) = \dfrac{|\{t \in T : X \subseteq t\}|}{|T|}\)

\(\text{Confidence}(X \Rightarrow Y) = \dfrac{\text{Support}(X \cup Y)}{\text{Support}(X)} \approx P(Y|X)\)

\(\text{Lift}(X \Rightarrow Y) = \dfrac{\text{Support}(X \cup Y)}{\text{Support}(X) \times \text{Support}(Y)}\)

\(\text{Conviction}(X \Rightarrow Y) = \dfrac{1 - \text{Support}(Y)}{1 - \text{Confidence}(X \Rightarrow Y)}\)
MeasureInterpretationKey value
SupportHow often \(X\cup Y\) appearsHigher = more frequent
ConfidenceEstimate of \(P(Y|X)\)Higher = stronger predictor
Lift = 1X and Y are statistically independentLift > 1 = positive association
ConvictionHow often rule makes incorrect prediction by chanceHigher = less coincidental

Apriori Algorithm

Anti-monotonicity (downward-closure): If an itemset is infrequent (below minsup), all its supersets are also infrequent and can be pruned without scanning the database. Equivalently, all subsets of a frequent itemset are frequent.

Step 1 — Find all frequent itemsets using iterative join-and-prune:

  • Generate candidate \(k\)-itemsets by joining \((k\!-\!1)\)-itemsets that share \(k\!-\!2\) items.
  • Prune candidates whose any \((k\!-\!1)\)-subset was infrequent.
  • Scan database to count surviving candidates; retain those ≥ minsup.

Step 2 — Generate association rules from each frequent itemset \(I\): for all non-empty subsets \(I_s \subsetneq I\), output rule \(I_s \Rightarrow I \setminus I_s\) if its confidence ≥ minconf.

Extensions & Practical Notes

  • Categorical & continuous variables: encode each level as a binary item; bin continuous features before converting.
  • Rare patterns: set group-based support thresholds (e.g. Rolex purchases genuinely low support but meaningful).
  • Hierarchical items: allow rules at multiple levels of a taxonomy.
  • Discriminative rules: restrict the consequent (e.g. only \(\Rightarrow\{\text{default}\}\)) to inject supervision.
  • Sequence mining: GSP algorithm handles ordered item sequences.
⚠ Post-processing is essential: association rule mining often produces thousands of rules. Filter trivial rules (e.g. spaghetti → spaghetti sauce), perform sensitivity analysis on minsup / minconf, and use visualisation tools (e.g. arulesViz in R). Confidence alone is not always the best metric — check Lift and Conviction too.
