Bag of Words

Binary/count vector; one dimension per vocabulary word. Completely ignores word order, grammar and negation. Very high-dimensional and sparse. Fast, interpretable.
shared with TF-IDF: sparse, no order vs embeddings: no semantics, no dense vectors use: Naïve Bayes, SVM baselines

TF-IDF vs BM25

Shared: both score terms by local frequency × global rarity.
TF-IDF: linear TF, simple doc-length normalisation by |d|.
BM25: sublinear/saturating TF, parametric length norm via k₁ & b — generally outperforms TF-IDF in retrieval benchmarks.
both: IDF weighting, corpus-level stats BM25: saturating TF; TF-IDF: linear TF use: search ranking, BM25 still beats embeddings on some benchmarks

word2vec — CBOW vs Skip-Gram

Both learn a dense embedding table from a self-supervised context prediction task. After training, only the weight matrix W is kept.
CBOW: predict focus word from context words — faster, better for frequent words.
Skip-Gram: predict context from focus word — slower, better for rare/infrequent words, higher overall quality.
both: dense vectors, context window, no order sensitivity CBOW: input=context; Skip-Gram: input=focus optimisations: negative sampling, subsampling, random window

GloVe / fastText / doc2vec

GloVe: factorises global co-occurrence matrix — combines local (word2vec-style) and global corpus statistics.
fastText: represents words as bags of character n-grams — handles OOV and misspellings.
doc2vec: adds a document-level paragraph vector alongside CBOW — direct document representation without averaging.
all: dense vectors, transfer learning, semantic similarity fastText: subword; GloVe: global co-occur; doc2vec: doc-level

Vanilla RNN

Maintains a hidden state aₜ = tanh(Wₐₓxₜ + Wₐₐaₜ₋₁ + bₐ). Weights are shared across time steps. Trained via Backpropagation Through Time (BPTT). Key limitation: vanishing/exploding gradients — long-range dependencies are hard to learn in practice.
shared with LSTM/GRU: sequential, hidden state, weight sharing vs LSTM: no gating, no cell state — gradient vanishes O(L) inference; cannot parallelise across time

Bidirectional RNN

Two RNNs run in parallel — one forward, one backward — and their hidden states are concatenated. Allows each position to attend to both past and future context. Requires the full sequence upfront — not suitable for real-time autoregressive generation.
like Transformer encoders: full context per position vs unidirectional RNN: reads future tokens too

LSTM (Hochreiter & Schmidhuber, 1997)

Adds a cell state Cₜ (long-term memory highway) alongside the hidden state. Three gates: forget (discard old memory), input (write new info), output (expose to hidden state). The cell state gradient path avoids vanishing.
vs GRU: gated mechanism, solves vanishing gradient vs GRU: 2 states (h, C), 3 gates, more parameters, slower still strong for smaller datasets or streaming inference

GRU (Cho et al., 2014)

Simplified LSTM: merges forget + input gates into one update gate; no separate cell state — only hₜ passes between steps. Fewer parameters → faster training, better on small data.
vs LSTM: gated, solves vanishing gradient vs LSTM: 1 state, 2 gates, lighter, slightly weaker long-range recommended default over LSTM when resources are limited

Seq2Seq (Encoder–Decoder)

An LSTM encoder compresses the input into a fixed-length context vector. A decoder LSTM generates output tokens one at a time from that vector. Used for translation, summarisation, dialogue. Bottleneck problem: one fixed vector must carry all information — performance degrades sharply on long sequences.
shares encoder/decoder idea with Transformer vs Attention: fixed context vector, no dynamic focus

Attention Mechanism

Replaces the fixed context vector with a dynamic weighted sum of all encoder states. At each decode step the model computes scores eᵢ = score(sₜ, hᵢ), normalises with softmax → weights αᵢ, then cₜ = Σαᵢhᵢ.
Attention score variants: Additive (Bahdanau), Dot-product (Luong), Scaled dot-product (Vaswani — used in Transformer).
key idea carried into Transformer self-attention vs Transformer: still uses RNN backbone; attention is additive Q/K/V framework formally introduced here

Transformer (Vaswani et al., 2017)

Drops recurrence entirely — uses self-attention (Q, K, V all from same input) so all positions are processed simultaneously. Multi-head attention runs h parallel heads, each learning different relationships. Positional encoding injects order (self-attention is permutation-invariant). Fully parallel training — O(L²) training & inference complexity.
Components: Token emb → Positional enc → N×(Masked MHA + Add&Norm + FFN + Add&Norm) → Linear + Softmax.
retains Q/K/V attention from Bahdanau vs RNN: no sequential dependency, full parallelism, O(L²) attention vs RNN: needs positional encoding; RNN encodes order implicitly training: O(L²) but parallelisable; inference: O(L²) KV-cache

Encoder-only (BERT, RoBERTa, DistilBERT)

Bidirectional context — each token attends to all others. Pre-trained with masked language modelling. Fine-tuned for classification, NER, QA.
uses standard Transformer encoder blocks vs GPT: bidirectional, not autoregressive

Decoder-only (GPT-1/2/3/4, LLaMA, Mistral)

Causal (left-to-right) masked attention. Pre-trained on next-token prediction. Modern GPT adds BPE tokenisation, RLHF alignment, sparse attention, MoE.
autoregressive like RNNs; same causal structure vs BERT: unidirectional, generative; not suited for classification alone

Encoder–Decoder (T5, BART, mT5)

Encoder reads the full input bidirectionally; decoder generates output autoregressively with cross-attention to encoder states. Best for translation, summarisation, seq2seq tasks.
combines strengths of both encoder-only and decoder-only vs decoder-only: heavier at inference; needs both halves

Alternatives to Transformers

Mamba (SSMs): selective linear recurrence — O(L) inference, parallelisable training via convolution. May sacrifice recall of specific distant tokens.
xLSTM: modern LSTM with improved gating, competitive with Transformers at O(L) inference.
Diffusion LLMs: non-autoregressive parallel decoding — quality has historically lagged.
Hybrid architectures (Jamba, Mamba-2) mix attention layers with SSM layers.
like RNNs: O(L) inference; like Transformers: can parallelise training vs Transformer: no O(L²) bottleneck but may lose token-level recall
