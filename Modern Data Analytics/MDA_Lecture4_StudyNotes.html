1. Scikit-Learn — Overview & Workflow

Why Scikit-Learn?

  • Simple, consistent API across all estimators
  • Actively developed; wide range of classical ML algorithms
  • NLP support; sample datasets; thorough documentation
  • Not the tool of choice for deep learning — use TensorFlow / PyTorch instead

Data Structures

ObjectShapeContent
Feature matrix X(n_samples, n_features)One row per observation; all columns numerical
Target vector y(n_samples,)Labels or values to predict (supervised only)

The 4-Step Recipe

  1. Choose the estimator class — e.g. from sklearn.naive_bayes import GaussianNB
  2. Instantiate with hyperparameters — e.g. model = GaussianNB()
  3. Fit on training data — model.fit(X_train, y_train)
  4. Apply to test data — y_pred = model.predict(X_test)
Key Point — Train / Test Split
Always split before any preprocessing. train_test_split(X, y, random_state=1) returns X_train, X_test, y_train, y_test. Performance is evaluated on the test set — data the model has never seen during training.
Computation Note — reshape(-1, 1)
Sklearn expects a 2-D feature matrix (n_samples, n_features). A single-feature 1-D array must be reshaped: X = np.array([...]).reshape(-1, 1) converts shape (n,) → (n, 1).

Belgian Phones — Practical Lesson

Example
Annual call data (1950–1973) was corrupted: 1964–1969 stored minutes, not calls. OLS fitted blindly pulled the regression line toward those outliers, producing a useless model. Lessons: (1) understand model assumptions; (2) preprocess data appropriately; (3) always read the documentation.
Warning — OLS & Outliers
OLS minimises squared residuals. A single large residual grows quadratically and can dominate the entire loss function, even when heavily outnumbered by normal observations.

2. The Golden Rule — Preventing Data Leakage

⚠️ Golden Rule
All preprocessors must be fit on training data only. Fitting on the full dataset lets the preprocessor learn statistics from the test set, inflating performance estimates.

Correct Workflow

  1. Split into X_train / X_test before any preprocessing
  2. Fit preprocessor on training data only: preprocessor.fit_transform(X_train)
  3. Apply learned parameters to test data: preprocessor.transform(X_test) — never fit_transform(X_test)

3. Encoders — Handling Categorical Variables

Sklearn's feature matrix must be fully numerical. Categorical features (gender, blood type, nationality, ZIP code) must be encoded first.

Key Point — One-Hot Encoding
Creates one binary column per unique category value. Each row has exactly one 1 among those columns. No false ordinal relationship is implied between categories.
from sklearn.preprocessing import OneHotEncoder enc = OneHotEncoder(handle_unknown='ignore') enc.fit(X_train) # learn categories from training data only X_enc = enc.transform(X_test).toarray() enc.get_feature_names_out() # → ['A_a', 'A_b', 'B_a', ...] enc.inverse_transform(X_enc) # recover original category labels
ParameterEffect
handle_unknown='ignore'Unknown test categories → all-zero row (no error)
handle_unknown='error'Raises ValueError if test contains unseen category
drop='first'Drops one column per feature to reduce multicollinearity
Warning — Curse of Dimensionality
A feature with 1 000 unique values creates 1 000 new columns. High-cardinality OHE explodes the feature space, making distance-based algorithms unreliable and models prone to overfitting.

4. Scalers — Feature Scaling

Models sensitive to feature scale: Ridge, k-NN, SVM, distance-based clustering. Tree-based models (Random Forest, XGBoost) do not require scaling.

ScalerFormulaBest for
StandardScalerX* = (X − μ) / σDefault; roughly normally distributed data
MinMaxScalerX* = (X − min) / (max − min)Bounded data; output in [0, 1]
RobustScalerX* = (X − median) / IQRData with significant outliers
Custom (BaseEstimator)User-defined fit/transformWhen built-in scalers don't fit the task
Key Point — Why Scale for Distance-Based Models?
Euclidean distance = √Σ(xᵢ − xⱼ)². A feature with range [0, 10 000] contributes 10 000× more squared distance than a feature with range [0, 1], regardless of which is more predictive. Scaling removes this bias.
from sklearn.preprocessing import StandardScaler StS = StandardScaler() X_scaled = StS.fit_transform(X_train) # fit on train only X_test_scaled = StS.transform(X_test) # apply same μ, σ
Warning
StandardScaler produces zero-mean, unit-variance data for the training set. The distribution shape is only truly standard normal if the input was normal — for non-normal data, the shape is unchanged.

Custom Scaler Pattern

from sklearn.base import BaseEstimator import numpy as np, pandas as pd class CutOffScaler(BaseEstimator): def __init__(self, min_cut=0, max_cut=10): self.min_cut = min_cut self.max_cut = max_cut def fit(self, X, y=None): return self def transform(self, X, y=None): return pd.DataFrame(np.clip(X.values, self.min_cut, self.max_cut), columns=X.columns, index=X.index)

5. Imputers — Handling Missing Data

Most Sklearn models cannot process NaN values. Options: drop via pandas, or impute using Sklearn.

ParameterOptions / Notes
missing_valuesnp.nan, None, or custom strings like 'Missing'
strategy'mean', 'median' (numerical); 'most_frequent' (categorical); 'constant'
add_indicatorIf True, appends a binary flag column marking imputed rows
from sklearn.impute import SimpleImputer SI_num = SimpleImputer(missing_values=np.nan, strategy='mean') SI_cat = SimpleImputer(missing_values=None, strategy='most_frequent') X_num = SI_num.fit_transform(X_train[['Age']]) X_cat = SI_cat.fit_transform(X_train[['Embarked']])
Example — add_indicator
In churn prediction, customers who skipped a survey question may have a systematically higher churn rate. add_indicator=True creates an extra binary column letting the model learn from the missingness pattern itself, not just the imputed value.

6. PCA — Principal Component Analysis

Concept
PCA finds orthogonal axes (principal components) that capture maximum variance. Projecting onto the top-k PCs reduces dimensionality while minimising information loss. Components are generally not directly interpretable.
Key Point — Uninterpretability in ML
In statistical reporting PCs need human-readable meaning. In ML, the model has no concept of feature semantics — it only needs predictive signal. If the PCs retain that signal, interpretability is irrelevant.
from sklearn.decomposition import PCA from sklearn.preprocessing import StandardScaler StS = StandardScaler() X_scaled = StS.fit_transform(X_train) # always scale FIRST pca = PCA() pca.fit(X_scaled) pca.explained_variance_ratio_ # e.g. array([0.969, 0.031]) X_reduced = pca.transform(X_scaled) X_test_reduced = pca.transform(StS.transform(X_test))
Warning — Scale Before PCA
PCA maximises variance. Without scaling, features with large numeric ranges bias the principal components toward those units, not toward informative directions.

Choosing Number of Components

  • Inspect pca.explained_variance_ratio_ — choose k where cumulative ratio reaches ~95%
  • Scree plot: look for the "elbow" where marginal gains drop sharply
  • PCA(n_components=0.95) automatically selects enough components to explain 95% of variance

Example — IsolationForest on Belgian Phones
from sklearn.ensemble import IsolationForest from sklearn import linear_model IsoFo = IsolationForest(n_estimators=100, contamination='auto') labels = IsoFo.fit_predict(phones.calls.values.reshape(-1,1)) # 1 = inlier, -1 = outlier calls_clean = phones.calls[labels == 1] year_clean = phones.year[labels == 1].values.reshape(-1,1) OLS = linear_model.LinearRegression().fit(year_clean, calls_clean)
After removing the 6 anomalous years, the linear fit captured the true underlying trend.
Key Point — Ensemble Methods
IsolationForest builds n_estimators random trees. Anomalies require fewer splits to be isolated; the anomaly score aggregates isolation depths across all trees. More estimators → more stable scores.
Warning
Outlier detectors must be fit on training data only. Fitting on the full dataset or the test set constitutes data leakage.

8. ColumnTransformer — Mixed-Type Datasets

Dispatches different transformers to different column subsets in parallel, then concatenates the outputs into a single numerical matrix.

Key Point — Element Format
Each element: (name, transformer, columns)
  • name — user-chosen string; referenced in GridSearchCV
  • transformer — any Sklearn-compatible object, or 'drop' / 'passthrough'
  • columns — list of column names or integer indices
from sklearn.compose import ColumnTransformer from sklearn.preprocessing import OneHotEncoder, StandardScaler t = ColumnTransformer([ ('drop_cols', 'drop', ['PassengerId', 'Name', 'Ticket', 'Cabin', 'Embarked', 'Parch']), ('OneHot', OneHotEncoder(handle_unknown='ignore'), ['Sex', 'SibSp', 'Pclass']), ('Scale', StandardScaler(), ['Age', 'Fare']) ]) X_train_t = t.fit_transform(X_train) # fit + transform on training data X_test_t = t.transform(X_test) # NOT fit_transform — apply learned params
Warning — Never fit_transform on Test Data
t.fit_transform(X_test) relearns statistics from the test set. Always use t.transform(X_test).

9. Pipelines

A Pipeline chains multiple Sklearn estimators sequentially into one object. It exposes .fit(), .predict(), and .score() — behaving like any standard Sklearn estimator.

Benefits

  • Eliminates repetitive fit/transform calls — cleaner, less error-prone code
  • Guarantees identical step order for training and test data
  • Single .fit() call propagates through all steps automatically
  • Integrates with GridSearchCV to tune all steps simultaneously
  • Custom BaseEstimator classes plug in directly as steps
from sklearn.pipeline import Pipeline from sklearn.preprocessing import StandardScaler from sklearn.decomposition import PCA from sklearn.linear_model import Ridge pipe = Pipeline([ ('scaler', StandardScaler()), # step 1 ('reduce_dim', PCA()), # step 2 ('regressor', Ridge()) # step 3 — final estimator ]) pipe.fit(X_train, y_train) # fit_transform step 1&2, fit step 3 preds = pipe.predict(X_test) # transform step 1&2, predict step 3 pipe.score(X_test, y_test) # R² for regression pipelines
Key Point — Step Constraints
  • All steps except the last must implement transform()
  • The final step must implement predict() for supervised pipelines
  • A ColumnTransformer counts as one step (typically the first)
Example — Without vs. With Pipeline
Without pipeline: scaler.fit_transform(X_train) → pca.fit_transform(...) → ridge.fit(...) → scaler.transform(X_test) → pca.transform(...) → ridge.predict(...) — 6 separate calls, easy to make mistakes.

With pipeline: pipe.fit(X_train, y_train) → pipe.predict(X_test) — 2 calls, identical outcome.

10. Hyperparameter Tuning with GridSearchCV

Concept — Parameters vs. Hyperparameters
Model parameters (e.g. Ridge coefficients) are learned automatically during .fit(). Hyperparameters (e.g. Ridge's alpha, PCA's n_components) are set by the user before training and are not updated by .fit(). A poor hyperparameter choice degrades performance.

GridSearchCV Procedure

  1. Define a grid of candidate hyperparameter values
  2. For each combination, perform k-fold CV within the training set
  3. Select the combination with the best mean CV score
  4. Refit on all training data using the best combination
  5. Evaluate once on the held-out test set
Key Point — Naming Convention
To reference a step's hyperparameter in param_grid: step_name__hyperparameter_name (double underscore). The hyperparameter name must match the estimator's documentation exactly.
from sklearn.model_selection import GridSearchCV params = { 'reduce_dim__n_components': np.arange(1, 11), # 10 values 'regressor__alpha': 2.0**np.arange(-6, 6) # 12 values → 120 combos × 5 folds = 600 fits } gs = GridSearchCV(pipe, param_grid=params, cv=5, verbose=1) gs.fit(X_train, y_train) gs.score(X_test, y_test) # final evaluation on held-out test set gs.best_params_ # best hyperparameter combination gs.best_estimator_ # the fitted best model object

Comparing Entire Steps (Not Just Values)

from sklearn.preprocessing import StandardScaler, RobustScaler pipe = Pipeline([('scaler', []), ('reduce_dim', PCA()), ('regressor', Ridge())]) grid = [{'scaler': [StandardScaler(), RobustScaler()]}] gs = GridSearchCV(pipe, grid).fit(X_train, y_train) gs.best_params_ # → {'scaler': RobustScaler()}
Warning — Test Set Must Remain Untouched
CV folds are drawn from the training set only. Using the test set to select hyperparameters inflates the final performance estimate and is data leakage. The test set is used exactly once, at the very end.
