2 · Supervised Learning — Regression Analysis

2.1 The General Framework

Regression estimates the relationship between a set of covariates (predictors) and a target variable (continuous or categorical):

\( Y = g(X_1, \ldots, X_n) + \epsilon \)

where \(\epsilon\) is a zero-mean error term. The goal: find the best-performing model from a chosen candidate set.

2.2 Linear Regression

\( Y = \beta_0 + \sum_{i=1}^{n} \beta_i X_i + \epsilon \)
  • Each candidate is fully specified by its n+1 parameters \(\boldsymbol\beta\).
  • Choose the candidate set based on data exploration + expert knowledge.
  • Apply Occam's Razor: avoid over-complex models that over-fit training data.

2.3 Prediction & the OLS Loss

Predicted value: \(\hat{Y} = b_0 + \sum_{i=1}^{n} b_i X_i\). The Ordinary Least Squares (OLS) loss:

\( l(\mathbf{b}) = \sum_{i=1}^{M}[Y_i - \hat{Y}_i]^2 = \sum_{i=1}^{M}\!\left[Y_i - b_0 - \sum_{j=1}^{n} b_j X_j\right]^2 \)
OLS minimisation finds the best model (1) from the linear candidate set only and (2) according to the squared-error definition of performance. Different loss functions yield different models.

3 · Finding the Best Model — Numerical Optimisation

3.1 Gradient Descent

Iteratively update parameters in the direction of steepest descent:

\( b^{(k+1)} = b^{(k)} - \eta \cdot \nabla l(b^{(k)}) \)

\(\eta\) = learning rate (step size). The learning rate matters critically:

Learning RateEffect
Too lowMany small updates; slow convergence
Just rightEfficient convergence to minimum
Too highDrastic updates; may diverge
Drawbacks of gradient descent: risk of getting stuck in local optima or flat plateaus. Mitigations: smart initialisation, adaptive learning rates, grid search.

3.2 Newton's Method

Uses second-order (curvature) information. Starting from a Taylor expansion around \(b_0\):

\( l(b) \approx l(b_0) + (\Delta b)^T \nabla l(b_0) + \tfrac{1}{2}(\Delta b)^T H(b_0)(\Delta b) \)

Minimising this second-order approximation yields the Newton step: \(\Delta b = -H^{-1}\nabla l\)

where \(H\) is the Hessian matrix. Generalisations include Levenberg-Marquardt, Quasi-Newton methods.

4 · Bias-Variance Trade-Off

4.1 The Core Tension

The candidate space must be large enough to contain a good approximation of \(g\), but not so large that it starts fitting the noise \(\epsilon\).

Overfitting (high variance, low bias): Model memorises training noise. Small changes in training data produce completely different parameters and predictions.
Underfitting (low variance, high bias): Model is too simple to capture the true relationship.

4.2 Why Not Use the Most Flexible Model?

Even though a quadratic set contains all linear models (so the best quadratic ≥ best linear on training data), the quadratic model can overfit. On new data, the linear model may generalise far better.

4.3 Dealing with Overfitting

MethodMechanismEffect
RegularisationAdd penalty to lossShrinks coefficients toward 0
Early StoppingStop training when validation error risesPrevents fitting noise
Ensemble MethodsCombine multiple modelsReduces variance (Bagging) or bias (Boosting)

5 · Regularisation

Regularisation constrains parameter estimates toward zero, effectively performing automatic variable selection.

MethodPenalty TermEffect on Coefficients
Ridge (L2)\(\lambda\sum_{j=1}^z b_j^2\)Shrinks all coefficients; none become exactly zero
Lasso (L1)\(\lambda\sum_{j=1}^z |b_j|\)Can set some coefficients to exactly zero → sparse model
Elastic Net\(\lambda_1\sum|b_j| + \lambda_2\sum b_k^2\)Combines Ridge + Lasso benefits; two hyperparameters
Ridge vs Lasso: Lasso performs variable selection by driving some coefficients to zero exactly; Ridge shrinks all coefficients but keeps them nonzero.

6 · Early Stopping

Never use all data for training. Split data into training set and validation set. Monitor validation (generalisation) error during training. Stop when it starts increasing.

Important: Once a validation set has been used to decide early stopping, it cannot be used again to estimate generalisation error — it has already influenced the model! This is why one sometimes uses a 3-way split: training / validation / test.
Early Stopping vs Post-Pruning: Early stopping halts before the model is fully grown. Post-pruning (used in decision trees) first grows the tree fully, then removes layers bottom-up based on validation performance.

7 · Ensemble Methods

7.1 Bagging (Bootstrap Aggregating)

1
Sample (with replacement) \(m\) datasets of fixed size from training data.
2
Train one model on each bootstrap sample → \(m\) different models.
3
Aggregate: majority vote (classification) or average (regression).
Effect: Decreases variance, not necessarily bias. Can be parallelised easily. An ensemble of decision trees = a forest.

7.2 Boosting

Sequentially add models that focus on correcting mistakes of the previous ensemble.

  • AdaBoost: Weights misclassified samples higher at each iteration.
  • Gradient Boosting: Predict the residual error and add it as a correction; closely related to gradient descent.
Effect: Decreases bias, not necessarily variance. Risk of overboosting → overfitting.

8.5 Post-Pruning

1
Grow tree to maximum depth → heavily overfitted.
2
Remove bottom layer; evaluate validation performance.
3
If performance unchanged/better → keep pruned; repeat step 2.
4
If performance drops → stop.

8.6 Common Pitfall: Class Imbalance

If 99 % of samples are "healthy", a classifier that always predicts "healthy" achieves 99 % accuracy. This is not useful! Use Balanced Accuracy and other class-aware metrics instead.

9 · Unsupervised Learning — Clustering

9.1 K-Means Algorithm

1
Choose \(K\) (number of clusters).
2
Randomly initialise \(K\) centroids (or use K-means++ for smarter initialisation).
3
Assign each data point to the nearest centroid (Euclidean by default).
4
Recompute centroids as the mean of assigned points.
5
Repeat steps 3–4 until convergence (centroids stop moving).

9.2 Key Decisions

DecisionOptions / Notes
Initial centroidsRandom or K-means++ (Sklearn default)
Stopping criterionFew reassignments, centroids barely move, or sum-of-squared-distances plateau
Number of runsRun multiple times; final label = most common assignment across runs
Distance metricEuclidean, Manhattan, Minkowski, Cosine, Hamming, etc.

9.3 Disadvantages of K-Means

  • Choosing \(K\) is hard.
  • Sensitive to initialisation (may converge to local optima).
  • Curse of dimensionality: Euclidean distances become meaningless in high dimensions → often combine with PCA.
  • Does not work for categorical data (mean undefined).
  • Sensitive to outliers.

9.4 Probabilistic Clustering

MethodKey Idea
Gaussian Mixture Model (GMM)Assumes data is generated from a mixture of Gaussians; returns cluster probabilities, not just labels. Uses EM algorithm.
Fuzzy C-MeansSoft clustering alternative to K-means.
GMM Algorithm: (1) random assignment → (2) compute μ, σ per group → (3) compute probability density per cluster → (4) reassign by max probability → (5) recalculate parameters → iterate until stable.

10 · Unsupervised Learning — Outlier Detection

10.1 Mahalanobis Distance

\( D_M(X) = \sqrt{(X-\mu_X) S_X^{-1} (X-\mu_X)^T} \)

Accounts for variable correlations (unlike Euclidean). Requires a robust covariance estimator since the data contains outliers → sklearn uses Minimum Covariance Determinant (MCD).

MCD key idea: find the subset of "clean" observations whose covariance matrix has the smallest determinant (smallest data cloud).

10.2 Isolation Forest

Key idea: outliers are isolated quickly; inliers require many splits to isolate.

→
Repeatedly split a randomly chosen feature at a random value. Points isolated near the top of a tree are flagged as anomalies.
Advantages
Few hyperparameters (just number of trees)
Easily parallelisable
Handles categorical variables
Fast predictions → excellent baseline

Other ML outlier detectors: One-Class SVM, Local Outlier Factor.

11 · Unsupervised Learning — Dimension Reduction (PCA)

11.1 Motivation

High-dimensional data suffers from: high computational cost, multicollinearity, difficulty visualising. PCA transforms correlated variables into uncorrelated principal components that capture maximum variance.

11.2 PCA Algorithm

1
Standardise variables (unit variance) to prevent high-variance variables from dominating.
2
Compute the covariance matrix.
3
Compute eigenvalues & eigenvectors of the covariance matrix.
4
Select principal components: PC1 = direction of maximum projected variance; PC2 = orthogonal to PC1; etc.
5
Project data points onto selected PCs.
6
Rotate so PCs are the new axes.
7
Reduce: drop components with smallest eigenvalues (least variance explained).

11.3 Explained Variance

\(\text{Explained Variance}_k = \frac{\text{Eigenvalue}_k}{\sum_{i=1}^n \text{Eigenvalue}_i}\)

11.4 Interpretation

The loadings (eigenvectors / components_ in sklearn) show how original variables contribute to each PC. Label PCs based on which variables load heavily on them.

11.5 Drawback

PCA only finds linear subspaces. Non-linear alternatives include Kernel PCA, t-SNE, UMAP, and Sparse Autoencoders (neural-network-based encoder-decoder that minimises reconstruction loss through a bottleneck).

🖊 Short Answer Questions

SA 1 · Bias-Variance Trade-Off
Explain, using the bias-variance trade-off framework, why a more flexible model (e.g. quadratic vs linear) does not always produce better generalisation performance, even though it will always fit the training data at least as well.
Key Points:
A more flexible model has a larger candidate set, so it will always achieve ≤ training loss compared to a simpler model. However, flexibility comes at the cost of higher variance: the model fits not just the true signal \(g\) but also the noise \(\epsilon\). Small changes in training data then produce very different models and wildly different predictions on new data. The simpler model has higher bias (it may miss some aspects of \(g\)) but lower variance — meaning predictions are more stable across datasets. Optimal generalisation occurs at the bias-variance balance: just enough complexity to approximate \(g\) well, but not so much that \(\epsilon\) is modelled. This is why Occam's Razor applies: among models with similar training performance, prefer the simpler one.
SA 2 · Loss Function Selection
A manufacturing dataset contains sensor readings where most values are normal, but a small proportion of readings are extreme due to sensor malfunctions. Compare MSE and MAE as loss functions for fitting a regression model on this data, and recommend which to use. Justify your answer.
Key Points:
MSE squares each error, meaning extreme outlier readings contribute disproportionately large values to the loss. The model is forced to "explain" those extreme sensor values, which distorts the fitted relationship for the majority of normal readings — the model is not robust to outliers.

MAE treats all errors linearly. Outliers contribute proportionally, not quadratically, so the fitted model is less distorted. MAE is also interpretable (average absolute error in the original units).

Recommendation: Use MAE or Huber loss. Huber loss is particularly appealing here: it acts like MSE for small (normal) errors (providing a smooth, well-behaved gradient) and like MAE for large (outlier) errors (providing robustness), controlled by the hyperparameter \(\delta\).
SA 3 · Regularisation Mechanism
Describe the mathematical mechanism by which Lasso regularisation can set some regression coefficients to exactly zero, while Ridge regularisation cannot. What practical benefit does this give Lasso?
Key Points:
Both Ridge (L2) and Lasso (L1) add a penalty to the OLS objective. Ridge adds \(\lambda \sum b_j^2\), a smooth, differentiable term whose gradient at zero is zero, so the optimum typically does not reach exactly zero. Lasso adds \(\lambda \sum |b_j|\), which is not differentiable at zero and has a constant gradient (sub-gradient) of ±λ at that point. Geometrically, the L1 penalty ball has "corners" at axis-aligned points; when the OLS ellipsoid touches a corner, the corresponding coefficient is exactly zero.

Practical benefit: Lasso performs automatic feature selection — irrelevant predictors get exactly zero coefficients, producing a sparse model that is easier to interpret and potentially more robust in production.
SA 4 · Early Stopping Data Split
Why is a three-way data split (training / validation / test) sometimes necessary? In what scenario is a two-way split sufficient?
Key Points:
A three-way split is necessary when the validation set is used to make model selection decisions during training — such as early stopping, hyperparameter tuning, or pruning. Once a validation set influences the model, it can no longer provide an unbiased estimate of generalisation error (the model has "seen" it indirectly). A separate, held-out test set is then required for final, unbiased evaluation.

A two-way split is sufficient when no decisions are made based on the held-out set during training — i.e., when the model is trained once on the training data and evaluated only once on the test data, with no iterative tuning steps.
SA 5 · Bagging vs Boosting
Contrast Bagging and Boosting in terms of (a) how models are built, (b) which component of prediction error each primarily reduces, and (c) a practical risk associated with each.
Key Points:
(a) Construction: Bagging trains \(m\) models independently on bootstrap samples (parallelisable); prediction = average or majority vote. Boosting trains models sequentially, where each new model corrects errors of the current ensemble.

(b) Error reduction: Bagging reduces variance (averaging independent noisy models cancels out their errors). Boosting reduces bias (each iteration targets the residual error, pulling predictions toward the true values).

(c) Risks: Bagging reduces variance but does not necessarily reduce bias — a very biased base learner will produce a biased forest. Boosting risks overfitting ("overboosting") if too many iterations are used; each model becomes increasingly tailored to the training data's noise.
SA 6 · Decision Tree Impurity
A decision tree node contains 14 red and 2 blue observations (16 total). Calculate its Gini Index and Misclassification Error. Then explain why these measures are used as splitting criteria rather than simply maximising the number of correctly classified training samples.
Calculations:
p(red) = 14/16 = 0.875; p(blue) = 2/16 = 0.125
Gini: G = 0.875(1−0.875) + 0.125(1−0.125) = 0.875×0.125 + 0.125×0.875 = 0.109 + 0.109 ≈ 0.22
Misclassification Error: M = min(14/16, 2/16) = 2/16 = 0.125

Why not maximise training accuracy directly? Greedy maximisation of correct classifications at each step is myopic — a split can give good immediate accuracy but poor downstream splits. Impurity measures like Gini quantify uncertainty across all classes and provide a richer signal that better guides the tree toward pure leaf nodes. Also, simply maximising local accuracy leads to deeper trees and overfitting.
SA 7 · K-Means Limitations & Remedies
You are asked to cluster a customer dataset with 50 features (mostly numerical). Outline at least three challenges specific to this high-dimensional setting, and propose a practical preprocessing pipeline before applying K-means.
Challenges:
1. Curse of dimensionality: Euclidean distances lose meaning — all points tend to be roughly equidistant, making cluster separation ambiguous.
2. Scaling: Features with large ranges dominate the distance metric; variables must be standardised.
3. Multicollinearity: Many of the 50 features may be correlated, introducing redundancy that inflates certain dimensions.
4. Outlier sensitivity: K-means centroids are means, dragged by outliers.

Practical Pipeline:
(i) Exploratory data analysis — identify outliers, missing values, feature distributions.
(ii) Standardise all features (zero mean, unit variance).
(iii) Apply PCA to reduce to a lower-dimensional space retaining, say, 90% of variance — this alleviates the curse of dimensionality and removes multicollinearity.
(iv) Run K-means++ multiple times on the PCA scores, choosing K via the elbow method on within-cluster sum of squares.
(v) Validate cluster structure qualitatively and with metrics like silhouette score.
SA 8 · Gradient Descent vs Newton's Method
Compare gradient descent and Newton's method as optimisation algorithms for training a machine learning model. In which scenarios might Newton's method be preferable, and when might it be impractical?
Key Points:
Gradient Descent: Uses only the gradient (first-order information). Computationally cheap per iteration. Requires careful tuning of learning rate. Scales well to large parameter spaces and large datasets (especially mini-batch/stochastic variants).

Newton's Method: Uses the Hessian (second-order information) to account for curvature. Can converge in far fewer iterations because it takes the optimal step size for a quadratic approximation. Produces the update \(\Delta b = -H^{-1}\nabla l\).

Preferable: Small-to-medium parameter spaces, smooth loss surfaces, when fast convergence is critical, and when computing/inverting the Hessian is feasible.

Impractical: Large neural networks with millions of parameters — the Hessian is an \(n \times n\) matrix (n = number of parameters), which is extremely expensive to compute and invert. Quasi-Newton methods (BFGS, L-BFGS) approximate the Hessian to bridge this gap.
SA 9 · Isolation Forest Intuition
Explain the intuition behind the Isolation Forest algorithm. Why are outliers isolated with fewer splits than inliers? How does the "forest" aspect improve robustness?
Key Points:
Intuition: The algorithm repeatedly chooses a random feature and a random split value within that feature's range. An outlier is by definition far from the bulk of the data, so a single random split can quickly isolate it — it appears at a very shallow depth in the tree. An inlier is surrounded by many similar points; many splits are required to isolate it, so it appears at greater depth.

Forest robustness: A single tree is stochastic (depends on random feature and split choices). Running many trees (an "isolation forest") and averaging the path lengths across all trees gives a stable, reliable anomaly score. Points consistently isolated early (short average path length across many trees) are flagged as outliers. This ensemble approach reduces the variance of the anomaly score.
SA 10 · Synthesis — End-to-End ML Pipeline
A company wants to predict whether a customer will churn (leave) based on their usage data. Outline an end-to-end machine learning pipeline using concepts from this lecture, addressing: problem type, candidate model, loss function, overfitting mitigation, and evaluation metric choice.
Model Answer:
Problem type: Binary classification (churn = yes/no). A supervised learning problem with a categorical target and continuous/mixed predictors → Logistic regression or Decision Tree (or ensemble thereof).

Candidate model: Start with logistic regression (interpretable, good baseline). Then try a Decision Tree or Random Forest for potentially better accuracy. Motivated by domain knowledge and data exploration.

Loss function: Binary cross-entropy (log-loss) for logistic regression; Gini impurity or entropy for decision trees.

Overfitting mitigation: (i) Regularisation (L2 for logistic regression, post-pruning / max-depth for trees). (ii) Early stopping via validation loss monitoring. (iii) Bagging (Random Forest) to reduce variance from individual trees.

Data split: Training / validation (for tuning) / test (for final unbiased evaluation).

Evaluation metric: Simple accuracy is inappropriate because churn is typically rare (class imbalance). Use Balanced Accuracy, F1-score, or ROC-AUC to account for the imbalance and properly reward correct identification of churning customers.
