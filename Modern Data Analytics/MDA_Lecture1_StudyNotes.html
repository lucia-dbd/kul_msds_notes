1.1 Python

Python is among the most popular programming languages for data scientists, especially when integrating data analysis with web apps or incorporating statistics code into production databases.

Unlike R (traditional statistical computing), Python excels at extended data science tasks like NLP, computer vision, and more.

Getting Started: Anaconda

Anaconda is a package manager that bundles Python with 300+ pre-installed packages for mathematics, science, and engineering. It avoids manual installation of individual dependencies.

1.4 Git, GitHub & Hugging Face

Git

Git (created by Linus Torvalds in 2005) is an open-source distributed version control system — the complete codebase including full history is mirrored on every developer's machine.

Git's key differentiator: branching model — independent branches let developers try new ideas, work in parallel, and merge or discard changes without touching others' work.

GitHub

GitHub is a cloud-based database for hosting Git repositories, enabling remote access by any authorized person from any device, anywhere.

git clone https://github.com/user/repo.git
ConceptExplanation
commitSnapshot of changes in your local repository
pushUpload local commits to remote (GitHub)
pullDownload remote changes to local
branchIndependent line of development
mergeCombine branch changes into another branch

Hugging Face

Hugging Face is a community platform and library hub for NLP, computer vision, and reinforcement learning — hosting state-of-the-art pre-trained models (BERT, GPT, etc.), datasets, and research papers.

1.6 Virtual Environments

A virtual environment (venv) is an isolated Python environment where the interpreter, libraries, and scripts are completely separate from other environments and the system Python — making each project self-contained.
Why you need it: Installing conflicting package versions for different projects into the global Python installation will break older projects.

Setup Steps (virtualenv)

# 1. Install virtualenv
pip install virtualenv

# 2. Create environment
python -m venv myenv

# 3. Activate
myenv\Scripts\activate   # Windows
source myenv/bin/activate # macOS/Linux

# 4. Export dependencies
pip freeze > requirements.txt

# 5. Install from requirements
pip install -r requirements.txt

# 6. Deactivate
deactivate

1.7 Object Oriented Programming (OOP)

OOP is a programming paradigm that organises code using classes (blueprints/concepts) and objects (instances of classes) to represent real-world entities and their behaviour — enabling modular, maintainable, scalable applications.

Core OOP Concepts

ConceptDescriptionPython Example
ClassBlueprint defining attributes and methodsclass Dog:
ObjectInstance of a classdog1 = Dog("Marcel", 2)
AttributeData belonging to an objectself.name = name
MethodFunction belonging to a classdef bark(self):
__init__Constructor; executes at instantiationAssigns initial values
selfReference to the current object instanceAccesses attributes/methods

Four Pillars of OOP

PillarMeaning
EncapsulationBundling data and methods; restricting direct access to internals
AbstractionHiding complex implementation details; exposing only necessary interface
InheritanceA child class inherits attributes/methods from a parent class
PolymorphismSame interface, different underlying implementations
Scikit-Learn uses OOP: A LinearRegression object is an instance of a class with methods like .fit(X, y) (training) and .predict(X) (inference). Pandas DataFrames and NumPy arrays are also class instances.
