2. Pharmacology: Effective Dose and LD50

In dose-response modeling, we often care about the dose at which a specific proportion of the population is affected.

Effective Level (EL): The dose $x$ that produces a quantal (all-or-nothing) effect in a given fraction of the population.

EL50 (Median Effective Level) / LD50 (Lethal Dose 50%): The dose at which $\pi(x) = 0.5$, i.e., 50% of the population is affected.

Under the logit model $\text{logit}[\pi(x)] = \beta_0 + \beta_1 x$, setting $\pi = 0.5$ means $\text{logit}(0.5)=0$, so: $$LD_{50} = -\frac{\beta_0}{\beta_1}$$ The steepest slope of the logistic curve occurs exactly at this point.

For the animal experiment: $\widehat{LD}_{50} = -(-1.40353)/0.26429 = 5.311$ mg.

3. Bootstrap Confidence Intervals

Bootstrap is a general, nonparametric resampling framework for constructing confidence intervals when the sampling distribution of a statistic is unknown or intractable.

Bootstrap Algorithm: Given i.i.d. sample $\mathbf{y} = \{y_1,\ldots,y_N\}$ from $p(y|\theta)$:
  1. Repeat $R$ times: sample with replacement $N$ elements from $\mathbf{y}$ to get $\mathbf{y}^*_i$.
  2. Compute statistic $T_i = t(\mathbf{y}^*_i)$ on the resample.
  3. Use the empirical distribution $T_1,\ldots,T_R$ to construct a CI for $\theta$.

In R: boot(data, statistic_fn, R=1000) followed by boot.ci(..., type="all").

Types of Bootstrap CIs (from boot.ci)

⚠ Practical note: The basic (pivotal) CI is generally more robust than the percentile CI for skewed or non-normal bootstrap distributions. The BCa CI can be unstable when the bias-correction factor requires extreme percentiles of the bootstrap sample. The studentized CI requires a within-bootstrap variance estimate — omitting it triggers R's warning message.

4. Sigmoidal Response Functions and Link Functions

Three (actually four) S-shaped response functions are commonly used for binary outcomes. All are bounded in $(0,1)$, S-shaped, and asymptotically approach 0 and 1. They arise naturally from dichotomizing a latent continuous variable $\tilde{y}_i = -\mathbf{x}_i^T\boldsymbol\beta_c + \varepsilon_i$, where the distribution of $\varepsilon_i$ determines the link function.

LinkError Distribution $\varepsilon$$\pi(\mathbf{x})$GLM call in R
LogitLogistic ($\sigma = \pi/\sqrt{3}$)$\frac{e^{\mathbf{x}^T\boldsymbol\beta}}{1+e^{\mathbf{x}^T\boldsymbol\beta}}$binomial("logit")
ProbitNormal $N(0,\sigma^2)$$\Phi(\mathbf{x}^T\boldsymbol\beta_P)$binomial("probit")
CloglogGumbel (extreme value)$1 - \exp[-\exp(\mathbf{x}^T\boldsymbol\beta_G)]$binomial(cloglog)
LoglogReversed Gumbel$\exp[-\exp(\mathbf{x}^T\boldsymbol\beta)]$Custom link function in R

Latent Variable Derivation — Probit

If $\varepsilon_i \sim N(0,\sigma^2)$ and $y_i = \mathbf{1}[\tilde{y}_i \leq 0]$, then: $$\pi_i = P(y_i=1|\mathbf{x}_i) = P\!\left(\frac{\varepsilon_i}{\sigma} \leq \frac{\mathbf{x}_i^T\boldsymbol\beta_c}{\sigma}\right) = \Phi(\mathbf{x}_i^T\boldsymbol\beta_P)$$ where $\boldsymbol\beta_P = \boldsymbol\beta_c/\sigma$. Note: neither $\boldsymbol\beta_c$ nor $\sigma$ is individually identifiable — only their ratio is.

Latent Variable Derivation — Logit

If $\varepsilon_i$ follows a logistic distribution with CDF $F(\varepsilon)=e^\varepsilon/(1+e^\varepsilon)$ and $\sigma = \pi/\sqrt{3}$, then: $$\pi_i = \frac{e^{\mathbf{x}_i^T\boldsymbol\beta_L}}{1+e^{\mathbf{x}_i^T\boldsymbol\beta_L}}, \quad \text{where } \boldsymbol\beta_L = \frac{\pi}{\sqrt{3}}\boldsymbol\beta_P \approx 1.814\,\boldsymbol\beta_P$$ This is why logit coefficients are approximately $\pi/\sqrt{3} \approx 1.814$ times the probit coefficients.
Identifiability constraint: In all latent variable formulations, neither $\boldsymbol\beta_c$ nor $\sigma$ is separately identifiable — only the ratio $\boldsymbol\beta_P = \boldsymbol\beta_c/\sigma$ can be estimated. This is why GLMs directly model the scaled ratio.

5. Symmetry Property of Link Functions

Symmetry: A response function $\pi(x)$ is symmetric if the curve has a symmetric appearance about the point where $\pi(x)=0.5$. This means $\pi(x)$ approaches 0 at the same rate it approaches 1.
LinkSymmetric?$\pi(x) \to 0$$\pi(x) \to 1$When to use
Logit✓ YesModerate rateModerate rateDefault; most common
Probit✓ YesModerate rateModerate rateLatent normal variable models
Cloglog✗ NoSlowlySharplyWhen $\pi \to 1$ rapidly; survival/extreme value
Loglog✗ NoSharplySlowlyWhen $\pi \to 0$ rapidly (not in base R glm)
⚠ Symmetry consequence: If the response variable is recoded as $y'_i = 1 - y_i$ (swapping 0s and 1s), symmetric links (logit, probit) simply reverse the signs of all coefficients. This follows from $\Phi(z) = 1 - \Phi(-z)$ for probit, and the logistic symmetry for logit. Asymmetric links (cloglog, loglog) do not have this property.
Animal experiment — comparing fitted curves: In the morbidity-dose example, all four links give visually similar fitted curves in the central range of proportions but diverge at the tails. The loglog link approaches 1 slowly, while cloglog approaches 1 sharply. Because the data are fairly symmetric, the logit and probit fits are nearly indistinguishable, and both provide excellent fit (Pearson $\chi^2$ p-values $> 0.60$).

6. Goodness-of-Fit Tests — Overview

After fitting a logistic regression model, we must assess whether it adequately describes the data. Goodness-of-fit (GOF) tests provide an overall measure of model adequacy. They test:

$H_0$: The logistic model is correctly specified   vs.   $H_1$: The saturated model fits better.
⚠ Important limitation: GOF tests are not sensitive to departures that affect only a few observations. One must distinguish between:
  • Replicated data: Multiple observations at the same covariate pattern $\mathbf{x}_i$ (e.g., grouped binary data). Pearson $\chi^2$ and Deviance test are appropriate.
  • Unreplicated / continuous covariates: Each subject has a unique covariate pattern. Use the Hosmer-Lemeshow test.

7. Pearson Chi-Square Goodness-of-Fit Test

Suppose we have $N$ distinct covariate patterns $\mathbf{x}_1,\ldots,\mathbf{x}_N$ (groups), each with $n_i$ replications, and $y_i = \sum_{j=1}^{n_i} y_{ij}$ successes. Then $y_i \sim \text{Bin}(n_i, \pi_i(\boldsymbol\beta))$.

Pearson Chi-Square Statistic: $$X^2 = \sum_{i=1}^{N} \sum_{k=0}^{1} \frac{(O_{ik} - E_{ik})^2}{E_{ik}} = \sum_{i=1}^{N} \frac{(y_i - n_i\hat\pi_i)^2}{n_i\hat\pi_i(1-\hat\pi_i)}$$ where $O_{i1} = y_i$, $O_{i0} = n_i - y_i$, $E_{i1} = n_i\hat\pi_i$, $E_{i0} = n_i(1-\hat\pi_i)$.
Asymptotic distribution: Under $H_0$, when $N$ is fixed and $n_i \to \infty$: $$X^2 \xrightarrow{d} \chi^2(N-p)$$ where $p = \dim(\boldsymbol\beta)$. The degrees of freedom equal the number of groups minus the number of estimated parameters.
⚠ Conditions: This test is only valid when there are categorical regressors only (so that $N$ is finite and each $n_i \to \infty$). With continuous predictors, $N$ grows with sample size and the chi-square approximation breaks down. Rule of thumb: all $E_{ik} \geq 1$, and at least 80% of cells should have $E_{ik} \geq 5$.

## Logit model

Both p-values are large → no evidence of lack of fit for either model. The log-log model actually fits slightly better by this criterion.

8. Deviance Goodness-of-Fit Test

The deviance test is the logistic-regression analogue of the F-test for lack of fit in linear regression. It compares the fitted model to the saturated model (one parameter per covariate pattern).

Deviance (Likelihood Ratio Test statistic): $$D = -2\big[\ell(\hat{\boldsymbol\pi}) - \ell(\tilde{\boldsymbol\pi})\big] = -2\sum_{i=1}^{N}\left[y_i \log\!\left(\frac{\hat\pi_i}{\tilde\pi_i}\right) + (n_i - y_i)\log\!\left(\frac{n_i - n_i\hat\pi_i}{n_i - n_i\tilde\pi_i}\right)\right]$$ where $\tilde\pi_i = y_i/n_i$ (saturated model MLE) and $\hat\pi_i$ is the fitted model MLE.
Key properties:
• $D \geq 0$ always; $D = 0$ iff the model fits perfectly.
• Under $H_0$ with $N$ fixed, $n_i \to \infty$: $D \xrightarrow{d} \chi^2(N-p)$.
• Only valid for categorical predictors only (same condition as Pearson $\chi^2$).
• $D$ is a generalization of the SSE from linear regression.
• R labels it "Residual deviance"; "Null deviance" $D_0$ uses only an intercept (analogous to total SS).

9. Hosmer-Lemeshow Test

When predictors are continuous, each observation has a unique covariate pattern → $N$ grows → the Pearson and Deviance chi-square approximations are invalid. The Hosmer-Lemeshow (HL) test solves this by grouping observations into $g$ (usually 10) strata based on estimated probabilities.

Two grouping strategies:
Strategy 1 (default): Group by quantiles of $\hat\pi_i$ — group $k$ contains the $n/g$ observations with the $k$-th smallest predicted probabilities.
Strategy 2: Group by equal intervals of $\hat\pi_i$ — group $k$ contains observations with $\hat\pi_i \in ((k-1)/g,\, k/g]$.

Within each group $k$: observed counts $O_{k1}, O_{k0}$ vs. expected $E_{k1} = \sum \hat\pi_i$, $E_{k0} = \sum(1-\hat\pi_i)$. $$\hat{C} = \sum_{k=1}^{g}\frac{(O_{k1}-E_{k1})^2}{E_{k1}} + \frac{(O_{k0}-E_{k0})^2}{E_{k0}} \xrightarrow{d} \chi^2(g-2)$$ Simulations show Strategy 1 gives the better chi-square approximation.
⚠ Limitations: The HL test loses 2 degrees of freedom (hence $\chi^2(g-2)$). Power depends heavily on the choice of $g$. It may miss localized departures from fit that don't affect overall groupings. Use alongside residual plots.

10. Logistic Regression Residuals

For Bernoulli data ($n_i=1$, $N=n$), the ordinary residual $e_i = y_i - \hat\pi_i$ takes only two values:

$e_i = \begin{cases} 1 - \hat\pi_i & \text{if } y_i = 1 \\ -\hat\pi_i & \text{if } y_i = 0 \end{cases}$

This binary structure makes raw residuals uninformative individually. Three standardized residuals are used instead.

Pearson Residuals

$$e_{P_i} = \frac{y_i - \hat\pi_i}{\sqrt{\hat\pi_i(1-\hat\pi_i)}}$$ Divides raw residual by the estimated SD of $y_i$. Note: $X^2 = \sum_{i=1}^n e_{P_i}^2$ (the Pearson chi-square statistic).

Studentized Pearson Residuals

$$e_{sP_i} = \frac{e_{P_i}}{\sqrt{1-\hat{h}_{ii}}}$$ where $\hat{h}_{ii} = \hat\pi_i(1-\hat\pi_i)\,\mathbf{x}_i^T(\mathbf{X}^T\hat{\mathbf{V}}\mathbf{X})^{-1}\mathbf{x}_i$ are diagonal elements of the hat matrix $\hat{\mathbf{H}} = \hat{\mathbf{V}}^{1/2}\mathbf{X}(\mathbf{X}^T\hat{\mathbf{V}}\mathbf{X})^{-1}\mathbf{X}^T\hat{\mathbf{V}}^{1/2}$, satisfying $\sum \hat{h}_{ii} = p$.

For replicated data (large $n_i$): $e_{sP_i} \approx N(0,1)$ → values $|e_{sP_i}|>2$ or $3$ suggest lack of fit.

Deviance Residuals

$$D_i = \text{sign}(y_i - \hat\pi_i)\sqrt{-2\big[y_i\log(\hat\pi_i) + (1-y_i)\log(1-\hat\pi_i)\big]}$$ Note: $D = \sum D_i^2$. Each $D_i^2$ measures one observation's contribution to the deviance statistic.
⚠ Crucial caveat: For binary data without replicates ($n_i=1$), neither $X^2 = \sum e_{P_i}^2$ nor $D = \sum D_i^2$ follows a chi-square distribution. The chi-square approximations only hold when there are replications ($n_i \to \infty$). Residual plots are used for pattern detection rather than formal inference.

Residual Plots

Plot residuals vs. the linear predictor $\hat\eta_i$ or estimated probabilities $\hat\pi_i$. A lowess smooth should be approximately horizontal at zero if the model is correct. A systematic curve indicates misspecification (e.g., a missing quadratic term).

11. Detection of Influential Observations

Even without residual patterns, individual observations can have outsized influence on the model. Three influence measures are used in logistic regression.

Δ Chi-Square ($\Delta X^2_i$)

Exact definition: $\Delta X^2_i = X^2 - X^2_{(i)}$ (change in Pearson statistic when case $i$ is deleted).
One-step approximation: $$\Delta X^2_i \approx e_{sP_i}^2$$

Δ Deviance ($\Delta D_i$)

Exact definition: $\Delta D_i = D - D_{(i)}$ (change in deviance when case $i$ is deleted).
One-step approximation: $$\Delta D_i \approx D_i^2 + \hat{h}_{ii}\, e_{sP_i}^2$$
These approximations avoid $n$ separate model refits. Large values of $\Delta X^2_i$ or $\Delta D_i$ — especially "spikes" when plotted against case number — flag influential observations.
⚠ Interpretation difficulty: No reference distribution exists for $\Delta X^2_i$ or $\Delta D_i$ — cut-offs must be determined subjectively by inspecting plots. Extreme values appear as spikes vs. case number, or outliers in upper corners of plots vs. the estimated linear predictor.
Donner Party findings: Cases 6, 26, 49, 55, 64, 68 appeared as spikes in both $\Delta X^2$ and $\Delta D$ plots for the main-effects model. In the quadratic model, cases 5, 6, 24 were most influential.

12. Cook's Distance for Logistic Regression

Cook's distance measures the influence of the $i$-th case on the fitted linear predictor (the logistic analogue of its role in linear regression, where it measures the change in fitted values).

One-step approximation: $$C_i = \frac{e_{P_i}^2\,\hat{h}_{ii}}{p\,(1-\hat{h}_{ii})^2}$$ where $p$ is the number of parameters in the linear predictor. Larger $C_i$ → more influential observation.
Unlike in linear regression, no universal threshold (like $C_i > 1$ or $C_i > 4/n$) is established for logistic regression. Plots of $C_i$ vs. case number are evaluated subjectively — look for observations that stand clearly apart from the bulk.

$D_i$Deviance residual (likelihood contribution)$\text{sign}(y_i-\hat\pi_i)\sqrt{-2[\cdots]}$

Practical summary from the lecture:
• Residuals and diagnostic tools are less informative for logistic than linear regression — individual 0/1 outcomes inherently limit residual variation.
• Influential observations are just as relevant conceptually, but harder to detect.
• If influential observations are found, understand why before deciding to remove or accommodate them.

Short Answer 1 · LD50 Inference
Explain what LD50 means, how it is derived from the logistic regression model, and compare the Wald (delta method), bootstrap, and profile likelihood approaches to constructing a 95% confidence interval for it. When would you prefer one over another?
Model Answer:
The LD50 (or EL50 in general pharmacology) is the dose $x$ at which exactly 50% of the population exhibits the response of interest. Under the logistic model $\text{logit}[\pi(x)] = \beta_0 + \beta_1 x$, setting $\pi = 0.5$ gives $\text{logit}(0.5) = 0$, so $0 = \beta_0 + \beta_1 \cdot LD_{50}$, yielding $LD_{50} = -\beta_0/\beta_1$. It also corresponds to the point of steepest slope on the sigmoid curve.

Inference: The MLE $\widehat{LD}_{50} = -\hat\beta_0/\hat\beta_1$ is nonlinear in the MLEs.
  • Wald / delta method: Approximate SE via $\text{Var}(g(\hat{\boldsymbol\beta})) \approx \nabla g^T \hat{V} \nabla g$. Fast and closed-form, but may be inaccurate for small samples or when the ratio $\beta_0/\beta_1$ is estimated with high uncertainty.
  • Profile likelihood CI: Inverts the LRT for $LD_{50}$ directly. More accurate than Wald, especially when the statistic's sampling distribution is skewed.
  • Bootstrap CI: Re-fits the model on $R$ resamples and uses the empirical distribution of $\widehat{LD}_{50}^*$. The basic (pivotal) CI is preferred when the bootstrap distribution is skewed (as seen in the animal experiment). No distributional assumptions on the nonlinear statistic are needed.
In the animal experiment, the bootstrap basic CI (4.216, 7.195) was wider than the Wald CI (3.91, 6.71), reflecting the right-skewed bootstrap distribution of $\widehat{LD}_{50}$.

Short Answer 2 · Sigmoidal Link Functions
Describe the latent variable framework that gives rise to different sigmoidal link functions. Why are logit and probit symmetric while cloglog and loglog are not? What are the practical consequences of choosing a symmetric vs. asymmetric link?
Model Answer:
Consider a latent continuous variable $\tilde{y}_i = -\mathbf{x}_i^T\boldsymbol\beta_c + \varepsilon_i$, and define $y_i = 1$ iff $\tilde{y}_i \leq 0$. Then $\pi_i = P(y_i=1|\mathbf{x}_i) = P(\varepsilon_i \leq \mathbf{x}_i^T\boldsymbol\beta_c) = F(\mathbf{x}_i^T\boldsymbol\beta_c)$, where $F$ is the CDF of $\varepsilon$.
  • Normal $F$ → Probit link (symmetric CDF)
  • Logistic $F$ → Logit link (symmetric CDF, heavier tails than normal)
  • Gumbel (extreme value) $F$ → Complementary log-log link (asymmetric)
  • Reversed Gumbel $F$ → Log-log link (asymmetric)
Symmetry: A link is symmetric if $F(z) = 1 - F(-z)$ (i.e., the CDF is symmetric around zero). Normal and logistic distributions have this property; Gumbel does not (it has a longer right tail). Symmetry implies that recoding $y'_i = 1 - y_i$ only reverses the signs of all coefficients — not the case for asymmetric links.

Practical consequences: If the true response curve approaches 0 and 1 at different rates (e.g., rapidly saturates at 1 but gradually rises from 0), a symmetric link will be misspecified. The cloglog is appropriate when small doses rarely cause the event but high doses almost certainly do (saturates quickly at 1). In practice, all four links often produce similar fitted curves in the middle range and differ mainly in the tails — where data are often sparse.

Short Answer 3 · Goodness-of-Fit Tests
Explain the Pearson chi-square and deviance GOF tests for logistic regression. Under what conditions are they valid? What is the connection between the deviance and the familiar log-likelihood ratio test?
Model Answer:
Both tests compare the fitted logistic model to the saturated model, which has one free parameter per distinct covariate pattern and achieves the maximum attainable log-likelihood $\ell(\tilde{\boldsymbol\pi})$.

Pearson $\chi^2$: $X^2 = \sum_{i=1}^N (y_i - n_i\hat\pi_i)^2 / [n_i\hat\pi_i(1-\hat\pi_i)]$. This is the standard GOF statistic, comparing observed to expected counts within each covariate group.

Deviance: $D = -2[\ell(\hat{\boldsymbol\pi}) - \ell(\tilde{\boldsymbol\pi})]$. This is explicitly a likelihood ratio test statistic. When the model is correct, the fitted model's log-likelihood $\ell(\hat{\boldsymbol\pi})$ should be close to the saturated model's $\ell(\tilde{\boldsymbol\pi})$, so $D$ should be small. Large $D$ indicates misspecification.

Both $X^2$ and $D$ have the same asymptotic null distribution: $\chi^2(N-p)$, under the conditions that $N$ is fixed and $n_i \to \infty$. This requires only categorical predictors. With continuous predictors, $N$ grows with $n$ and the chi-square approximation fails. The deviance generalises the SSE from linear regression; the null deviance generalises the total SS.

Short Answer 4 · Hosmer-Lemeshow Test
Describe the Hosmer-Lemeshow test in detail: how is it constructed, what is its null distribution, and what are its limitations? How did it guide model building in the Donner Party analysis?
Model Answer:
The HL test addresses the failure of the Pearson $\chi^2$ and deviance tests when predictors are continuous. Instead of grouping by covariate pattern (which is unique for each observation), it groups by estimated probabilities $\hat\pi_1,\ldots,\hat\pi_n$.

Construction: Divide observations into $g$ (usually 10) strata. Strategy 1 uses quantiles of $\hat\pi_i$ (preferred by simulation); Strategy 2 uses equal intervals $[0,1/g], (1/g, 2/g],\ldots$. Within each stratum $k$, compute observed counts $O_{k1}, O_{k0}$ and expected counts $E_{k1}=\sum \hat\pi_i$, $E_{k0}=\sum(1-\hat\pi_i)$. The test statistic is the usual $X^2$ on these $2g$ cells.

Null distribution: By simulation, $\hat{C} \xrightarrow{d} \chi^2(g-2)$ (losing 2 df). With $g=10$, this gives $\chi^2(8)$.

Limitations: Power depends on $g$; the test may miss localized departures. It should always be supplemented with residual plots.

Donner Party: The main effects model gave $\hat{C} = 16.01$, $p = 0.042$ — marginal evidence of misspecification. This prompted adding a quadratic age term and a gender-age interaction. The extended model gave $\hat{C} = 3.76$, $p = 0.878$ — excellent fit.

Short Answer 5 · Types of Residuals
Distinguish between Pearson, studentized Pearson, and deviance residuals in logistic regression. What is the relationship between each residual type and the corresponding GOF test statistic? When does each become uninformative?
Model Answer:
Pearson residuals: $e_{P_i} = (y_i - \hat\pi_i)/\sqrt{\hat\pi_i(1-\hat\pi_i)}$. Standardise the ordinary residual by the estimated SD of $y_i$. Their squares sum to $X^2$, the Pearson chi-square statistic. The problem is that $e_{P_i}$ uses $\hat\pi_i$ (an estimate) in the denominator, so its variance is not exactly 1.

Studentized Pearson: $e_{sP_i} = e_{P_i}/\sqrt{1-\hat{h}_{ii}}$. Divides by the estimated SD of the residual (not just of $y_i$), accounting for the fact that the fitted value $\hat\pi_i$ is estimated. With replications ($n_i$ large), $e_{sP_i} \approx N(0,1)$, so $|e_{sP_i}| > 2$ or $3$ is a useful diagnostic threshold.

Deviance residuals: $D_i = \text{sign}(y_i-\hat\pi_i)\sqrt{-2[y_i\log\hat\pi_i + (1-y_i)\log(1-\hat\pi_i)]}$. Their squares sum to the deviance $D$. They measure each observation's contribution to the LRT against the saturated model.

When uninformative: For binary data ($n_i=1$), each residual takes only two possible values (one if $y_i=1$, another if $y_i=0$), producing two parallel lines in plots. Neither $X^2$ nor $D$ follows a chi-square distribution in this case. Residual plots with a lowess smooth remain useful for detecting systematic patterns despite this limitation.

Short Answer 6 · Influence Diagnostics
Explain the concepts of $\Delta X^2_i$, $\Delta D_i$, and Cook's distance in logistic regression. How are they approximated in practice, and why is interpreting their magnitude difficult?
Model Answer:
These measures quantify how much the $i$-th observation changes key summaries of the analysis when it is deleted.

$\Delta X^2_i = X^2 - X^2_{(i)}$: Change in Pearson $\chi^2$. One-step approximation: $\approx e_{sP_i}^2$. Flags observations that disproportionately drive the overall Pearson GOF statistic.

$\Delta D_i = D - D_{(i)}$: Change in deviance. One-step approximation: $\approx D_i^2 + \hat{h}_{ii}e_{sP_i}^2$. Note it includes both the deviance residual squared and the leverage-weighted studentized residual — both high "misfit" and high "leverage" contribute.

Cook's distance: $C_i = e_{P_i}^2\hat{h}_{ii}/[p(1-\hat{h}_{ii})^2]$. Measures the standardised change in the fitted linear predictor. An observation requires both substantial misfit ($e_{P_i}^2$) and substantial leverage ($\hat{h}_{ii}$) to be truly influential.

Interpretive difficulty: No reference distribution exists for any of these measures. Unlike linear regression (where Cook's $D > 1$ or $4/n$ is sometimes used), no universal threshold applies in logistic regression. One must rely on graphical inspection — "spikes" versus case number or clusters in the upper corners of scatter plots.

Short Answer 7 · Bootstrap Methodology
Describe the bootstrap procedure for constructing a confidence interval for a nonlinear function of logistic regression parameters, such as LD50. Contrast the normal, basic, percentile, BCa, and studentized types. In which situations does each fail?
Model Answer:
Bootstrap generates an empirical sampling distribution of a statistic $T = t(\mathbf{y})$ by resampling with replacement from the observed data $R$ times. For LD50, each resample fits a logistic model and computes $T^*_r = -\hat\beta_{0,r}^*/\hat\beta_{1,r}^*$.

Normal CI: $\hat\theta \pm z_{\alpha/2}\widehat{\text{SE}}_{boot}$, bias-corrected. Fails if $T$ is non-normal (e.g., skewed).

Basic (pivotal) CI: $(2\hat\theta - T^*_{(1-\alpha/2)},\; 2\hat\theta - T^*_{(\alpha/2)})$. Reflects the bootstrap distribution without assuming normality. More robust to skewness than the percentile CI.

Percentile CI: $(T^*_{(\alpha/2)}, T^*_{(1-\alpha/2)})$. Directly takes the empirical quantiles. Intuitive but invalid when the bootstrap distribution is asymmetrically shifted relative to the true sampling distribution.

BCa: Adjusts for bias and skewness by selecting modified percentiles of the bootstrap distribution. Can be unstable when the bias-correction factor $\hat{z}_0$ pushes the required quantiles into the tails, where empirical estimates are noisy.

Studentized: Like the basic CI but uses a pivot standardised by a within-bootstrap SE estimate. Most accurate when the additional variance estimation is reliable; failing to provide the variance estimate triggers R's warning.

  • Is the bootstrap valid for any test statistic and sample size?
Short Answer 8 · The Deviance as a Generalisation
Explain how the deviance in logistic regression generalises the sum of squared errors (SSE) from linear regression. What is the null deviance and what does a large drop from null to residual deviance signify? How is this related to the AIC?
Model Answer:
In linear regression, the SSE measures how far the fitted values are from the observed values. The deviance $D = -2[\ell(\hat{\boldsymbol\pi}) - \ell(\tilde{\boldsymbol\pi})]$ plays the same role in logistic regression: it measures the discrepancy between the fitted model and the best possible fit (the saturated model). The connection is exact in linear regression with normal errors, where $-2$ times the log-likelihood difference equals the scaled SSE.

Null deviance $D_0$: The deviance when the model contains only an intercept (worst realistic model — every observation predicted to have the same probability $\bar{y}$). This is the logistic analogue of the total SS, measuring total variability in the response.

Large drop $D_0 - D$: A large reduction indicates the predictors explain substantial variation in $\pi$. This is also a LRT for the joint significance of all predictors: $D_0 - D \sim \chi^2(p-1)$ under $H_0$: all slope coefficients are zero.

AIC connection: $\text{AIC} = -2\ell(\hat{\boldsymbol\pi}) + 2p = D + 2p - 2\ell(\tilde{\boldsymbol\pi})$. Since $\ell(\tilde{\boldsymbol\pi})$ is the same for all models on the same dataset, minimising AIC is equivalent to minimising $D + 2p$ — balancing fit and complexity.

Short Answer 10 · Integrative / Critical Thinking
Critically evaluate the statement: "Once the Hosmer-Lemeshow test gives a non-significant p-value, the logistic regression model is adequate and no further diagnostics are needed." What are the limitations of this conclusion?
Model Answer:
The statement is an overreach. The HL test is a necessary but far from sufficient check on model adequacy. Several important limitations apply:

1. Power limitations: The HL test is a global summary — it averages over all $g$ groups. It may fail to detect localized departures that affect only a small number of groups or that cancel across groups.

2. Sensitivity to $g$: The test result can change substantially depending on the choice of number of groups $g$. A non-significant result with $g=10$ might become significant with $g=8$ or $g=12$.

3. Influence not addressed: A good HL p-value says nothing about whether individual influential observations are distorting the parameter estimates. Cook's distance and delta statistics can reveal problems the HL test entirely misses.

4. Functional form not tested: The HL test does not directly test whether the link function is appropriate, whether a predictor's effect is linear, or whether important interactions are missing.

5. Residual plots: Plots of deviance residuals against predictors can reveal systematic curvature or heteroscedasticity (in grouped data) that no summary statistic captures.

Recommendation: Use the HL test as one tool in a broader diagnostic toolkit that includes residual plots (deviance and Pearson, vs. linear predictor and vs. each covariate), influence measures ($\Delta X^2$, $\Delta D$, Cook's $D$), comparison of observed vs. predicted proportions in subgroups, and subject-matter reasoning.
