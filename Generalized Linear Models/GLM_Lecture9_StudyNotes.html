9.1  From Binary to Polytomous Responses

Standard logistic regression handles a binary response $y \in \{0,1\}$. When the outcome has $J > 2$ categories, we need an extension. Two fundamentally different situations arise:

Nominal response: No natural order among categories (e.g., disease subtype: A, B, C). Use Baseline-Category Logit (BCL) models.

Ordinal response: A natural ordering exists (e.g., well < mild < moderate < impaired). Use Cumulative logit or Adjacent-Category Logit (ACL) models to exploit the ordering.

Number of non-redundant logits

With $J$ categories, there are $J(J-1)/2$ possible pairwise log-odds, but only $J-1$ are non-redundant (the rest are linear combinations). All models below use exactly $J-1$ logits.

NominalBCL (baseline-category logit)Compare each category to a reference
OrdinalCumulative logit (proportional odds)Model $P(Y \le j)$ directly
OrdinalAdjacent-category logit (ACL)Compare adjacent categories locally

9.2  The Multinomial Distribution

All polytomous models are built on the multinomial likelihood. Suppose $n$ independent trials each produce one of $J$ categories with probabilities $\pi_1, \ldots, \pi_J$ (summing to 1). Then $\mathbf{y} = (y_1, \ldots, y_J)$ with $\sum y_j = n$ follows:

$$P(y_1=n_1, \ldots, y_J=n_J) = \frac{n!}{n_1!\cdots n_J!}\pi_1^{n_1}\cdots\pi_J^{n_J}$$ $$E(y_j)=n\pi_j, \quad \text{Var}(y_j)=n\pi_j(1-\pi_j), \quad \text{Cov}(y_i,y_j)=-n\pi_i\pi_j \; (i\neq j)$$

Likelihood function (polytomous regression)

With $N$ covariate patterns $\mathbf{x}_i$, the log-likelihood (after removing constants) is:

$$\ell(\boldsymbol\beta \mid \mathbf{y}_i, \mathbf{x}_i) = \sum_{i=1}^N \sum_{j=1}^J y_{ij}\ln[\pi_j(\mathbf{x}_i)]$$
All models discussed below have concave log-likelihoods; Newton–Raphson (Fisher scoring) yields unique MLEs.

Grouped vs. ungrouped data

In grouped data, several observations share the same covariate vector $\mathbf{x}_i$ (typical in designed experiments with categorical regressors). In ungrouped data, each $\mathbf{x}_i$ is unique (common when continuous covariates are present); then $n_i = 1$ and $y_{ki} \in \{0,1\}$.

9.3  Baseline-Category Logit (BCL) Model — Nominal Responses

Choose category $J$ as the reference (baseline). Model $J-1$ log-odds of each category vs. baseline:

BCL model: $$\ln\!\left[\frac{\pi_j(\mathbf{x})}{\pi_J(\mathbf{x})}\right] = \alpha_j + \mathbf{x}^T\boldsymbol\beta_j, \quad j=1,\ldots,J-1$$ with $\alpha_J = 0$, $\boldsymbol\beta_J = \mathbf{0}$ by convention. Each logit has its own parameter vector $(\alpha_j, \boldsymbol\beta_j)$.

Recovering category probabilities

$$\pi_j(\mathbf{x}) = \frac{e^{\alpha_j + \mathbf{x}^T\boldsymbol\beta_j}}{1 + \sum_{k=1}^{J-1}e^{\alpha_k + \mathbf{x}^T\boldsymbol\beta_k}}, \quad j=1,\ldots,J-1 \qquad \pi_J(\mathbf{x}) = \frac{1}{1+\sum_{k=1}^{J-1}e^{\alpha_k+\mathbf{x}^T\boldsymbol\beta_k}}$$

Interpretation of coefficients

$e^{\beta_{jm}}$ is the multiplicative effect of a 1-unit increase in $x_m$ on the odds of category $j$ vs. category $J$. Removing predictor $x_m$ simultaneously sets $J-1$ coefficients to zero — test with a likelihood-ratio test on $J-1$ df.

Invariance of the baseline choice

Any category can serve as baseline. Log-odds between any two non-baseline categories $a$ and $b$ are:

$$\ln\!\left[\frac{\pi_a(\mathbf{x})}{\pi_b(\mathbf{x})}\right] = (\alpha_a - \alpha_b) + \mathbf{x}^T(\boldsymbol\beta_a - \boldsymbol\beta_b)$$
Fitted values and likelihood are identical regardless of baseline. Only the parameterisation changes; differences $\alpha_a - \alpha_b$ and $\boldsymbol\beta_a - \boldsymbol\beta_b$ are invariant.

Mental Impairment Case Study (BCL)

Response: impair (1=well, 2=mild, 3=moderate, 4=impaired). Predictors: ses (SES, 0=low, 1=high) and life (life events index, continuous). Baseline = impaired (4). R package: VGAM::vglm(..., family=multinomial).

Fitted logit equations: $$\ln\!\left(\frac{\pi_1}{\pi_4}\right) = 1.90 + 1.61\cdot\text{ses\_high} - 0.56\cdot\text{life}$$ $$\ln\!\left(\frac{\pi_2}{\pi_4}\right) = 1.25 + 1.36\cdot\text{ses\_high} - 0.33\cdot\text{life}$$ $$\ln\!\left(\frac{\pi_3}{\pi_4}\right) = 1.24 - 0.34\cdot\text{ses\_high} - 0.27\cdot\text{life}$$
Key interpretation: Given a fixed number of life events, high-SES individuals have estimated odds of being well (vs. impaired) that are $e^{1.61} = 2.72$ times those of low-SES individuals. Each additional life event reduces the estimated odds of being well (vs. impaired) by $1-e^{-0.56} = 43\%$, adjusting for SES.

9.4  Ordinal Responses — Motivation

When categories have a natural order, BCL models can be used but waste information about ordering. Examples of ordinal responses:

  • Patient quality of life: excellent < good < fair < poor
  • Political philosophy: very liberal → very conservative
  • BMI category: underweight < normal < overweight < obese

Ordinal-specific models (cumulative, ACL) are typically more parsimonious and produce interpretable ordinal summaries.

9.5  Cumulative Logit Models

For ordered categories $1 < 2 < \cdots < J$, define cumulative probabilities:

$$P(y \le j) = \pi_1 + \pi_2 + \cdots + \pi_j$$ $$P(y=1) = P(y \le 1) \le P(y \le 2) \le \cdots \le P(y \le J) = 1$$

The cumulative logits are:

$$\text{logit}[P(y \le j \mid \mathbf{x})] = \ln\!\left[\frac{P(y \le j \mid \mathbf{x})}{P(y > j \mid \mathbf{x})}\right] = \ln\!\left[\frac{\pi_1 + \cdots + \pi_j}{\pi_{j+1} + \cdots + \pi_J}\right]$$

The cumulative logit model (proportional odds)

$$\text{logit}[P(y \le j \mid \mathbf{x})] = \alpha_j + \mathbf{x}^T\boldsymbol\beta, \quad j = 1, \ldots, J-1$$
  • Separate intercepts $\alpha_j$ for each cumulative logit (with $\alpha_1 \le \alpha_2 \le \cdots \le \alpha_{J-1}$).
  • Common slope $\boldsymbol\beta$: the effect of covariates does not depend on $j$.
  • Cumulative probability curves $P(y \le j \mid \mathbf{x})$ are parallel (never cross).

Estimating category probabilities

$$\pi_j(\mathbf{x}) = P(y \le j \mid \mathbf{x}) - P(y \le j-1 \mid \mathbf{x}) = \frac{e^{\alpha_j + \mathbf{x}^T\boldsymbol\beta}}{1+e^{\alpha_j + \mathbf{x}^T\boldsymbol\beta}} - \frac{e^{\alpha_{j-1}+\mathbf{x}^T\boldsymbol\beta}}{1+e^{\alpha_{j-1}+\mathbf{x}^T\boldsymbol\beta}}$$

These are plugged into the multinomial log-likelihood and maximised via Newton–Raphson.

9.6  Proportional Odds Property

The cumulative logit model with common slope $\boldsymbol\beta$ implies a remarkable property. For two covariate vectors $\mathbf{x}_1$ and $\mathbf{x}_2$:

$$\frac{\text{Odds}(y \le j \mid \mathbf{x}_1)}{\text{Odds}(y \le j \mid \mathbf{x}_2)} = e^{(\mathbf{x}_1-\mathbf{x}_2)^T\boldsymbol\beta}$$

The cumulative odds ratio is the same for all $j$ — hence "proportional odds." McCullagh (1980) coined this term.

The proportional odds assumption means a single number $e^{\boldsymbol\beta}$ summarises the effect of covariates across all cut-points simultaneously — powerful parsimony, but an assumption that should be checked.

Model selection framework

ModelSlopesParametersAssumption
Proportional odds (PO)Common $\boldsymbol\beta$$(J-1) + p$Parallel cumulative curves

Non-parallel (NPO)Separate $\boldsymbol\beta_j$$(J-1)(1+p)$None (most flexible)

Partial proportional odds (Peterson & Harrell 1990)

$$\text{logit}[P(y \le j \mid \mathbf{x}, \mathbf{z})] = \alpha_j + \mathbf{x}^T\boldsymbol\beta + \mathbf{z}^T\boldsymbol\gamma_j$$ Proportional odds holds for $\mathbf{x}$ but not for $\mathbf{z}$. Intermediate between PO and NPO.

Problems with non-parallel models

  • Parameters increase with $J$, making estimation harder.
  • Simpler (biased) models can have smaller MSE and better-powered tests.
  • With large $n$, almost any proportional-odds assumption will be rejected statistically.
  • NPO models may produce out-of-order cumulative probabilities.

9.7  Latent Variable Interpretation

The proportional odds model has an elegant motivation from a latent continuous variable $y^*$. Suppose:

$$y^* = -\mathbf{x}^T\boldsymbol\beta + \varepsilon, \quad \varepsilon \sim F \text{ (mean 0)}$$ $$y = j \iff \alpha_{j-1} < y^* \le \alpha_j \quad (\alpha_0 = -\infty,\; \alpha_J = +\infty)$$

Then $P(y \le j \mid \mathbf{x}) = P(y^* \le \alpha_j \mid \mathbf{x}) = F(\alpha_j + \mathbf{x}^T\boldsymbol\beta)$.

For the logistic distribution ($F(\varepsilon) = e^\varepsilon/(1+e^\varepsilon)$) this gives the cumulative logit model. For the normal distribution, it gives the cumulative probit model.

Invariance of $\boldsymbol\beta$: The same covariate effect parameters appear regardless of how the cut-points $\alpha_j$ divide the latent scale — i.e., the effect estimates are invariant to the choice of response categories. This allows comparison across studies using different scales.

Sign flip: To interpret $\boldsymbol\beta$ in terms of the latent regression (effect on $y^*$), use $-\boldsymbol\beta$ (since the latent model has $-\mathbf{x}^T\boldsymbol\beta$).

Latent ordinal superiority $\gamma$

For a binary covariate $x_1 \in \{0,1\}$ with coefficient $\beta_1$, the ordinal superiority is:

$$\gamma = P(y^*_0 < y^*_1) \approx \frac{e^{-\beta_1/\sqrt{2}}}{1+e^{-\beta_1/\sqrt{2}}} \quad \text{(latent logistic)}$$

For SES in the mental impairment study: $-\beta_1 = -1.11 \Rightarrow \hat\gamma = 0.313$, CI = (0.16, 0.51). A randomly selected low-SES person has latent impairment score exceeding that of a random high-SES person with probability 0.313.

Latent $R^2$

$$R^2_L = \frac{\sum_i(\hat y^*_i - \bar y^*)^2}{\sum_i(y^*_i - \bar y^*)^2} \approx \frac{\text{Var}(\hat y^*)}{\text{Var}(\hat y^*) + \pi^2/3}$$

The denominator adds $\pi^2/3 \approx 3.29$ (variance of standard logistic distribution). For mental impairment: $R^2_L = 0.224$.

9.8  Adjacent-Category Logit (ACL) Model

Instead of cumulating probabilities, model the log-odds of adjacent categories directly:

$$\text{logit}\!\left[\frac{P(y=j \mid \mathbf{x})}{P(y=j+1 \mid \mathbf{x})}\right] = \ln\!\left(\frac{\pi_j}{\pi_{j+1}}\right) = \alpha_j + \mathbf{x}^T\boldsymbol\beta, \quad j=1,\ldots,J-1$$ With proportional odds structure: same $\boldsymbol\beta$ for all $j$ (separate $\alpha_j$).

Theoretical justification (Anderson 1984)

If $(\mathbf{x} \mid y=j) \sim \mathcal{N}(\boldsymbol\mu_j, \Sigma)$, then ACL holds with $\boldsymbol\beta_j = \Sigma^{-1}(\boldsymbol\mu_j - \boldsymbol\mu_{j+1})$. Equally-spaced means give proportional odds structure (same effect for each logit).

Properties

  • ACL $\Rightarrow$ baseline-category logits: $\ln(\pi_j/\pi_k) = \sum_{s=j}^{k-1}\alpha_s + (k-j)\mathbf{x}^T\boldsymbol\beta$
  • Effects are estimable in case-control (retrospective) studies — unlike cumulative logit models.
  • No structural crossing problem (unlike NPO cumulative logit).
  • Loses the latent-variable interpretation of cumulative models.

9.9  Extensions: Clustered & Multivariate Data

Marginal models (GEE): Generalized Estimating Equations extend to ordinal responses via cumulative logit or ACL models. R: multgee::ordLORgee() using local odds ratios for working association structure.
Random effects models: Mixed ordinal logit models include subject-level random effects to handle clustering/repeated measures. R: ordinal::clmm() for cumulative logit with random effects.

Short Answer 1 · Foundations
Explain why, with $J$ response categories, we need only $J-1$ non-redundant logits. How does this principle appear differently in BCL and cumulative logit models?
Model Answer:
With $J$ categories, all probabilities are determined by $J-1$ of them (since $\sum_j \pi_j = 1$). Any $J$th probability is the complement of the sum of the others. Thus, only $J-1$ logits (log-odds) are mathematically independent — any additional logit is a linear combination of the others.

In the BCL model, redundancy is handled by fixing the baseline category ($\alpha_J=0$, $\boldsymbol\beta_J=\mathbf{0}$) and modelling $J-1$ logits $\ln(\pi_j/\pi_J)$ each with its own parameter vector — a total of $(J-1)(1+p)$ parameters for $p$ predictors.

In the cumulative logit model, the $J-1$ non-redundant quantities are the cumulative logits $\text{logit}[P(y \le j)]$ for $j=1,\ldots,J-1$ — these also fully determine the distribution. The proportional odds constraint then reduces parameters to $(J-1) + p$ total by sharing a common slope $\boldsymbol\beta$ across all $j$.

Short Answer 2 · Proportional Odds
Derive and explain the "proportional odds" property of the cumulative logit model. Under what circumstances does this assumption fail, and how can you detect and handle violations?
Model Answer:
Derivation: The model states $\text{logit}[P(y \le j|\mathbf{x})] = \alpha_j + \mathbf{x}^T\boldsymbol\beta$. For two covariate vectors $\mathbf{x}_1$, $\mathbf{x}_2$: the log cumulative odds ratio is $\alpha_j + \mathbf{x}_1^T\boldsymbol\beta - \alpha_j - \mathbf{x}_2^T\boldsymbol\beta = (\mathbf{x}_1-\mathbf{x}_2)^T\boldsymbol\beta$. This is identical for all $j$ — hence the cumulative odds ratio $e^{(\mathbf{x}_1-\mathbf{x}_2)^T\boldsymbol\beta}$ is proportional to the "distance" $\mathbf{x}_1-\mathbf{x}_2$ with the same proportionality constant regardless of cut-point $j$.

When it fails: When the covariate effect genuinely differs across cut-points (e.g., religious region effects reverse between $P(y \le 1)$ and $P(y \le 2)$ for fundamentalism data). Also fails with substantial dispersion effects (covariate affects variance of latent $y^*$, not just mean).

Detection: (1) LRT comparing PO and NPO models; (2) AIC/AICc comparison; (3) Graphical check: plot observed proportions against predicted cumulative probabilities for each logit. (4) Inspect coefficients of NPO model for pattern.

Handling: Use partial PO (Peterson & Harrell 1990) for covariates violating the assumption while keeping PO for others; or use the NPO model, accepting the parameter burden; or consider ACL as an alternative formulation.

Short Answer 3 · Latent Variable
Explain the latent variable motivation for the proportional odds model. What is the practical implication of parameter invariance with respect to category choices?
Model Answer:
Suppose an unobserved (latent) continuous variable $y^* = -\mathbf{x}^T\boldsymbol\beta + \varepsilon$ underlies the ordinal response, where $\varepsilon \sim \text{Logistic}(0,1)$. The observed $y$ is determined by which interval $(\alpha_{j-1}, \alpha_j]$ contains $y^*$.

Then $P(y \le j|\mathbf{x}) = P(y^* \le \alpha_j|\mathbf{x}) = F(\alpha_j + \mathbf{x}^T\boldsymbol\beta)$ where $F$ is the logistic CDF — exactly the cumulative logit model.

Parameter invariance: Crucially, the same $\boldsymbol\beta$ appears regardless of how the $\alpha_j$ cut-points are placed. This means the covariate effect estimates are invariant to the choice of response categories. Practically, two studies using different ordinal scales (e.g., 3-point vs. 5-point Likert) will produce comparable $\hat{\boldsymbol\beta}$ estimates that can be meta-analysed or compared directly — a powerful advantage for evidence synthesis.

Sign convention: Since the latent model has $-\mathbf{x}^T\boldsymbol\beta$, to interpret $\boldsymbol\beta$ in the latent direction (effect on $y^*$), reverse the sign: the latent effect of $x_m$ on $y^*$ is $-\beta_m$.

Short Answer 4 · BCL Interpretation
In the mental impairment BCL model, the coefficient for life in the well-vs-impaired logit is $-0.560$. Provide a precise interpretation. How does this compare to the SES effect, and why should these not be directly compared in magnitude?
Model Answer:
$e^{-0.560} = 0.571$, so each additional life event multiplies the estimated odds of being well (vs. impaired) by 0.571, holding SES constant. Equivalently, each additional life event reduces the well-vs-impaired odds by approximately $43\%$ ($1 - e^{-0.560} = 0.429$).

The SES coefficient is $1.606$: high-SES individuals have odds of being well (vs. impaired) that are $e^{1.606} = 4.98$ times those of low-SES individuals, at the same life events level.

Why not directly compare magnitudes: Life is a continuous variable (index score) and SES is binary (0/1). A 1-unit change in life events may be clinically very different from the entire shift between low and high SES. Direct comparison requires standardisation (e.g., per SD increase) or expressing both in terms of clinically meaningful quantities. Additionally, the coefficients are on different logit scales (well vs. impaired only) and do not directly measure overall association.

Short Answer 5 · BCL vs Cumulative Logit
Compare and contrast the BCL and cumulative logit (proportional odds) models in terms of: (a) the type of odds ratio each provides, (b) parsimony, (c) use cases, and (d) identifiability in case-control studies.
Model Answer:
(a) Odds ratios: BCL provides odds ratios comparing each category to the reference (e.g., well vs. impaired). Cumulative logit provides cumulative odds ratios: odds of being in categories $\le j$ vs. $> j$. The cumulative OR has the same value for all $j$ under proportional odds — a single number summarises the entire ordinal response. BCL requires $J-1$ separate ORs per predictor.

(b) Parsimony: The proportional odds model has $(J-1) + p$ parameters; BCL has $(J-1)(1+p)$. For $J=4$, $p=2$: PO has 5 parameters, BCL has 9. PO is substantially more parsimonious when the proportional odds assumption holds.

(c) Use cases: BCL is appropriate for nominal responses or ordinal responses where the proportional odds assumption is implausible. Cumulative logit is ideal for ordinal responses with a latent-variable motivation; it uses the ordering and yields a single interpretable OR. ACL is preferred when retrospective sampling occurs or when local (adjacent-pair) effects are of primary interest.

(d) Case-control identifiability: Cumulative logit models are not identifiable with case-control (retrospective) data because the sampling distribution of $\mathbf{x}$ is conditional on $y$, which invalidates the cumulative logit parameterisation. BCL and ACL models are identifiable in retrospective designs (by analogy with binary logistic regression in case-control settings).

Short Answer 6 · Adjacent-Category Logit
Explain the theoretical justification for the ACL model proposed by Anderson (1984). Under what distributional assumption does the proportional-odds ACL model arise naturally?
Model Answer:
Anderson (1984) showed that if $(\mathbf{x} \mid y=j) \sim \mathcal{N}(\boldsymbol\mu_j, \Sigma)$ — i.e., within each category the covariates are multivariate normal with the same covariance matrix $\Sigma$ but different means $\boldsymbol\mu_j$ — then by Bayes' theorem:

$$\ln\!\left(\frac{\pi_j}{\pi_{j+1}}\right) = \alpha_j + \mathbf{x}^T\boldsymbol\beta_j, \quad \boldsymbol\beta_j = \Sigma^{-1}(\boldsymbol\mu_j - \boldsymbol\mu_{j+1})$$

If the category means are equally spaced, i.e., $\boldsymbol\mu_j - \boldsymbol\mu_{j+1} = \boldsymbol\delta$ for all $j$, then $\boldsymbol\beta_j = \Sigma^{-1}\boldsymbol\delta = \boldsymbol\beta$ is constant — yielding the proportional-odds ACL model with the same $\boldsymbol\beta$ for all adjacent logits.

This is the linear discriminant analysis (LDA) model applied in reverse. The ACL model is thus the natural model when a multivariate normal with equal covariances underlies the categories. This gives it a strong theoretical foundation and suggests it will work well when this Gaussian mixture assumption approximately holds. It contrasts with the latent-variable motivation for cumulative logit, where a single continuous $y^*$ is discretised.

Short Answer 7 · Model Assessment
How would you assess the fit of a BCL model in R? Walk through the steps taken in the mental impairment example, and explain what each diagnostic tells you.
Model Answer:
Step 1 — Obtain predicted probabilities: Use predict(menim.mod1, type="response") to get $\hat\pi_j(\mathbf{x}_i)$ for each observation, then aggregate over covariate groups using aggregate(..., FUN=sum) to get expected cell counts.

Step 2 — Chi-squared goodness-of-fit test: Compare observed vs. expected cell counts via $X^2 = \sum (\text{obs}-\text{exp})^2/\text{exp}$. For mental impairment: $X^2 = 2.22$, df = 7 (= 16 cells − 9 BCL parameters), p = 0.947. A non-significant result indicates adequate fit.

Step 3 — Analysis of Deviance (Type III): anova(menim.mod1, type='III') tests each predictor's contribution. For life events: Deviance = 8.59, df = 3, p = 0.035 (significant); for ses: Deviance = 5.12, df = 3, p = 0.163 (non-significant). This suggests life events is the more important predictor.

Step 4 — Residual deviance on model output: Residual deviance = 96.70 on 111 df. If this were substantial relative to df, it would signal lack of fit, but here it is acceptable.

Caveats: The chi-squared test requires adequate expected cell counts (typically ≥ 5). With sparse cells or continuous predictors, the goodness-of-fit test may not be reliable.

Short Answer 8 · Religious Fundamentalism
In the religious fundamentalism example, the proportional odds model fits poorly (residual deviance 98.02 on 3 df). Explain what "dispersion effects" are and how they manifest in this dataset.
Model Answer:
Dispersion effects occur when a covariate affects not just the mean (location) of the latent response distribution but also its spread (variance). In the proportional odds model (which implicitly assumes a common-variance latent distribution), only location shifts are modelled. When dispersion differs, the proportional odds assumption fails.

In this data: Northeast residents show $P(y=1) = 14\%$ and $P(y=3) = 34\%$ (bimodal-ish spread), while West/Mountain shows $P(y=1) = 20\%$ and $P(y=3) = 37\%$. Crucially, the ordering of Northeast vs. West/Mountain reverses between $P(y \le 1)$ (NE lower) and $P(y \le 2)$ (NE higher). This reversal cannot be accommodated by a single shift $\beta_\text{NE}$ — it implies that Northeast residents are less concentrated at the extremes (fundamentalist or liberal) and more concentrated in the middle (moderate) category. In other words, Northeast has less dispersion in beliefs than West/Mountain.

The NPO model resolves this by allowing $\hat\beta_\text{NE}^{(1)} = -0.452$ (NE less likely to be fundamentalist vs. others) and $\hat\beta_\text{NE}^{(2)} = 0.091$ (NE slightly more likely to be fundamentalist or moderate vs. others) — a pattern consistent with reduced dispersion around the center.

Short Answer 10 · Study Design & Model Choice
A clinical trialist collects pain severity (none/mild/moderate/severe) at baseline and at 3 months for 200 patients randomised to treatment or placebo. Which polytomous model(s) would you recommend, and what complications arise from the study design?
Model Answer:
Response structure: Pain severity is ordinal (none < mild < moderate < severe), so ordinal models are appropriate. BCL ignores the ordering — use only as a robustness check.

Primary model: The cumulative proportional odds logit model is the natural choice. It provides a single odds ratio for treatment effect on pain severity, interpretable via the latent variable framework (treatment shifts the latent pain distribution by $-\beta_\text{trt}$). Include baseline pain as a covariate for efficiency.

Design complication — repeated measures: The same patients are measured at two time points; their observations are correlated. Standard models assume independence.
  • GEE approach: multgee::ordLORgee() fits marginal cumulative logit models using GEE, with local odds ratios to specify working correlation. Provides population-average (marginal) effect of treatment.
  • Random effects approach: ordinal::clmm() adds a patient-level random effect to the cumulative logit model. Provides subject-specific (conditional) treatment effect — more appropriate for prediction of individual trajectories.
Check proportional odds: Test treatment × time interaction on each logit separately. With only 3 cut-points and a relatively small sample, the test may be underpowered; assess substantive importance of violations.

Additional consideration: Since this is a randomised trial (prospective, not case-control), cumulative logit is identifiable. ACL is also valid but gives local rather than global treatment effect summaries.
