1. The Poisson Distribution

The Poisson distribution is the workhorse for modelling count data — the number of times an event occurs in a fixed interval of time or space.

Definition: A discrete random variable $y$ follows a Poisson distribution with parameter $\lambda > 0$, written $y \sim \text{Poisson}(\lambda)$, if: $$P(y = k) = \frac{e^{-\lambda}\lambda^k}{k!}, \quad k = 0, 1, 2, \ldots$$ Key property: $E(y) = \text{Var}(y) = \lambda$ — mean equals variance.

Conditions for a Poisson Process

The Poisson distribution arises naturally from a counting process satisfying three axioms: (1) the expected number of events in any interval is proportional to the interval's length; (2) the probability of two or more simultaneous events in an infinitesimally small interval is zero; (3) events in non-overlapping intervals are independent.

Law of Rare Events (Poisson Limit Theorem)

If $y_n \sim \text{Bin}(n, p_n)$ and $np_n \to \lambda$ as $n \to \infty$, then: $$\lim_{n\to\infty} P(y_n = k) = \frac{e^{-\lambda}\lambda^k}{k!}$$ This justifies the Poisson distribution as the limiting case of the binomial when events are rare ($p$ small) and trials are many ($n$ large).
Why Poisson and not OLS for counts? OLS allows negative predictions and assumes constant variance — both impossible for counts. The Poisson model enforces $\lambda > 0$ via the log link and naturally links variance to the mean.

2. The Poisson Regression Model (Log-Linear Model)

Like logistic regression, the Poisson model has two parts:

Systematic part (log-linear): $$\ln(\lambda) = \ln\!\left[E(y \mid \mathbf{x})\right] = \mathbf{x}^T\boldsymbol\beta = \beta_0 + \beta_1 x_1 + \cdots + \beta_{p-1}x_{p-1}$$ Equivalently, the response function is: $$\lambda = \mu(\mathbf{x}, \boldsymbol\beta) = e^{\mathbf{x}^T\boldsymbol\beta}$$ Distribution part: $y \sim \text{Poisson}(\lambda)$

The log link is the canonical link for the Poisson family. It ensures $\lambda > 0$ for all real-valued linear predictors — solving the impossible-values problem that would arise with a linear model.

R syntax: glm(y ~ x1 + x2, family = poisson(link = "log"))
For rate models with exposure: glm(y ~ offset(log(n)) + x1 + x2, family = poisson(link = "log"))

Hessian Matrix and Information

The Hessian of the log-likelihood is: $$\frac{\partial^2 \ell(\boldsymbol\beta \mid \mathbf{X}, \mathbf{y})}{\partial\boldsymbol\beta\,\partial\boldsymbol\beta^T} = -\mathbf{X}^T\mathbf{V}\mathbf{X}$$ where $\mathbf{V} = \text{diag}(e^{\mathbf{x}_1^T\boldsymbol\beta}, \ldots, e^{\mathbf{x}_N^T\boldsymbol\beta})$. Critically, $\mathbf{V}$ does not depend on $\mathbf{y}$, so the observed and expected information matrices are equal: $\mathbf{I}(\boldsymbol\beta) = \mathbf{H}(\boldsymbol\beta)$. This is a special property of GLMs using their canonical link.

3. Interpreting Poisson Regression Coefficients

The exponentiated coefficients $e^{\hat\beta_j}$ are called Relative Risks (RR) or Rate Ratios.
  • $e^{\hat\beta_0}$: Expected count when all covariates = 0
  • $e^{\hat\beta_j}$ for continuous $x_j$: A 1-unit increase in $x_j$ multiplies the expected count by $e^{\hat\beta_j}$, holding others fixed
  • $e^{\hat\beta_j}$ for binary/categorical $x_j$: The expected count in group $x_j=1$ is $e^{\hat\beta_j}$ times the expected count in the reference group, holding others fixed

4. Maximum Likelihood Estimation

Given $N$ pairs $(y_i, \mathbf{x}_i)$, the likelihood and log-likelihood are:

$$L(\boldsymbol\beta \mid \mathbf{X}, \mathbf{y}) = \prod_{i=1}^N \frac{e^{y_i\mathbf{x}_i^T\boldsymbol\beta} e^{-e^{\mathbf{x}_i^T\boldsymbol\beta}}}{y_i!}$$ $$\ell(\boldsymbol\beta \mid \mathbf{X}, \mathbf{y}) = \sum_{i=1}^N \left(y_i\mathbf{x}_i^T\boldsymbol\beta - e^{\mathbf{x}_i^T\boldsymbol\beta} - \log(y_i!)\right) \propto \sum_{i=1}^N \left(y_i\mathbf{x}_i^T\boldsymbol\beta - e^{\mathbf{x}_i^T\boldsymbol\beta}\right)$$

The score equations are $\frac{\partial\ell}{\partial\boldsymbol\beta} = \mathbf{X}^T(\mathbf{y} - \boldsymbol\mu) = \mathbf{0}$, where $\boldsymbol\mu = (e^{\mathbf{x}_i^T\boldsymbol\beta})^T$. These have no closed-form solution. However, the negative log-likelihood $-\ell(\boldsymbol\beta)$ is a convex function, guaranteeing a unique global maximum found via standard convex optimization (IWLS).

Contrast with logistic regression: In logistic regression, the Hessian depends on $\mathbf{y}$ through $\hat\pi_i(1-\hat\pi_i)$, so observed ≠ expected information in general. In Poisson with log link (canonical), $\mathbf{V} = \text{diag}(e^{\mathbf{x}_i^T\boldsymbol\beta})$ does not depend on $\mathbf{y}$, so $\mathbf{I}(\boldsymbol\beta) = -\mathbf{H}(\boldsymbol\beta)$ exactly. This is a property shared by all GLMs using their canonical link.

5. Exposure and Offset

Count data often involves varying observation windows — e.g., different population sizes, follow-up times, or area sizes. Six cases over one year is very different from six cases over ten years. When modelling rates rather than raw counts, we use an offset.

Rate model: $$\ln\!\left(\frac{E(y \mid \mathbf{x})}{\text{exposure}}\right) = \mathbf{x}^T\boldsymbol\beta$$ This implies: $$\ln(E(y \mid \mathbf{x})) = \ln(\text{exposure}) + \mathbf{x}^T\boldsymbol\beta$$ The term $\ln(\text{exposure})$ is called the offset — a predictor whose coefficient is constrained to 1. It is not estimated but rather fixed as part of the model structure.
Skin Cancer Study: Cities have vastly different population sizes (e.g., Minneapolis 15–24: 172,675 vs Dallas 85+: 7,583). Without the offset, we would be comparing raw counts, not rates. The offset log(n) converts the model to a per-capita rate model:

glm(cases ~ city + age.range + offset(log(n)), family = poisson(link = "log"), data = nonmel)

The intercept then represents the log rate for the reference group (85+ in Minneapolis): $e^{-5.4834} = 0.00415$ cases per person — i.e., ~4.15 per 1,000 persons in the oldest Minneapolis group.
Prediction with offset: To predict per-person rates, set n = 1 in the new data. To predict per-1,000, set n = 1000. The predicted count for the actual population uses the observed n. All three quantities are obtained by manipulating the offset — the coefficient vector $\hat{\boldsymbol\beta}$ is the same.

6. Goodness-of-Fit and Residuals

Pearson and Deviance Tests

Both the Pearson $\chi^2$ and deviance test assess overall model fit for Poisson models, analogously to logistic regression:

$$X^2 = \sum_{i=1}^N \frac{(y_i - \hat\mu_i)^2}{\hat\mu_i} \sim \chi^2_{N-p} \qquad \text{Deviance} = 2\sum_{i=1}^N y_i\ln\!\left(\frac{y_i}{\hat\mu_i}\right) \sim \chi^2_{N-p}$$
Skin Cancer Study GOF: 
Pearson X²  = 8.127, df = 7, p-value = 0.321
Deviance    = 8.259, df = 7, p-value = 0.310
Both tests fail to reject the null (p > 0.05), indicating the model with city + age.range fits the data well. Note that the Hosmer-Lemeshow test is not applicable here — it was developed specifically for logistic regression.

DHARMa Residuals (Simulation-Based)

Interpreting standard residuals in GLMs is difficult because the response is discrete. The DHARMa package provides simulation-based "scaled residuals" that are always uniform on [0,1] if the model is correct — regardless of the distributional family.

Algorithm:
  1. For each observation $i$, simulate $n_{\text{sim}}$ responses $\tilde{y}_{i1}, \ldots, \tilde{y}_{in}$ from the fitted model (using the estimated $\hat\lambda_i$).
  2. Compute the empirical CDF $\hat{F}_i$ of the simulated values.
  3. The DHARMa residual is $r_i = \hat{F}_i(y_i^{\text{obs}})$ — the quantile of the observed value within the simulated distribution.
Interpretation: $r_i = 0$ means all simulated values exceed the observed; $r_i = 0.5$ means the observed is at the median of the simulated distribution. Under a correctly specified model, $r_i \sim \text{Uniform}(0,1)$.
DHARMa diagnostics for the Publications model:
— testUniformity: KS test $D = 0.108$, $p = 1.31 \times 10^{-9}$ → residuals significantly non-uniform → model misfits
— testDispersion: ratioObsSim = 1.415, $p < 2.2 \times 10^{-16}$ → significant overdispersion
— The rootogram shows the Poisson model systematically underpredicts zeros and overpredicts mid-range counts.
⚠ Outliers in DHARMa: Observations with residuals exactly 0 or 1 are outside the simulation envelope. The probability of being classified as an outlier depends on $n_{\text{sim}}$ (default 250). Increasing to 1000 stabilizes results.

7. Overdispersion

The Poisson model imposes $\text{Var}(y \mid \mathbf{x}) = E(y \mid \mathbf{x}) = \lambda$. In practice, real count data often exhibit overdispersion: $\text{Var}(y \mid \mathbf{x}) > E(y \mid \mathbf{x})$.

Publications data: Unadjusted sample variance $\text{Var}(y) = 3.710 > 1.693 = E(y)$. The variance is more than twice the mean — clear overdispersion. Consequence: the standard Poisson model underestimates standard errors, producing artificially small $p$-values and inflated Type I error.

8. Sandwich (Robust) Variance Estimator

The sandwich estimator is motivated by the theory of misspecified models. If the true data-generating process is $g(y \mid \mathbf{z}, \boldsymbol\gamma_0)$ but we fit $p(y \mid \mathbf{x}, \boldsymbol\theta)$, the MLE converges to $\boldsymbol\theta^*$ that minimises the Kullback-Leibler divergence:

$$I(f:g,\boldsymbol\theta) = E_g\!\left[\log\frac{g(y \mid \mathbf{z},\boldsymbol\gamma_0)}{p(y \mid \mathbf{x},\boldsymbol\theta)}\right]$$

Asymptotically: $\sqrt{n}(\hat{\boldsymbol\theta}_{\text{MLE}} - \boldsymbol\theta^*) \xrightarrow{d} \mathcal{N}(\mathbf{0}, \mathbf{C}(\boldsymbol\theta^*))$ where the sandwich covariance is:

$$\mathbf{C}(\boldsymbol\theta^*) = \mathbf{A}^{-1}(\boldsymbol\theta^*)\,\mathbf{B}(\boldsymbol\theta^*)\,\mathbf{A}^{-1}(\boldsymbol\theta^*)$$ $\mathbf{A}$: expected Hessian (the "bread"); $\mathbf{B}$: outer product of scores (the "meat").
Key result for log-linear Poisson models: If the mean structure $\ln(\lambda) = \mathbf{x}^T\boldsymbol\beta_0$ is correctly specified, the MLE converges to the true $\boldsymbol\beta_0$ even when the variance is misspecified (e.g., overdispersion exists). The sandwich estimator then provides asymptotically valid inference for $\boldsymbol\beta_0$.

9. Quasi-Likelihood (Quasi-Poisson)

Quasi-likelihood models relax the full distributional specification. Instead of assuming $y \sim \text{Poisson}(\lambda)$, we only specify the mean and variance functions separately:

Poisson Overdispersion Scale Model: $$E(y_i \mid \mathbf{x}_i) = \lambda = e^{\mathbf{x}_i^T\boldsymbol\beta} \qquad \text{(mean structure — must be correct)}$$ $$\text{Var}(y_i \mid \mathbf{x}_i) = \phi\lambda \qquad \text{(variance structure — linear in mean)}$$ The quasi-MLE for $\boldsymbol\beta$ solves the same score equations as standard Poisson — producing identical point estimates. The dispersion parameter $\hat\phi$ is estimated from the Pearson statistic: $\hat\phi = X^2 / (N - p)$.
Why are estimates identical but SEs different?
The score equations $\mathbf{X}^T(\mathbf{y} - \boldsymbol\mu) = \mathbf{0}$ do not depend on $\phi$ — so the quasi-ML estimator of $\boldsymbol\beta$ is the same as the Poisson MLE. However, the estimated covariance matrix is $\hat\phi(\mathbf{X}^T\hat{\mathbf{V}}\mathbf{X})^{-1}$, so all SEs are inflated by $\sqrt{\hat\phi}$.
Publications data — quasi-Poisson: Dispersion parameter $\hat\phi = 1.829$, so SEs are multiplied by $\sqrt{1.829} \approx 1.352$ (≈35% larger). Estimates unchanged. AIC is reported as NA because quasi-likelihood does not have a proper likelihood function. The test statistic changes from $z$ (Poisson) to $t$ (quasi-Poisson) because $\phi$ is estimated.
⚠ Quasi-Poisson vs Negative Binomial variance functions:
Quasi-Poisson: $\text{Var}(y) = \phi\lambda$ — linear in the mean
Negative Binomial: $\text{Var}(y) = \mu + \frac{1}{\theta}\mu^2$ — quadratic in the mean
For the publications data, the mean-variance plot shows the NB quadratic relationship fits better at high means, suggesting NB is more appropriate than quasi-Poisson.

10. Negative Binomial Regression

Derivation as a Poisson-Gamma Mixture

Assume $y \mid \lambda \sim \text{Poisson}(\lambda)$ with $\lambda = \lambda^* e^{\mathbf{x}^T\boldsymbol\beta}$ and $\lambda^* \sim \text{Gamma}(\theta, \theta)$.

Note: $E(\lambda^*) = 1$, $\text{Var}(\lambda^*) = 1/\theta$. By the laws of total expectation and total variance: $$E(y) = \mu = e^{\mathbf{x}^T\boldsymbol\beta}$$ $$\text{Var}(y) = E[\text{Var}(y\mid\lambda)] + \text{Var}[E(y\mid\lambda)] = \mu + \frac{1}{\theta}\mu^2$$ Marginalising over $\lambda$ gives the Negative Binomial distribution: $$p(y \mid \theta) = \frac{\Gamma(\theta+y)}{\Gamma(\theta)\,y!}\left(\frac{\theta}{\theta+e^{-\mathbf{x}^T\boldsymbol\beta}}\right)^\theta\left(\frac{e^{-\mathbf{x}^T\boldsymbol\beta}}{\theta+e^{-\mathbf{x}^T\boldsymbol\beta}}\right)^y$$

The parameter $\theta$ (also written $1/\alpha$ in some software) controls the degree of extra-Poisson variation. As $\theta \to \infty$, $\text{Var}(y) \to \mu$ and the NB converges to Poisson.

11. Zero-Inflated Poisson (ZIP) Models

A frequent pattern with count data is excess zeros beyond what any standard count distribution predicts. In the publications data, 30.0% of scientists published zero articles, but the Poisson model predicts only 20.9% — a 9-percentage-point discrepancy.

The ZIP Mixture Model

The ZIP density mixes a point mass at zero with a Poisson count distribution: $$f_{\text{ZIP}}(y; \mathbf{x}, \mathbf{z}, \boldsymbol\beta, \boldsymbol\gamma) = f_{\text{zero}}(0; \mathbf{z}, \boldsymbol\gamma)\cdot\mathbf{1}_{[y=0]} + [1 - f_{\text{zero}}(0; \mathbf{z}, \boldsymbol\gamma)]\cdot f_{\text{Poisson}}(y; \mathbf{x}, \boldsymbol\beta)$$ where $\pi = f_{\text{zero}}(0; \mathbf{z}, \boldsymbol\gamma) = g^{-1}(\mathbf{z}^T\boldsymbol\gamma)$ (modelled via a logistic regression).

The mean is: $\mu = \pi \cdot 0 + (1-\pi)\cdot e^{\mathbf{x}^T\boldsymbol\beta} = (1-\pi)e^{\mathbf{x}^T\boldsymbol\beta}$

The model has two separate components: the count component (who is in the Poisson group and how many events they have) and the zero-inflation component (probability of being a "structural zero"). The regressors $\mathbf{z}$ and $\mathbf{x}$ need not be the same.

Summary of the Publications Study

Under the Negative Binomial model, the significant predictors are: ment (mentor's publications, RR = $e^{0.029} \approx 1.029$ per article — the strongest positive effect), kid5 (children under 6, RR ≈ 0.838 — each young child reduces publication rate by ~16%), femWomen (RR ≈ 0.805 — women publish at ~80% the rate of men), and marSingle (borderline, p = 0.067). Short Answer 1 · Core Concept
Explain the Poisson regression model: its systematic and distributional components, why the log link is used, and how to interpret the exponentiated coefficients as relative risks.
Model answer:

The Poisson regression model has two components. The distributional part specifies $y_i \mid \mathbf{x}_i \sim \text{Poisson}(\lambda_i)$, where the count is Poisson with conditional mean $\lambda_i$. The systematic part links $\lambda_i$ to the predictors via the log link: $\ln(\lambda_i) = \mathbf{x}_i^T\boldsymbol\beta$, so $\lambda_i = e^{\mathbf{x}_i^T\boldsymbol\beta}$.

Why log link? The log link enforces $\lambda_i > 0$ for all values of $\boldsymbol\beta$, since $e^{\text{anything}} > 0$. An identity link ($\lambda_i = \mathbf{x}_i^T\boldsymbol\beta$) could yield negative predictions, which are impossible for counts.

Interpretation of $e^{\hat\beta_j}$: For a continuous predictor $x_j$, a 1-unit increase multiplies the expected count by $e^{\hat\beta_j}$: $E(y \mid x_j + 1) = e^{\hat\beta_j} \cdot E(y \mid x_j)$. For a binary predictor, $e^{\hat\beta_j}$ is the ratio of expected counts between the coded group and the reference group (the "relative risk" or "rate ratio"). For example, in the skin cancer study, RR = 2.234 for Dallas means Dallas has 2.234 times the skin cancer rate of Minneapolis within each age group.

Short Answer 2 · Offset
Explain the concept of an offset in Poisson regression. Why is it needed for the skin cancer dataset? Show mathematically how the offset enters the model and how it is implemented in R.
Model answer:

An offset is needed whenever the observation window (population size, follow-up time, area, etc.) varies across observations, and we want to model rates rather than raw counts. In the skin cancer dataset, Minneapolis ages 15–24 has 172,675 people while Dallas ages 85+ has only 7,583 — comparing raw counts would be meaningless.

Mathematical derivation: We model the rate $\lambda/n$ (cases per person): $$\ln\!\left(\frac{E(y \mid \mathbf{x})}{n}\right) = \mathbf{x}^T\boldsymbol\beta$$ Rearranging: $\ln(E(y \mid \mathbf{x})) = \ln(n) + \mathbf{x}^T\boldsymbol\beta$. The term $\ln(n)$ is the offset — it enters the model as a predictor whose coefficient is constrained to 1 (not estimated).

R implementation: glm(cases ~ city + age.range + offset(log(n)), family = poisson(link="log"))

Predictions at different scales: Set n = 1 for per-person rates, n = 1000 for per-thousand rates, or use the actual population size for predicted counts.

Short Answer 3 · Overdispersion
Define overdispersion in Poisson regression. How is it detected? What are the consequences of ignoring it? Describe three approaches for handling it.
Model answer:

Definition: Overdispersion occurs when $\text{Var}(y \mid \mathbf{x}) > E(y \mid \mathbf{x}) = \lambda$. The Poisson model assumes $\text{Var} = \lambda$; real count data often violate this.

Detection: (1) Compare raw variance to mean: for publications, $\text{Var}(y) = 3.71 \gg 1.69 = E(y)$. (2) Examine DHARMa dispersion test: ratioObsSim = 1.415, $p \ll 0.001$. (3) Compare residual deviance to df: for publications, $D = 1634.4$ on $df = 909$ (ratio $\approx 1.8$ — well above 1). (4) Rootogram showing systematic misfit.

Consequences of ignoring: Standard Poisson SEs are underestimated (too small) → $z$-statistics are too large → $p$-values too small → inflated Type I error. Some predictors appear significant when they are not (e.g., marSingle: $p = 0.011$ Poisson vs $p = 0.058$ sandwich).

Three approaches:
(1) Sandwich estimator: corrects SEs without changing estimates; valid when mean structure is correct; no parametric assumption on variance.
(2) Quasi-Poisson: models $\text{Var}(y) = \phi\lambda$; estimates $\hat\phi$ from data; SEs multiplied by $\sqrt{\hat\phi}$; estimates unchanged; AIC unavailable.
(3) Negative Binomial: full parametric model with $\text{Var}(y) = \mu + \mu^2/\theta$; quadratic variance function; different (slightly) estimates; AIC available for model comparison; best model for publications data by AIC.
Likely follow-up questions:
• When would you prefer quasi-Poisson over the negative binomial?
• What is underdispersion, and how would you handle it?
• Can zero-inflation cause overdispersion? (Yes — excess zeros increase variance beyond the Poisson mean.)
Short Answer 4 · Sandwich Estimator Theory
Explain the theoretical justification for the sandwich (robust) variance estimator in Poisson regression. Under what conditions does the Poisson MLE converge to the true parameters even when the distribution is misspecified?
Model answer:

Setting: Suppose the true DGP is $g(y \mid \mathbf{z}, \boldsymbol\gamma_0)$ (e.g., negative binomial), but we fit the Poisson model $p(y \mid \mathbf{x}, \boldsymbol\theta)$. The MLE converges to $\boldsymbol\theta^*$ that minimises the Kullback-Leibler divergence: $$I(f:g, \boldsymbol\theta) = E_g\!\left[\log\frac{g(y \mid \mathbf{z}, \boldsymbol\gamma_0)}{p(y \mid \mathbf{x}, \boldsymbol\theta)}\right]$$ Equivalently, $\boldsymbol\theta^*$ solves $E_g[\mathbf{s}(\boldsymbol\theta)] = \mathbf{0}$ where $\mathbf{s}(\boldsymbol\theta) = \partial\log p / \partial\boldsymbol\theta$ is the score.

Key result for log-linear Poisson: If the mean structure is correctly specified, i.e., the true $\lambda$ satisfies $\ln(\lambda) = \mathbf{x}^T\boldsymbol\beta_0$ for some $\boldsymbol\beta_0$, then $\boldsymbol\theta^* = \boldsymbol\beta_0$ — the MLE converges to the true regression parameters even if the variance is wrong. This is because the score equations depend only on the mean: $\mathbf{X}^T(\mathbf{y} - \boldsymbol\mu) = \mathbf{0}$, and if the mean is correct, these are unbiased estimating equations.

Sandwich covariance: Asymptotically $\sqrt{n}(\hat{\boldsymbol\beta}_{\text{MLE}} - \boldsymbol\beta_0) \xrightarrow{d} \mathcal{N}(\mathbf{0}, \mathbf{C})$ where $\mathbf{C} = \mathbf{A}^{-1}\mathbf{B}\mathbf{A}^{-1}$ with $\mathbf{A}$ the expected Hessian and $\mathbf{B}$ the expected outer product of scores. This sandwich formula correctly accounts for the actual variance, not the Poisson-assumed variance.
Likely follow-up questions:

Short Answer 5 · Negative Binomial Derivation
Derive the mean and variance of the negative binomial model from the Poisson-Gamma mixture representation. Explain what the parameter $\theta$ represents and what happens when $\theta \to \infty$.
Model answer:

Setup: $y \mid \lambda \sim \text{Poisson}(\lambda)$ with $\lambda = \lambda^* e^{\mathbf{x}^T\boldsymbol\beta}$, $\lambda^* \sim \text{Gamma}(\theta, \theta)$, so $E(\lambda^*) = 1$ and $\text{Var}(\lambda^*) = 1/\theta$.

Mean: By the law of total expectation: $$E(y) = E[E(y\mid\lambda)] = E(\lambda) = e^{\mathbf{x}^T\boldsymbol\beta} \cdot E(\lambda^*) = e^{\mathbf{x}^T\boldsymbol\beta} = \mu$$ Variance: By the law of total variance: $$\text{Var}(y) = E[\text{Var}(y\mid\lambda)] + \text{Var}[E(y\mid\lambda)] = E(\lambda) + \text{Var}(\lambda)$$ $$= e^{\mathbf{x}^T\boldsymbol\beta} + \frac{1}{\theta}e^{2\mathbf{x}^T\boldsymbol\beta} = \mu + \frac{1}{\theta}\mu^2$$ Interpretation of $\theta$: $\theta$ is the inverse overdispersion parameter. Large $\theta$ means small $1/\theta$, so little extra-Poisson variation. $\theta = 2.264$ for publications means $\text{Var}(y) \approx \mu + 0.44\mu^2$ — substantial overdispersion at higher means.

As $\theta \to \infty$: $\text{Var}(y) \to \mu$ — the NB converges to Poisson (equidispersion). Equivalently, $\lambda^* \sim \text{Gamma}(\infty, \infty)$ converges to a point mass at 1, removing the random effect.

Short Answer 7 · DHARMa Residuals
Explain how DHARMa residuals are computed and interpreted. Why are they superior to standard Pearson or deviance residuals for GLM diagnostics? What does the publications model's DHARMa output tell us?
Model answer:

Computation: For each observation $i$: (1) Simulate $n_{\text{sim}} = 250$ replications $\tilde{y}_{ij}$ from the fitted model, using the estimated $\hat\lambda_i$. (2) Compute the empirical CDF $\hat{F}_i$ of these simulated values. (3) The DHARMa residual is $r_i = \hat{F}_i(y_i^{\text{obs}})$ — the quantile of the observed value within its simulated distribution.

Why superior to Pearson/deviance residuals? Standard residuals in GLMs have non-uniform and model-specific distributions that depend on the mean. For count data, this makes detecting patterns difficult. DHARMa residuals are always $U[0,1]$ under a correctly specified model, regardless of the distribution family. This enables model-free diagnostic tests.

Publications model output: — testUniformity: KS $D = 0.108$, $p = 1.3 \times 10^{-9}$ → residuals are NOT uniform → Poisson model is significantly misspecified. — testDispersion: ratio = 1.415, $p < 2.2 \times 10^{-16}$ → observed variance of residuals exceeds what a correctly specified Poisson model would produce → significant overdispersion. — These findings motivate switching to the negative binomial model, which passes both tests.

Short Answer 8 · Zero-Inflated Models
Explain the ZIP model: its structure, the distinction between structural and sampling zeros, and what the publications ZIP output tells us about the role of mentor productivity in determining structural non-publishing.
Model answer:

ZIP structure: The ZIP model is a two-component mixture. With probability $\pi$ (the zero-inflation probability), an observation is a "structural zero" — the individual can never produce events. With probability $1-\pi$, the individual belongs to the Poisson count process. The density is: $$P(y = k) = \pi\cdot\mathbf{1}_{[k=0]} + (1-\pi)\cdot\frac{e^{-\lambda}\lambda^k}{k!}$$ The mean is $\mu = (1-\pi)\lambda$, which is always lower than the Poisson mean.

Structural vs sampling zeros: A structural zero is from an individual who can never experience the event (e.g., a PhD student who has permanently decided not to pursue publications — perhaps they plan a non-academic career). A sampling zero is from an individual who could publish but happened not to in this window.

Publications ZIP(full) output: The zero-inflation component includes mentor articles (ment) with coefficient $\hat\gamma_{\text{ment}} = -0.134$ ($p = 0.003$). Negative coefficient in logit model means mentor productivity reduces the log-odds of being in the structural-zero group. A productive mentor keeps students engaged in the publication process, reducing the probability of permanent non-publishing.

Short Answer 9 · Comparing SE Methods
Using the publications data, compare the four approaches to handling overdispersion (Poisson, sandwich, quasi-Poisson, NB) with respect to their point estimates and standard errors. Which approach do you recommend and why?
Model answer:

Point estimates: Poisson, sandwich, and quasi-Poisson all produce identical coefficient estimates (solving the same score equations). NB produces slightly different estimates (accounting for the quadratic variance in the likelihood).

Standard errors: The naive Poisson SEs are smallest — they assume equidispersion and underestimate uncertainty. Sandwich SEs are 30–90% larger (e.g., ment SE: 0.0020 → 0.0038). Quasi-Poisson SEs are uniformly multiplied by $\sqrt{1.829} = 1.352$ (~35% larger). NB SEs are similar to sandwich and quasi-Poisson SEs in magnitude but arise from a different (parametric) derivation.

Recommendation: The Negative Binomial model is best for this dataset for several reasons: (1) It has a proper likelihood enabling AIC comparison, and wins overwhelmingly (ΔAIC = 178). (2) Its DHARMa diagnostics are satisfactory (both tests non-significant). (3) The quadratic variance function is supported by the mean-variance plot. (4) It provides richer parameter estimates (including $\hat\theta$) that characterise the heterogeneity in the population. The quasi-Poisson or sandwich are reasonable conservative choices when the full NB is not needed or when model robustness is paramount.

Short Answer 10 · Critical Thinking — Model Choice
A colleague claims: "For count data, I always use negative binomial regression because it handles overdispersion and is always better than Poisson." Critique this claim using the skin cancer and publications case studies.
Model answer:

The claim is an oversimplification. While the NB is a useful tool for overdispersed count data, "always" is too strong — model choice should be data-driven and theoretically motivated.

Counter-example: Skin cancer study. Here the standard Poisson model with an offset fits adequately — Pearson $\chi^2 = 8.13$ ($p = 0.32$) and Deviance $= 8.26$ ($p = 0.31$) are both non-significant. The DHARMa diagnostics also pass. Fitting a NB model would add an unnecessary parameter ($\theta$) without improving fit. The principle of parsimony (Occam's razor) argues against the NB here.

Supporting example: Publications study. The Poisson model fails dramatically — DHARMa tests strongly reject it, and AIC is 178 units worse than NB. Here the NB is clearly appropriate.

Additional nuances: (1) If zero-inflation is the primary issue (not general overdispersion), ZIP or ZINB may be more appropriate than NB alone. (2) NB adds a free parameter $\theta$ — if overdispersion is mild, quasi-Poisson (no extra parameters) may be sufficient. (3) The NB assumes a specific (quadratic) variance function; if the true variance function is different, NB could still misfit. (4) The NB requires estimation of $\theta$, which can be unstable with small samples.

Conclusion: Always start with Poisson, check diagnostics (DHARMa, deviance/df ratio), and escalate to NB or ZIP only if evidence warrants. Model selection should be guided by AIC and diagnostic checks, not a blanket rule.
