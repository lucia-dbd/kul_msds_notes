1. Why Logistic Regression? Motivation & the Donner Party

Linear regression models a continuous response $y$ as a linear function of predictors. But many outcomes of scientific interest are binary: survived/died, diseased/healthy, success/failure. We need a model that:

(1) Keeps the predicted probability $P(y=1 \mid \mathbf{x})$ strictly between 0 and 1.
(2) Allows flexible modelling of how predictors relate to probability.
(3) Is estimable by Maximum Likelihood from a Binomial/Bernoulli likelihood.
The Donner Party (1846–1847): 88 members of the Donner and Reed families set out from Illinois to California. Stranded by snowstorms in the Sierra Nevada, 40 died before rescue in April 1847. Data collected: age, sex, survival (0/1). Scientific question: controlling for age, do women have higher survival odds than men? This is the running case study for Chapter 4.

Three canonical examples of linear regression from the lectures motivate the need for alternatives when $y$ is binary:

ContextResponse $y$Model
Hubble's lawGalaxy velocity (continuous)Linear regression ✓
Lung cancer vs. smoking (rates)Proportion (continuous 0–1)Linear regression (approximate)

2. The Problem with the Linear Probability Model

For a binary outcome, $E(y \mid \mathbf{x}) = P(y=1 \mid \mathbf{x})$, a probability. The linear model would require: $$P(y=1 \mid \mathbf{x}) = \beta_0 + \beta_1 x_1 + \cdots + \beta_p x_p$$ but a linear function $\eta(\mathbf{x}) = \mathbf{x}^T\boldsymbol{\beta}$ is unbounded — it ranges over $(-\infty, +\infty)$, while a probability is constrained to $[0,1]$.
⚠ Concrete failure example: Suppose $P(y=1 \mid \text{fem}) = 0.5 - \text{fem}$ (linear model with $\beta_0 = 0.5$, $\beta_1 = -1$). For women ($\text{fem}=1$): $P(y=1) = 0.5 - 1 = -0.5$ — a negative probability! Logistic regression fixes this by mapping the linear predictor through a function that is always in $(0,1)$.
Animal experiment (morbidity vs. dose): 20 mice were exposed to doses from 0–20 mg. The observed proportions show a sigmoid pattern. A linear fit at 20 mg predicts a proportion above 1, which is impossible. The logistic curve tracks the data far better and stays within $[0,1]$ throughout.

3. The Logit Transform and the Expit (Logistic) Function

From probability to log-odds: the logit

Logit (log-odds) transform: $$\text{logit}[\pi] = \ln\left(\frac{\pi}{1-\pi}\right) = \ln\left(\frac{P(y=1)}{P(y=0)}\right)$$ Range: $-\infty \leq \text{logit}[\pi] \leq +\infty$ for $\pi \in (0,1)$.

Since the logit ranges over all of $\mathbb{R}$, it is valid to write:

$$\text{logit}[P(y=1 \mid \mathbf{x})] = \eta(\mathbf{x}) = \mathbf{x}^T\boldsymbol{\beta} = \beta_0 + \beta_1 x_1 + \cdots + \beta_p x_p$$

Back to probability: the expit (inverse logit)

Expit (logistic) function — inverting the logit: $$P(y=1 \mid \mathbf{x}) = \frac{e^{\eta(\mathbf{x})}}{1 + e^{\eta(\mathbf{x})}} = \frac{e^{\mathbf{x}^T\boldsymbol{\beta}}}{1 + e^{\mathbf{x}^T\boldsymbol{\beta}}}$$ This is always in $(0,1)$ for any finite $\eta$, solving the range problem.

Shape of the expit function

The expit is an S-shaped (sigmoid) curve. Key features:
— $\beta_0$ shifts the curve left/right (where $P = 0.5$ occurs at $\eta = 0$, i.e., $x = -\beta_0/\beta_1$).
— $|\beta_1|$ controls the steepness: larger $|\beta_1|$ = steeper curve.
— $\beta_1 > 0$: probability increases with $x$; $\beta_1 < 0$: probability decreases with $x$.
— As $\eta \to +\infty$, $P \to 1$; as $\eta \to -\infty$, $P \to 0$.

4. The Logistic Regression Model: Two Parts

Every GLM has two components — the logistic regression model is no exception:

PartNameFormulaDescription
SystematicLinear predictor + link$\text{logit}[\pi_i(\boldsymbol{\beta})] = \mathbf{x}_i^T\boldsymbol{\beta}$How the mean probability relates to predictors
DistributionRandom component$y_i \sim \text{Bern}[\pi_i(\boldsymbol{\beta})]$ or $y_i \sim \text{Bin}[n_i, \pi_i(\boldsymbol{\beta})]$Distribution of the response around its mean
Bernoulli case (ungrouped, individual-level data, $n_i = 1$, $N = n$):
Each $y_i \in \{0,1\}$, and $y_i \sim \text{Bern}[\pi_i(\boldsymbol{\beta})]$ where $\text{logit}[\pi_i(\boldsymbol{\beta})] = \mathbf{x}_i^T\boldsymbol{\beta}$.
Binomial case (grouped data, $N$ groups with $n_i$ replicates):
$y_i = \sum_{j=1}^{n_i} y_{ij}$ is the number of successes in group $i$, and $y_i \sim \text{Bin}[n_i, \pi_i(\boldsymbol{\beta})]$ where $\text{logit}[\pi_i(\boldsymbol{\beta})] = \mathbf{x}_i^T\boldsymbol{\beta}$.
This arises in designed experiments with categorical predictors.
Simple vs. Multiple logistic regression:
— Simple: 1 predictor (e.g., $\text{logit}[\pi] = \beta_0 + \beta_1 \text{age}$).
— Multiple: $p-1$ predictors (e.g., $\text{logit}[\pi] = \beta_0 + \beta_1 \text{age} + \beta_2 \text{fem}$).
The structure is identical; only the dimension of $\mathbf{x}$ differs.
⚠ Why OLS fails for binary $y$: Ordinary Least Squares minimises $\sum(y_i - \hat y_i)^2$ and assumes homoscedastic normal errors. For binary $y_i \in \{0,1\}$, the variance is $\pi_i(1-\pi_i)$ which depends on $\mathbf{x}$ (heteroscedastic), the errors are far from normal, and the predicted values can leave $[0,1]$. Maximum Likelihood with a Bernoulli/Binomial likelihood is the correct approach.

5. Maximum Likelihood Estimation

Likelihood and log-likelihood (Binomial case)

$$L(\boldsymbol{\beta}) \propto \prod_{i=1}^N \pi_i(\boldsymbol{\beta})^{y_i} [1 - \pi_i(\boldsymbol{\beta})]^{n_i - y_i}$$ $$\ell(\boldsymbol{\beta}) = \sum_{i=1}^N \left[y_i \mathbf{x}_i^T\boldsymbol{\beta} - n_i \log\left(1 + \exp(\mathbf{x}_i^T\boldsymbol{\beta})\right)\right]$$

Equivalently (highlighting the logit form):

$$\ell(\boldsymbol{\beta}) = \sum_{i=1}^N \left[y_i \log\frac{\pi_i(\boldsymbol{\beta})}{1-\pi_i(\boldsymbol{\beta})} + n_i \log(1-\pi_i(\boldsymbol{\beta}))\right]$$

Score equations

Score vector (gradient of $\ell$ w.r.t. $\boldsymbol{\beta}$): $$\mathbf{S}(\boldsymbol{\beta}) = \frac{\partial \ell}{\partial \boldsymbol{\beta}} = \sum_{i=1}^N \mathbf{x}_i\left(y_i - n_i \frac{e^{\mathbf{x}_i^T\boldsymbol{\beta}}}{1+e^{\mathbf{x}_i^T\boldsymbol{\beta}}}\right) = \mathbf{X}^T(\mathbf{y} - \boldsymbol{\mu})$$ where $\mathbf{X}$ is the design matrix, $\mathbf{y} = (y_i)^T$, and $\boldsymbol{\mu} = E(\mathbf{y}) = (n_i \pi_i(\boldsymbol{\beta}))^T$.

Setting $\mathbf{S}(\boldsymbol{\beta}) = \mathbf{0}$ gives the normal equations for logistic regression:

Intercept: $\sum_{i=1}^N [y_i - n_i\pi_i(\boldsymbol{\beta})] = 0$
Regressor $x_k$: $\sum_{i=1}^N x_{ki}[y_i - n_i\pi_i(\boldsymbol{\beta})] = 0$ for $k=1,\ldots,p-1$
The score equations require that the observed counts equal the fitted expected counts (summed over the appropriate margin). This is analogous to the OLS normal equations $\sum e_i = 0$ and $\sum x_{ki} e_i = 0$ in linear regression.

6. Hessian Matrix and Uniqueness of the MLE

Hessian matrix of $\ell$: $$\mathbf{H}(\boldsymbol{\beta}) = \frac{\partial^2 \ell}{\partial \boldsymbol{\beta} \partial \boldsymbol{\beta}^T} = -\mathbf{X}^T \mathbf{V} \mathbf{X}$$ where $\mathbf{V} = \text{diag}[n_1\pi_1(1-\pi_1), \ldots, n_N\pi_N(1-\pi_N)]$.
Remarkable property (canonical link): For the logistic regression model (logit = canonical link for Binomial), $\mathbf{V}$ does not depend on $\mathbf{y}$, only on $\boldsymbol{\beta}$ through $\pi_i(\boldsymbol{\beta})$. Therefore: $$\mathbf{I}(\boldsymbol{\beta}) = -E[\mathbf{H}(\boldsymbol{\beta})] = -\mathbf{H}(\boldsymbol{\beta}) = \mathbf{X}^T\mathbf{V}\mathbf{X}$$ The expected and observed information matrices are equal. Newton-Raphson = Fisher Scoring.
Concavity and uniqueness: When $\mathbf{X}$ has full column rank and $\hat{\mathbf{V}}$ has no zero diagonal elements (i.e., $0 < \hat\pi_i < 1$ for all $i$), $\mathbf{H}(\hat{\boldsymbol{\beta}})$ is negative definite. The log-likelihood is therefore strictly concave, guaranteeing a unique global maximum.
⚠ When MLE does not exist — perfect (complete) separation: If a hyperplane in predictor space perfectly separates all $y=0$ observations from all $y=1$ observations, then $\hat{\boldsymbol{\beta}} \to \pm\infty$ along certain directions (the log-likelihood has no finite maximum). This occurs with small samples or very strong predictors. Software may warn of non-convergence or produce absurdly large coefficient estimates with enormous standard errors.
Estimated covariance matrix of $\hat{\boldsymbol{\beta}}$: $$\widehat{\text{Cov}}(\hat{\boldsymbol{\beta}}) = \left(\mathbf{X}^T\hat{\mathbf{V}}\mathbf{X}\right)^{-1}$$ This is the inverse of the observed Fisher information evaluated at $\hat{\boldsymbol{\beta}}$.

7. Computing the MLE: Newton-Raphson / Fisher Scoring

Unlike linear regression (where OLS has a closed-form solution), logistic regression MLE requires iterative optimisation.

Newton-Raphson update: $$\boldsymbol{\beta}^{(t+1)} = \boldsymbol{\beta}^{(t)} - \left[\frac{\partial^2 \ell}{\partial\boldsymbol{\beta}\partial\boldsymbol{\beta}^T}\bigg|_{\boldsymbol{\beta}^{(t)}}\right]^{-1} \mathbf{S}(\boldsymbol{\beta}^{(t)}), \quad t = 0, 1, 2, \ldots$$ The algorithm stops when $\|\boldsymbol{\beta}^{(t+1)} - \boldsymbol{\beta}^{(t)}\| / \|\boldsymbol{\beta}^{(t)}\| \leq \varepsilon$.
Since $\mathbf{I}(\boldsymbol{\beta}) = -\mathbf{H}(\boldsymbol{\beta})$ for the logit (canonical link), Newton-Raphson and Fisher Scoring give identical updates. This also means the algorithm is equivalent to Iteratively Reweighted Least Squares (IRLS) — a form of weighted OLS with weights $w_i = n_i\pi_i(1-\pi_i)$ that change at each iteration. R reports the number of "Fisher Scoring iterations".
R output for Donner party model:
glm(Outcome ~ Age + fem, family=binomial(link="logit"))
Converged in 4 Fisher Scoring iterations.
$\hat\beta_0 = 0.554$, $\hat\beta_1 = -0.0356$ (Age), $\hat\beta_2 = 1.068$ (fem).
Null deviance: 120.86 (88 df) | Residual deviance: 108.87 (85 df) | AIC: 114.87.

8. Hypothesis Testing: The Holy Trinity in Logistic Regression

The three large-sample tests from Chapter 2 all apply. For $H_0: \mathbf{C}\boldsymbol{\beta} = \mathbf{d}$ (e.g., $H_0: \beta_k = 0$):

TestStatisticEvaluated atNull distribution
LR (Deviance)$G^2 = -2[\ell^{(0)} - \ell^{(1)}]$Both $\hat{\boldsymbol{\beta}}_0$ and $\hat{\boldsymbol{\beta}}$$\chi^2(r)$
Wald$(\hat{\boldsymbol{\beta}}_* )^T(-\mathbf{H}_{**})^{-1}\hat{\boldsymbol{\beta}}_*$$\hat{\boldsymbol{\beta}}$ (unrestricted MLE)$\chi^2(p_*)$
Score (Rao)$\mathbf{S}(\hat{\boldsymbol{\beta}}_0)^T[-\mathbf{H}(\hat{\boldsymbol{\beta}}_0)]^{-1}\mathbf{S}(\hat{\boldsymbol{\beta}}_0)$$\hat{\boldsymbol{\beta}}_0$ (null MLE)$\chi^2(r)$
All three tests are asymptotically equivalent under $H_0$ and are implemented in R:
— LR: anova(model0, model1, test='Chisq')
— Wald: z-values in summary() or wald.test() from aod
— Score: anova(model0, model1, test='Rao')
Donner party — testing $H_0: \beta_2 = 0$ (no gender effect):
LR: $G^2 = 5.15$, $p = 0.023$ * | Wald: $W = 4.9$, $p = 0.027$ * | Score: $\text{Rao} = 5.07$, $p = 0.024$ *
All three tests agree: there is significant evidence that gender affects survival, adjusted for age. The LR test has the best finite-sample properties.
⚠ The z-test in R output is a Wald test: The coefficient table shows $z = \hat\beta_k / se(\hat\beta_k)$ which is a Wald z-statistic (asymptotically $\mathcal{N}(0,1)$ under $H_0$, so $z^2 \sim \chi^2(1)$). Note: in linear regression, R uses a t-test (exact); in logistic regression, it uses a Wald z-test (asymptotic only), because no exact distributional result is available.

9. Interval Estimation: Wald vs. Profile-Likelihood CIs

Wald CI for $\beta_k$

$$\hat\beta_k \pm z_{1-\alpha/2}\; se(\hat\beta_k), \qquad se(\hat\beta_k) = \sqrt{\hat{\mathbf{I}}_{kk}^{-1}}$$ CI for $OR = e^{\beta_k}$: $\left(e^{\hat\beta_k - z_{1-\alpha/2}\cdot se(\hat\beta_k)},\; e^{\hat\beta_k + z_{1-\alpha/2}\cdot se(\hat\beta_k)}\right)$

Profile-likelihood CI (preferred)

The profile-likelihood CI inverts the LR test: it consists of all values $\beta_{k0}$ for which $H_0: \beta_k = \beta_{k0}$ is not rejected at level $\alpha$: $$G^2 = 2[\ell_1(\hat\beta_k) - \ell_1(\beta_{k0})] \leq \chi^2_{1,1-\alpha}$$ where $\ell_1(\beta_k) = \max_{\boldsymbol{\beta}_{-k}} \ell(\beta_k, \boldsymbol{\beta}_{-k})$ is the profile log-likelihood.
MethodR commandAdvantageLimitation
Waldconfint.default(model)Fast, simpleSymmetric on $\beta$ scale; poor for small $n$; not invariant
Profile-LRconfint(model)Better coverage; invariant to reparametrisationComputationally heavier (refits model)
Donner party — 95% CI for gender effect ($\beta_2$):
Profile-LR: $(0.144,\; 2.048)$ → OR CI: $(e^{0.144}, e^{2.048}) = (1.154,\; 7.753)$
Wald: $(0.123,\; 2.013)$ → OR CI: $(1.131,\; 7.488)$
Both exclude OR = 1, confirming the significant gender effect. The profile-LR CI is slightly wider and asymmetric on the OR scale — more appropriate for this small dataset.
CI for predicted probability $\pi(\mathbf{x})$: If $(L, U)$ is a CI for $\mathbf{x}^T\boldsymbol{\beta}$, then the CI for $\pi(\mathbf{x})$ is: $$\left(\frac{1}{1+e^{-L}},\; \frac{1}{1+e^{-U}}\right)$$ This correctly respects the $(0,1)$ constraint for probabilities.

10. Odds and Odds Ratios

Odds

Odds of "success": $$\Theta = \frac{P(y=1)}{P(y=0)} = \frac{\pi}{1-\pi}$$ Range: $0 < \Theta < \infty$. If $\pi = 2/3$: $\Theta = 2$ ("2 to 1 in favour"). If $\pi = 1/3$: $\Theta = 1/2$ ("1 to 2 against").

Odds Ratio (OR)

Odds Ratio — the fundamental measure of association in logistic regression: $$OR = \frac{\Theta_{y=1 \mid x=1}}{\Theta_{y=1 \mid x=0}} = \frac{P(y=1\mid x=1)/P(y=0\mid x=1)}{P(y=1\mid x=0)/P(y=0\mid x=0)}$$ Properties: $OR > 0$; $OR = 1 \Leftrightarrow$ independence; $OR > 1 \Leftrightarrow$ positive association; $OR < 1 \Leftrightarrow$ negative association.
The fundamental connection between $\beta_1$ and the OR (binary predictor): Substituting the logistic model expressions for $P(y=1\mid x=0)$ and $P(y=1\mid x=1)$: $$OR = e^{\beta_1} \qquad \Longleftrightarrow \qquad \beta_1 = \ln(OR)$$ The regression coefficient on the logit scale is the log-odds ratio. This holds exactly for binary predictors and approximately (as the change in log-odds per unit increase) for continuous predictors.
Hypothetical 2×2 table: Women: $P(\text{survive}) = 2/3$, $\Theta_{\text{women}} = 2$. Men: $P(\text{survive}) = 1/3$, $\Theta_{\text{men}} = 1/2$.
$OR = 2 / (1/2) = 4$ — women's survival odds are 4 times men's odds.
If instead both have $P(\text{survive}) = 2/3$: $OR = 2/2 = 1$ — no association.

Donner party interpretations:
Estimated model: $\text{logit}[\hat P(y=1 \mid \text{age, fem})] = 0.553 - 0.035\cdot\text{age} + 1.067\cdot\text{fem}$

Gender ($\hat\beta_2 = 1.067$): $\widehat{OR} = e^{1.067} \approx 2.91$. The odds of survival for a woman are approximately 3 times the odds for a man of the same age. This adjusted OR does not depend on age (the OR is constant across all ages — a key property of logistic regression with no interaction term).

Age ($\hat\beta_1 = -0.0356$): $\widehat{OR} = e^{-0.0356} \approx 0.965$. Each additional year of age is associated with a 3.5% decrease in the survival odds for both men and women (adjusted).

10-year age increase: $\widehat{OR} = e^{-0.0356 \times 10} = e^{-0.356} \approx 0.70$. A 10-year age increase is associated with a 30% decrease in survival odds.
⚠ Common interpretation errors:
✗ "$\beta_1 = -0.035$ means each year older reduces survival probability by 3.5%." Wrong — this is the effect on the log-odds, not the probability. The effect on probability is non-constant (depends on the current probability level).
✗ "OR = 3 means women are 3× more likely to survive." Wrong — OR is not a relative risk. The OR exaggerates the relative risk when events are common. OR = relative risk only when $\pi \approx 0$ (rare disease).
✓ Correct: "The odds of survival for women are about 3 times the odds for men of the same age."

12. Predicting Survival Probabilities

The fitted logistic model can predict the probability of "success" for any covariate pattern $\mathbf{x}$:

$$\hat P(y=1 \mid \mathbf{x}) = \frac{e^{\mathbf{x}^T\hat{\boldsymbol{\beta}}}}{1 + e^{\mathbf{x}^T\hat{\boldsymbol{\beta}}}}$$
Donner party predictions (average age 20.22 years):
a) Man, age 20.22: $\hat\eta = 0.553 - 0.035(20.22) + 1.067(0) = -0.155$
$\hat P = e^{-0.155}/(1+e^{-0.155}) = 0.856/1.856 = 0.461$

b) Woman, age 20.22: $\hat\eta = 0.553 - 0.035(20.22) + 1.067(1) = 0.912$
$\hat P = e^{0.912}/(1+e^{0.912}) = 2.49/3.49 = 0.713$

At average age, a woman had about a 71% predicted survival probability vs. 46% for a man.
In R: predict(model, newdata=..., type="response") returns predicted probabilities directly. type="link" returns predicted log-odds ($\mathbf{x}^T\hat{\boldsymbol{\beta}}$).
