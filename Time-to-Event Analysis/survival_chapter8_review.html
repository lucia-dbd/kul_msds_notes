8.1 Introduction to Competing Risks

Core idea: In standard survival analysis, subjects experience only one type of event. In a competing risks setting, there are K causes of failure, and we can only observe the first cause (in the absence of censoring).

Clinical Examples

⚠ Key warning: Naively treating competing events as independent censoring leads to overestimation of the cumulative incidence (Kaplan-Meier overestimates the CIF when competing events are present).

Prostate Cancer Example (DES Trial)

506 patients (stage III/IV) randomised to placebo or diethylstilbestrol (DES). DES can reduce prostate cancer death but increase cardiovascular death. Simply censoring non-cancer deaths ignores this harmful side-effect — making the competing risks framework essential.

8.2 Formal Setup

Notation:
  • \(T\) = latent (true) survival time
  • \(C\) = censoring time (assumed independent of \(T\) and cause)
  • \(Y = \min(T,C)\) = observed time
  • \(D = k\) if cause = \(k\) (\(k=1,\ldots,K\)), \(D=0\) if \(Y=C\)
We observe \((Y, D)\) for each subject.
The censoring assumption: \(C\) is independent of \(T\) and of the cause of death. This is analogous to the standard survival analysis assumption.

8.3 Key Quantities

Cumulative Incidence Function (CIF)

$$I_k(t) = P(T \le t,\, D = k)$$
Also called the sub-distribution function. Note:
  • \(I_k(\infty) = P(D=k) \le 1\) → not a proper CDF
  • \(\sum_{k=1}^{K} I_k(t) = P(T \le t)\) (overall failure distribution)

Cause-Specific Hazard

$$\lambda_k(t) = \lim_{\varepsilon\to 0} \frac{P(t \le T < t+\varepsilon,\, D=k \mid T \ge t)}{\varepsilon}$$ The hazard of failing from cause \(k\) among those still at risk (no failure from any cause yet).

\(\displaystyle\sum_{k=1}^K \lambda_k(t) = \lambda(t)\) = overall hazard.

Relationship: CIF and Cause-Specific Hazard

$$I_k(t) = \int_0^t \lambda_k(s)\, S(s)\, ds$$ where \(S(s) = P(T > s)\) is the overall survival function.

Marginal Quantity vs. CIF

The Kaplan-Meier treating other causes as censoring estimates: $$S_k(t) = \exp(-\Lambda_k(t)) = \exp\!\left(-\int_0^t \lambda_k(s)\,ds\right)$$ Since \(S(t) = \exp\!\left(-\sum_{k=1}^K \Lambda_k(t)\right) \le S_k(t)\), we have: $$I_k(t) \le 1 - S_k(t)$$ KM overestimates the true event probability \(I_k(t)\). Equality holds only when there is no competing risk.

Subdistribution Hazard (Fine & Gray, 1999)

$$h_k(t) = -\frac{d}{dt}\log(1 - I_k(t)) = \frac{I_k'(t)}{1-I_k(t)}$$ Key property: directly links to the CIF via $$I_k(t) = 1 - \exp\!\left(-\int_0^t h_k(s)\,ds\right)$$
⚠ Unusual risk set for hk: Individuals who already failed from a competing cause \(j \ne k\) remain in the risk set for \(h_k(t)\). This is mathematically necessary but clinically unnatural.

8.4 Nonparametric Estimation of the CIF

Let \(0 < t_1 < \cdots < t_N\) be the ordered distinct failure times (any cause). Define:
  • \(d_{kj}\) = number failing from cause \(k\) at \(t_j\)
  • \(d_j = \sum_k d_{kj}\) = total failures at \(t_j\)
  • \(n_j\) = number at risk just before \(t_j\)
Then: $$\hat{\lambda}_k(t_j) = \frac{d_{kj}}{n_j}, \qquad \hat{I}_k(t) = \sum_{t_j \le t} \hat{\lambda}_k(t_j)\,\hat{S}(t_{j-1})$$ where \(\hat{S}(t) = \prod_{t_j\le t}\!\left(1 - \frac{d_j}{n_j}\right)\) is the KM estimator for all-cause survival.
Asymptotic normality of \(\hat{I}_k(t)\) holds → confidence intervals can be constructed.

R Implementation (cmprsk package)

library(cmprsk)
D <- data$d1 + 2*data$d2  # 0=censored, 1=cancer death, 2=other death
fit <- cuminc(Y, D, group, cencode=0)
# fit[[1]] = CIF for cause 1 in group 0 (placebo)
# fit[[2]] = CIF for cause 1 in group 1 (treatment)
# etc.
Prostate cancer result: \(\hat{I}_{11}(60) = 0.20\) but KM gives \(1 - \hat{S}_{11}(60) = 0.28\). The CIF correctly accounts for the competing risk of non-cancer death, giving a lower (more realistic) estimate.

8.5 Cox Regression on Cause-Specific Hazards

Model: $$\lambda_k(t\mid X) = \lambda_{k0}(t)\exp(\beta_k^T X)$$ Separate baseline hazard \(\lambda_{k0}(t)\) and regression coefficients \(\beta_k\) for each cause \(k\).
Estimation trick: Fit a standard Cox model for cause \(k\) treating failures from all other causes as censored. This works because: $$\lambda_k(t\mid X) = \text{hazard of } T_k \mid X \quad \text{if } T_k \perp (T_2,\ldots,T_K)\mid X$$ But the conditional independence assumption is only used for estimation convenience, not as a biological claim.
⚠ Interpretation: \(\beta_k\) describes the effect of \(X\) on the cause-specific hazard, not on the marginal hazard. A covariate significant for cause 1 may have no effect on cause 2, and vice versa.

R Code

library(survival)
# Cause 1: cancer death
coxph(Surv(dtime, status==1) ~ rx+age+pf+hx+hg+sz+sg, data=data)
# Cause 2: non-cancer death
coxph(Surv(dtime, status==2) ~ rx+age+pf+hx+hg+sz+sg, data=data)

8.6 Fine–Gray Model: Regression on Subdistribution Hazards

Model (Fine & Gray, 1999): $$h_k(t\mid X) = h_{k0}(t)\exp(\gamma_k^T X)$$ This leads to a proportional CIF model: $$1 - I_k(t\mid X) = \bar{I}_{k0}(t)^{\exp(\gamma_k^T X)}$$ where \(\bar{I}_{k0}(t) = \exp\!\left(-\int_0^t h_{k0}(s)\,ds\right)\).
Advantage: \(\gamma_k\) directly describes the effect on the CIF — a positive coefficient means higher probability of failing from cause \(k\) by time \(t\).

R Code

library(cmprsk)
cov <- cbind(data$rx, data$age, data$pf, data$hx, data$hg, data$sz, data$sg)
# Fine-Gray for cancer death (cause 1)
c1 <- crr(data$dtime, data$status, cov, failcode=1)
# Alternative: fastcmprsk
library(fastcmprsk)
CR <- fastCrr(Crisk(dtime,status) ~ rx+age+pf+hx+hg+sz+sg, data=data)

⚠ A covariate can have opposite signs in CSH and Fine–Gray models! This is not a contradiction — the two quantities measure different things. Always specify which model you are using when interpreting results.

8.8 Multi-State Models

Competing risks: one initial state → several mutually exclusive absorbing states.
Multi-state models: allow intermediate (transient) states before absorption.
Illness-death model: State 1 (Healthy) → State 2 (Ill) → State 3 (Dead), plus a direct transition Healthy → Dead. This is the simplest multi-state model and a generalisation of competing risks.
Breast cancer (Putter et al, 2007): Surgery → {Local recurrence, Distant metastasis, Local + Distant} → Death.
Key references: Geskus (2016, 2020); Putter, Fiocco & Geskus (2007) Statistics in Medicine.

🔍 Short Answer & R Output Questions

Short Answer 1
Explain why the Kaplan-Meier estimator overestimates the true cumulative incidence Ik(t) when other causes are treated as independent censoring.
Answer: The KM treating other causes as independent censoring estimates Sk(t) = exp(−Λk(t)), so 1 − Sk(t) represents the probability of failing from cause k if competing risks did not exist. The true CIF is Ik(t) = ∫λk(s)S(s)ds where S(s) = exp(−∑Λk(s)) ≤ Sk(s). Because the overall survival S is always ≤ Sk, we have Ik(t) ≤ 1 − Sk(t). The KM inflates the risk by ignoring the fact that subjects who die from other causes can no longer die from cause k.
Short Answer 2
What is the difference in risk sets between the cause-specific hazard λk(t) and the subdistribution hazard hk(t)?
Answer: For λk(t): the risk set at time t contains only subjects who have not yet experienced any event (alive at t). For hk(t): subjects who failed from a competing cause (D ≠ k) before time t remain in the risk set (notionally assigned T*k = ∞). This makes the Fine–Gray risk set clinically unnatural — individuals who are already dead from another cause are counted as still "at risk." However, this is mathematically necessary to maintain the direct relationship 1 − Ik(t|X) = exp(−∫hkds).
Short Answer 3
In the prostate cancer CSH Cox model, the treatment variable rx has β̂ = −0.713 for cancer death and β̂ = +0.123 for non-cancer death. Provide a clinical interpretation of these two results together.
Answer: Treatment (DES at higher dose) significantly reduces the cause-specific hazard of dying from prostate cancer (HR = e−0.713 ≈ 0.49 — about 51% reduction). However, treatment shows a slightly higher (though non-significant, p = 0.37) cause-specific hazard for non-cancer death (HR ≈ 1.13), consistent with known cardiovascular side-effects of DES. Taken together, the beneficial cancer effect of DES must be weighed against the potential non-cancer mortality risk — a classic competing risks dilemma that would be missed if cancer deaths were analysed alone.
Short Answer 4
Write the R code to fit a Fine–Gray model for non-cancer death (cause 2) in the prostate data using covariates rx and age, and explain how the event indicator must be coded.
Answer: 
library(cmprsk)
# status: 0=censored, 1=cancer death, 2=non-cancer death
cov <- cbind(data$rx, data$age)
dimnames(cov)[[2]] <- c('rx', 'age')
c2 <- crr(data$dtime, data$status, cov, failcode=2)
The failcode=2 argument tells crr() that non-cancer death (D=2) is the event of interest; cancer deaths (D=1) are treated as competing events (entering the modified risk set). Censored observations have status=0. Alternatively, using fastcmprsk: 
data$status2 <- d2 + 2*d1  # swap roles: cause 2 is now coded 1
fastCrr(Crisk(dtime, status2) ~ rx + age, data=data)
Short Answer 5
Describe how to choose between the cause-specific hazard and the Fine–Gray subdistribution hazard model in a study investigating whether a new drug affects the probability of cancer relapse in the presence of death as a competing event.
Answer: Since the research question is about the probability of relapse (i.e., the CIF), the Fine–Gray model on the subdistribution hazard is preferred. This is because: (1) the subdistribution hazard hk(t|X) has a direct one-to-one relationship with the CIF, so regression coefficients γk directly describe covariate effects on the incidence probability; (2) a positive γk implies a higher CIF, making interpretation straightforward for clinical decision-making. The cause-specific hazard model would be preferred instead if the biological mechanism of drug action on relapse hazard is of primary interest, or for understanding the hazard process separately from the competing event.
