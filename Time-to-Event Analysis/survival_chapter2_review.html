2.1 Nonparametric Likelihood Functions

All nonparametric estimators in this chapter are derived by maximising a nonparametric likelihood that correctly accounts for censoring and/or truncation. The key insight is to factorise the full likelihood and drop uninformative censoring terms.

Likelihood for Right Censored Data

For a random sample (Yi, δi) with Yi = min(Ti, Ci), δi = I(Ti ≤ Ci), and assuming uninformative (independent) censoring:

Full likelihood contribution: event (δ=1): (1−G(Yᵢ)) · f(Yᵢ) censored (δ=0): (1−F(Yᵢ)) · g(Yᵢ) Drop non-informative G and g terms → survival likelihood: L = ∏ᵢ f(Yᵢ)^δᵢ · S(Yᵢ)^(1−δᵢ) = ∏ᵢ h(Yᵢ)^δᵢ · S(Yᵢ) Equivalently: L = ∏_{i∈D} f(Yᵢ) · ∏_{i∈R} S(Yᵢ) D = index set of event times R = index set of right-censored times
Interpretation: An observed event at Yi contributes f(Yi) = h(Yi)·S(Yi); a censored observation contributes only S(Yi) = P(T > Yi). The censored value tells us only that the subject was still alive at Yi.

General Likelihood: All Censoring Types

L = ∏_{i∈D} f(Yᵢ) · ∏_{i∈R} S(Yᵢ) · ∏_{i∈L} [1−S(Yᵢ)] · ∏_{i∈I} [S(lᵢ)−S(rᵢ)] D = exact event times R = right-censored L = left-censored I = interval (lᵢ, rᵢ)

Likelihood with Left Truncation

If subject i is left-truncated at time ai, we condition on T ≥ ai, dividing each term by S(ai):

L = ∏_{i∈D} f(Yᵢ)/S(aᵢ) · ∏_{i∈R} S(Yᵢ)/S(aᵢ) · ∏_{i∈L} [S(aᵢ)−S(Yᵢ)]/S(aᵢ) · ∏_{i∈I} [S(lᵢ)−S(rᵢ)]/S(aᵢ) Right truncation at bᵢ: replace S(aᵢ) with 1−S(bᵢ)

2.2 Kaplan-Meier Estimator

The Kaplan-Meier (KM) estimator is the nonparametric MLE of S(t) for right-censored data. Proposed in the most-cited statistics paper of all time: Kaplan & Meier (JASA, 1958) — ranked #1 among all statistics papers with over 25,000 citations.

Notation

Y₍₁₎ ≤ … ≤ Y₍ᵣ₎ : ordered event times d₍ⱼ₎ : events at Y₍ⱼ₎ r₍ⱼ₎ : risk set size just before Y₍ⱼ₎

Risk set r₍ⱼ₎ = number of subjects who have not yet died and were not censored just before Y₍ⱼ₎.

Formula (derived as MLE)

Ŝ(t) = ∏_{j: Y₍ⱼ₎ ≤ t} (r₍ⱼ₎ − d₍ⱼ₎) / r₍ⱼ₎ = ∏_{j: Y₍ⱼ₎ ≤ t} (1 − d₍ⱼ₎/r₍ⱼ₎) Discrete hazard estimate at each event time: ĥ₍ⱼ₎ = d₍ⱼ₎/r₍ⱼ₎ (from MLE)

Properties

  • Step function: jumps only at event times; constant at censored times
  • Jumps grow larger as time increases (smaller risk set)
  • Uncensored case: reduces to empirical survival function Ŝ(t) = (1/n)∑I(Yᵢ > t)
  • If largest observation is censored: Ŝ(t) never reaches 0 — three conventions: set to 0, hold constant, or leave undefined beyond Yn
Key exam point: Ŝ(t) only steps down at event times. A censored observation at time t reduces the risk set for future events but does NOT cause a step in Ŝ(t). At time 3 (censored) and time 8 (censored) in the example above, Ŝ stays flat.

Greenwood's Variance Formula & Asymptotic Normality

V̂ₐₛ(Ŝ(t)) = Ŝ²(t) · ∑_{j: Y₍ⱼ₎ ≤ t} d₍ⱼ₎ / [r₍ⱼ₎ · (r₍ⱼ₎ − d₍ⱼ₎)] Asymptotic normality: [Ŝ(t) − S(t)] / √V̂ₐₛ(Ŝ(t)) → N(0, 1)

2.3 Redistribution-to-the-Right Principle

An alternative, intuitive algorithm to compute the KM estimator:

  1. Assign initial mass 1/n to each of the n observations
  2. Find the first censored observation; redistribute its mass equally among all observations to its right
  3. Move to the next censored observation (using updated masses) and repeat
  4. Continue until all censored observations have been processed
  5. The accumulated masses at each event time equal the KM jump sizes
Intuition: A censored individual's probability is "passed forward" to surviving subjects — it is not lost but reallocated to those still at risk. This shows that KM is a weighted empirical survival function where censored observations redistribute their weight rightward.

2.4 Nelson-Aalen Estimator

Proposed independently by Nelson (Technometrics, 1972) and Aalen (Annals of Statistics, 1978). Directly estimates the cumulative hazard H(t).

Nelson-Aalen estimator: Ĥ(t) = ∑_{j: Y₍ⱼ₎ ≤ t} d₍ⱼ₎ / r₍ⱼ₎ for t ≤ Y₍ᵣ₎ Asymptotic variance: V̂ₐₛ(Ĥ(t)) = ∑_{j: Y₍ⱼ₎ ≤ t} d₍ⱼ₎ / r²₍ⱼ₎ Asymptotic normality: [Ĥ(t) − H(t)] / √V̂ₐₛ(Ĥ(t)) → N(0, 1)

Alternative KM Estimator via Nelson-Aalen

Ŝₐₗₜ(t) = exp(−Ĥ(t)) = ∏_{j: Y₍ⱼ₎ ≤ t} exp(−d₍ⱼ₎/r₍ⱼ₎) In R: stype=2 in survfit()
KM vs Nelson-Aalen based: Both are asymptotically equivalent. Ŝₐₗₜ(t) often performs better in small samples — since exp(−d/r) ≥ (r−d)/r, it gives slightly higher (less biased) survival estimates when sample sizes are small.

2.5 Confidence Intervals for S(t)

Plain CI — conf.type = "plain" (not recommended)

Ŝ(t) ± z_{α/2} · √V̂ₐₛ(Ŝ(t)) Problem: may yield values outside [0, 1]

Log-Log Transformation — conf.type = "log-log" ✓ preferred

Transform: θ = log(−log S(t)) maps [0,1] → (−∞, +∞) Variance of log(−logŜ(t)): V̂ₐₛ(log(−logŜ(t))) = (1/logŜ(t))² · ∑ d₍ⱼ₎/[r₍ⱼ₎(r₍ⱼ₎−d₍ⱼ₎)] CI on log-log scale: log(−logŜ(t)) ± z_{α/2} · √V̂ₐₛ Back-transform: Ŝ(t)^exp(+c) and Ŝ(t)^exp(−c) where c = z_{α/2} · √V̂ₐₛ(log(−logŜ(t)))
Why log-log is preferred: The transformation maps [0,1] to the whole real line, ensuring that after back-transformation, the CI bounds always lie within [0,1]. The plain CI can produce nonsensical negative lower bounds or upper bounds above 1.

2.6 Mean and Median Survival Estimation

Restricted Mean Survival Time

Since E(T) = ∫₀^∞ S(t) dt, we plug in Ŝ(t). If the largest observation Yn is censored, Ŝ(t) is inconsistent in the right tail — two practical solutions:

Proposal 1 (upper limit = Yₙ): μ̂_{Yₙ} = ∫₀^{Yₙ} Ŝ(t) dt [assume event immediately after last censoring] Proposal 2 (user-defined upper limit tₘₐₓ): μ̂_{tₘₐₓ} = ∫₀^{tₘₐₓ} Ŝ(t) dt [Ŝ(t) = Ŝ(Yₙ) for Yₙ ≤ t ≤ tₘₐₓ] Variance: V̂ₐₛ(μ̂_τ) = ∑ⱼ [∫_{Y₍ⱼ₎}^τ Ŝ(t)dt]² · d₍ⱼ₎/[r₍ⱼ₎(r₍ⱼ₎−d₍ⱼ₎)] 95% CI: μ̂_τ ± 1.96·√V̂ₐₛ(μ̂_τ) R: print(fit, print.rmean=TRUE) # τ = Yₙ print(fit, print.rmean=TRUE, rmean=10) # τ = 10
Important: Both estimators are inconsistent for the true mean μ. But given censoring in the right tail, no nonparametric method can do better. Always report which upper limit τ was used — it directly affects the estimate.

Quantile Estimation

The median is preferred over the mean for skewed survival data. It can be consistently estimated when censoring is not too heavy.

p-th quantile estimator: x̂ₚ = inf{ t : Ŝ(t) ≤ 1−p } = smallest t at which Ŝ(t) drops to or below 1−p Median = x̂_{0.5} (smallest t with Ŝ(t) ≤ 0.5) CI for xₚ (inversion — avoids density estimation): { t : |[Ŝ(t)−(1−p)] / √V̂ₐₛ(Ŝ(t))| ≤ z_{α/2} } R: quantile(fit, probs=c(0.10, 0.25, 0.50, 0.75, 0.90))
NA in quantile output: If Ŝ(t) never drops to 1−p (e.g., the curve stays above 0.1 for all observed t), the quantile is not estimable and R returns NA. Common for upper quantiles under heavy censoring.

2.7 Left Truncated & Right Censored Data

When subject i is left-truncated at Li, only those with Ti ≥ Li enter the sample. The KM formula structure stays the same, but the risk set is redefined.

Modified Risk Set

r₍ⱼ₎ = #{ i : Lᵢ ≤ Y₍ⱼ₎ ≤ Yᵢ } = subjects under observation both before and up to event time Y₍ⱼ₎

Lynden-Bell Estimator (1971)

We can only estimate a conditional survival function Sₗ(t) = P(T > t | T ≥ l) for l ≤ min(Li):

Ŝₗ(t) = 1 if t < l = ∏_{j: l ≤ Y₍ⱼ₎ ≤ t} (1 − d₍ⱼ₎/r₍ⱼ₎) if t ≥ l R: survfit(Surv(Trunc, Time, Censor) ~ 1) [three-column Surv: left truncation time, event time, δ]
Impact of truncation: The modified risk set is smaller than in the non-truncated case (subjects with Li > Y₍ⱼ₎ are excluded), making estimates less precise with wider CIs. Compare Ŝ(2) = 0.800 without truncation vs Ŝ(2) = 0.500 with truncation times (0,0,2,3,5) in the slides example.

✍️ Short Answer Questions

Short Answer 1
Derive the Kaplan-Meier estimator from first principles. Starting from the nonparametric log-likelihood for right-censored data, show why the MLE takes the product-limit form Ŝ(t) = ∏_{j: Y₍ⱼ₎ ≤ t} (1 − d₍ⱼ₎/r₍ⱼ₎).
Model Answer:

Step 1 — Log-likelihood:
For right-censored data with uninformative censoring:
log L = ∑ᵢ [δᵢ log f(Yᵢ) + (1−δᵢ) log S(Yᵢ)]

Step 2 — Nonparametric substitution:
Replace f(Yᵢ) = S(Yᵢ⁻) − S(Yᵢ), the mass placed at Yᵢ. It can be shown that the maximiser over all distributions must be a step function placing mass only at observed event times. Writing Ŝ(t) = ∏_{j: Y₍ⱼ₎ ≤ t} (1 − h₍ⱼ₎) for some jump sizes h₍ⱼ₎, the log-likelihood becomes:
log L = ∑ⱼ [d₍ⱼ₎ log h₍ⱼ₎ + (r₍ⱼ₎ − d₍ⱼ₎) log(1 − h₍ⱼ₎)]

Step 3 — MLE for each h₍ⱼ₎:
Differentiating with respect to each h₍ⱼ₎ and setting to zero:
d/dh₍ⱼ₎ log L = d₍ⱼ₎/h₍ⱼ₎ − (r₍ⱼ₎ − d₍ⱼ₎)/(1 − h₍ⱼ₎) = 0
⟹ ĥ₍ⱼ₎ = d₍ⱼ₎/r₍ⱼ₎

Step 4 — Plug in:
Ŝ(t) = ∏_{j: Y₍ⱼ₎ ≤ t} (1 − ĥ₍ⱼ₎) = ∏_{j: Y₍ⱼ₎ ≤ t} (r₍ⱼ₎ − d₍ⱼ₎)/r₍ⱼ₎ ✓
Short Answer 2
Explain the redistribution-to-the-right principle and use it to compute the KM estimator for the example data: Time = (2, 3, 5, 7, 8), Censor = (1, 0, 1, 1, 0). Verify your answer matches the formula-based calculation.
Model Answer:

Algorithm: Each observation starts with mass 1/5 = 0.2. Process censored observations in time order, redistributing their mass equally to all observations to their right.

Initial masses: t=2: 0.2, t=3: 0.2, t=5: 0.2, t=7: 0.2, t=8: 0.2

t=3 is censored: Its mass 0.2 is redistributed to t=5, t=7, t=8 (3 observations to the right), adding 0.2/3 ≈ 0.0667 each.
Updated masses: t=2: 0.2, t=5: 0.2667, t=7: 0.2667, t=8: 0.2667

t=8 is censored: Its updated mass 0.2667 is redistributed — but there are no observations to its right. Under the convention that Ŝ(Yₙ) stays at its last value, this mass is simply not redistributed further.

Final masses at event times: t=2: 0.200, t=5: 0.2667, t=7: 0.2667

KM via redistribution:
Ŝ(2) = 1 − 0.200 = 0.800 ✓
Ŝ(5) = 0.800 − 0.2667 = 0.533 ✓
Ŝ(7) = 0.533 − 0.2667 = 0.267 ✓

These match exactly the formula-based values from the table.
Short Answer 3
Why is the log-log transformation preferred over the plain (untransformed) approach when constructing confidence intervals for S(t)? Describe the transformation, its variance, and the back-transformation step to obtain the CI for S(t).
Model Answer:

Problem with the plain CI:
The plain CI Ŝ(t) ± z_{α/2}√V̂ₐₛ(Ŝ(t)) is symmetric around Ŝ(t) and can produce values outside [0,1], e.g., a negative lower bound when Ŝ(t) is close to 0, or an upper bound above 1 when Ŝ(t) is close to 1. Survival probabilities must lie in [0,1], so this is mathematically inadmissible.

Log-log transformation:
Define θ(t) = log(−log S(t)). This maps S(t) ∈ (0,1) to θ(t) ∈ (−∞, +∞), so a CI on the θ-scale can take any real value and will always back-transform to [0,1].

Variance of log(−logŜ(t)):
By the delta method:
V̂ₐₛ(log(−logŜ(t))) = (1/logŜ(t))² · ∑ d₍ⱼ₎/[r₍ⱼ₎(r₍ⱼ₎ − d₍ⱼ₎)]

CI on log-log scale:
log(−logŜ(t)) ± z_{α/2} · √V̂ₐₛ(log(−logŜ(t)))

Back-transformation:
If the CI on the log-log scale is (L, U), then:
CI for S(t): (exp(−exp(U)), exp(−exp(L))) = (Ŝ(t)^exp(c), Ŝ(t)^exp(−c))
where c = z_{α/2}·√V̂ₐₛ. This always lies in [0,1]. In R: conf.type="log-log".
Short Answer 4
Describe how the presence of left truncation changes the Kaplan-Meier estimation procedure. What can and cannot be estimated? Use the slides example (truncation times = 0,0,2,3,5; event times = 2,3,5,7,8) to illustrate the impact on the risk set and the resulting estimates.
Model Answer:

What changes: With left truncation at Lᵢ, subject i only enters the risk set at times ≥ Lᵢ. Subjects with Lᵢ > Y₍ⱼ₎ are NOT at risk at event time Y₍ⱼ₎ — they haven't entered the study yet.

New risk set: r₍ⱼ₎ = #{i : Lᵢ ≤ Y₍ⱼ₎ ≤ Yᵢ}

What can be estimated: Only a conditional survival function Sₗ(t) = P(T > t | T ≥ l) for l ≤ min(Lᵢ). The unconditional S(t) is not identifiable from truncated data alone.

Illustration:
Truncation times Lᵢ = (0,0,2,3,5); Times Yᵢ = (2,3,5,7,8); Censor = (1,0,1,1,0)

At event time Y₍₁₎ = 2: Risk set = {i : Lᵢ ≤ 2 ≤ Yᵢ} = {subjects 1,2} → r₍₁₎ = 2
Compare: without truncation, r₍₁₎ = 5

Result: Ŝₗ(2) = (2−1)/2 = 0.500 vs Ŝ(2) = 0.800 without truncation.

The survival estimates are lower and standard errors are much wider (see: std.err = 0.354 at t=2 with truncation vs 0.179 without). This makes intuitive sense: fewer subjects are effectively at risk early in the study when truncation times are non-zero.
Short Answer 5
Compare and contrast the Kaplan-Meier estimator Ŝ(t) and the Nelson-Aalen based estimator Ŝₐₗₜ(t) = exp(−Ĥ(t)). What are their similarities and differences? Under what circumstances should Ŝₐₗₜ(t) be preferred, and why?
Model Answer:

Similarities:
  • Both are nonparametric step-function estimators of S(t)
  • Both are derived from the same underlying data (Yi, δᵢ)
  • Both are asymptotically equivalent: for large n, they converge to the same limit S(t)
  • Both produce the same qualitative features: steps at event times only, correct handling of censoring
Differences:
  • KM is derived as the nonparametric MLE directly maximising the log-likelihood; NA-based uses the relation S(t) = exp(−H(t))
  • KM uses (r−d)/r at each step; NA-based uses exp(−d/r) — since exp(−x) ≥ 1−x for x > 0, we always have Ŝₐₗₜ(t) ≥ Ŝ(t)
  • For large r₍ⱼ₎ (small d/r), exp(−d/r) ≈ 1−d/r, so both are very similar
When Ŝₐₗₜ(t) is preferred:
In small samples, Ŝ(t) can be downward biased — particularly when the risk set is small (d/r is not small). Since Ŝₐₗₜ(t) ≥ Ŝ(t) always, it provides a slightly higher and often less biased estimate in small-sample scenarios. Simulation studies have shown better finite-sample performance for Ŝₐₗₜ(t). In R: use stype=2 in survfit().
