5.1 Common Parametric Distributions

Parametric survival models assume T follows a specific distributional family, characterised by a small number of parameters. The choice of distribution determines the shape of the hazard function.

Exponential Distribution

Parameters: λ > 0 S₀(t) = exp(−λt) f₀(t) = λ exp(−λt) h₀(t) = λ ← constant hazard (memoryless) Empirical check: plot log(Ŝ(t)) vs t → should be linear
Key property: The only continuous distribution with the memoryless property: P(T > s+t | T > s) = P(T > t). The hazard is constant — past survival provides no information about future risk.

Weibull Distribution

Parameters: λ > 0 (scale), ρ > 0 (shape) S₀(t) = exp(−λt^ρ) f₀(t) = ρλt^(ρ−1) exp(−λt^ρ) h₀(t) = ρλt^(ρ−1) ← monotone hazard ρ < 1 → decreasing hazard (early failures, infant mortality) ρ = 1 → constant hazard (reduces to Exponential) ρ > 1 → increasing hazard (wear-out, aging) Empirical check: plot log(Ĥ(t)) = log(−logŜ(t)) vs log(t) → should be linear (slope = ρ, intercept = log(λ))

Log-Logistic Distribution

Parameters: λ > 0, κ > 0 S₀(t) = 1 / [1 + (λt)^κ] f₀(t) = λκ(λt)^(κ−1) / [1 + (λt)^κ]² h₀(t) = λκ(λt)^(κ−1) / [1 + (λt)^κ] κ > 1 → hazard rises then falls (hump-shaped; models acute illness) κ ≤ 1 → hazard decreases monotonically Median: M(T) = exp(1/κ) / λ (function of λ only, not κ)

Log-Normal Distribution

Parameters: µ ∈ ℝ (location), γ > 0 (scale) → log T ~ N(µ, γ²) S₀(t) = 1 − Φ((log t − µ) / γ) f₀(t) = (1/γt√2π) exp(−(log t − µ)² / 2γ²) No closed form for h₀(t) Hazard rises then falls (like log-logistic with κ > 1) Mathematically less tractable than log-logistic Median: M(T) = exp(µ) (function of µ only)

5.2 Accelerated Failure Time (AFT) Model

The AFT model relates covariates to survival by stretching or compressing the time axis. It is a fully parametric regression model for T.

AFT Model: Sᵢ(t) = S₀(exp(θᵀxᵢ) · t) where: θ = (θ₁, …, θₚ)ᵀ = vector of regression coefficients exp(θᵀxᵢ) = acceleration factor for subject i S₀(·) = baseline survival function (parametric family) Hazard under AFT: hᵢ(t) = exp(θᵀxᵢ) · h₀(exp(θᵀxᵢ) · t) Effect on median: Mᵢ = exp(−θᵀxᵢ) · M₀
Interpretation of acceleration factor: If exp(θᵀxᵢ) = 2, time runs twice as fast for subject i — they experience events at half the age compared to baseline. If exp(θᵀxᵢ) = 0.5, time runs half as fast — survival is extended (protective covariate).
Sign convention in R (survreg): R fits the log-linear model log T = µ + βᵀx + σW. The coefficient β in R equals −θ in the AFT notation above. A positive R coefficient means longer survival time (protective); a negative coefficient means shorter survival time (harmful). Always check the parameterisation used.

5.3 Equivalent Linear (Log-Linear) Model

The AFT model has a natural log-linear representation that simplifies estimation:

log T = µ + βᵀx + σW where: µ = intercept β = (β₁,…,βₚ)ᵀ = regression coefficients (β = −θ from AFT) σ = scale parameter W = error with known distribution (same for all x)
Equivalence: The AFT model Sᵢ(t) = S₀(exp(θᵀxᵢ)t) and the linear model log T = µ + βᵀx + σW are equivalent when:
  • S₀ is the survival function of exp(µ + σW)
  • θ = −β/σ
The error distribution W determines which parametric family is used.

Unique property of Weibull: The Weibull is the only continuous distribution that is simultaneously an AFT model AND a Cox proportional hazards model. This makes it especially important in practice.

5.4 Weibull Model in Detail

Three Equivalent Representations

1. AFT Model: Sᵢ(t) = S₀(exp(θᵀxᵢ)·t), S₀(t) = exp(−λt^α) → Sᵢ(t) = exp(−λ exp(γᵀxᵢ)·t^α) with γ = αθ → hᵢ(t) = αλt^(α−1) exp(γᵀxᵢ) = h₀(t)·exp(γᵀxᵢ) ← PH form! 2. Cox PH with Weibull baseline: hᵢ(t) = h₀(t)·exp(γᵀxᵢ), h₀(t) = αλt^(α−1) 3. Log-linear model: log T = µ + βᵀx + σW, W ~ standard extreme value with: θ = −β/σ = −β·α (since σ = 1/α) α = 1/σ λ = exp(−µ/σ) (= exp(−αµ))

Schizophrenia Worked Example

Fitting survreg(Surv(Time,Censor)~Gender+Education+Marital, dist="weibull") gives the log-linear form:

log T = 7.91 − 0.46·Gender − 0.01·Educ + 0.17·Married − 0.59·AloneAgain + 0.94·ε where exp(ε) ~ Weib(1,1) = Exp(1) [i.e., σ = 0.94] Interpretation of Gender coefficient (−0.46): → Males (Gender=1) have shorter log-survival time by 0.46 units → Acceleration factor = exp(−(−0.46)/0.94) ≈ exp(0.49) ≈ 1.63 → Males experience events ~1.63× faster than females AFT form: Sᵢ(t) = S₀(exp(0.46·Gender + 0.01·Educ − 0.17·Married + 0.59·AloneAgain)·t) with S₀(t) = exp(−λt^α), λ = exp(−7.91/0.94), α = 1/0.94 ≈ 1.064

5.5 Log-Logistic Model in Detail

Three Equivalent Representations

1. AFT Model: Sᵢ(t) = S₀(exp(θᵀxᵢ)·t), S₀(t) = 1/[1 + (λt)^α] 2. Proportional Odds Model: Sᵢ(t)/[1−Sᵢ(t)] = (S₀(t)/[1−S₀(t)]) · exp(−γᵀxᵢ) → The odds of surviving beyond t are proportional across covariate groups 3. Log-linear model: log T = µ + βᵀx + σW, W ~ standard logistic: S_W(w) = 1/[1+eʷ] with: θ = −β/σ (same conversion as Weibull case) α = 1/σ λ = exp(−µ/σ)
Key distinction: Unlike Weibull (which is both AFT and PH), the log-logistic model is both AFT and a proportional odds model. It is NOT a Cox PH model. Use log-logistic when the hazard is non-monotone (hump-shaped) and proportional hazards is inappropriate.

5.6 Other Distributions

Log-Normal

log T = µ + βᵀx + σW, W ~ N(0,1) → Log-normal AFT = linear model with standard normal error → NOT a PH model, NOT a proportional odds model

Generalised Gamma — The Master Distribution

log T = µ + βᵀx + σW, W has density: f_W(w) = |ν| (ν²)^(1/ν²) exp(νw − ν²exp(νw)) / Γ(1/ν²) Special cases (by choosing ν): ν = 1 → Weibull model ν = 1, σ = 1 → Exponential model ν → 0 → Log-normal model Use: fit the generalised gamma as the "full" model, then test nested special cases to select the best distribution.
Why it matters: The generalised gamma nests the three most common parametric families. Fitting it and testing whether ν=1 (Weibull), ν=1 & σ=1 (Exponential), or ν→0 (log-normal) provides a principled, likelihood-based model selection strategy.

5.7 Estimation

We estimate parameters via maximum likelihood using the log-linear representation. For right-censored data:

Likelihood: L(µ, β, σ) = ∏ᵢ fᵢ(Yᵢ)^δᵢ · Sᵢ(Yᵢ)^(1−δᵢ) Writing log Yᵢ = µ + βᵀxᵢ + σWᵢ, each term becomes: = ∏ᵢ [(1/σYᵢ) f_W((log Yᵢ − µ − βᵀxᵢ)/σ)]^δᵢ × [S_W((log Yᵢ − µ − βᵀxᵢ)/σ)]^(1−δᵢ) MLE: (µ̂, β̂, σ̂) = argmax L(µ, β, σ) Properties of MLE: • Asymptotically unbiased and normal • Covariance matrix estimated from observed Fisher information • Delta method → CIs for derived quantities (median, S(t), etc.)
Identifiability: Since W has a known distribution, its mean and variance are fixed by convention. This is why, for example, in the Weibull model we set exp(αµ) = 1 and α = 1 as an identifiability constraint when linking the log-linear to the AFT parameterisation.

5.8 Model Selection

Method 1: Nested Likelihood Ratio / Wald / Score Tests

Use the generalised gamma as the "full" model and test whether simpler models are adequate:

H₀: ν = 1 → Weibull H₀: ν = 1, σ = 1 → Exponential H₀: ν → 0 → Log-normal Test statistics: Wald, likelihood ratio, or score test (all based on the censored data likelihood)

Method 2: AIC (for non-nested models)

AIC = −2 log L + 2(p + 1 + k) where: p + 1 = number of regression parameters including intercept (µ, β₁,…,βₚ) k = 0 for Exponential (no shape parameter) k = 1 for Weibull, log-logistic, log-normal (one shape parameter) k = 2 for Generalised gamma (two shape parameters) → Select the model with the lowest AIC R command: survreg(Surv(Time,Censor) ~ x1 + x2, dist="weibull") Available: dist = "weibull", "exponential", "loglogistic", "lognormal", "logistic", "gaussian" (last two: no log-transform of T)
Graphical checks before fitting:
  • Exponential: plot log(Ŝ(t)) vs t — should be linear through origin
  • Weibull: plot log(−logŜ(t)) vs log(t) — should be linear (slope = ρ)
  • Log-logistic: plot log(Ŝ(t)⁻¹ − 1) vs log(t) — should be linear
  • Log-normal: plot Φ⁻¹(1 − Ŝ(t)) vs log(t) — should be linear

✍️ Short Answer Questions

Short Answer 1
Show algebraically that the AFT model Sᵢ(t) = S₀(exp(θᵀxᵢ)·t) is equivalent to the log-linear model log T = µ + βᵀx + σW. Identify the relationship between the model parameters (θ, S₀) and (µ, β, σ, W).
Model Answer:

Starting from the log-linear model:
log T = µ + βᵀx + σW    ⟹    T = exp(µ + βᵀx + σW)

Computing Sᵢ(t):
Sᵢ(t) = P(Tᵢ > t) = P(log Tᵢ > log t)
       = P(µ + σWᵢ > log t − βᵀxᵢ)
       = P(Wᵢ > (log t − µ − βᵀxᵢ)/σ)
       = S_W((log t − µ − βᵀxᵢ)/σ)

Now define S₀ as the survival function of exp(µ + σW), i.e., S₀(t) = S_W((log t − µ)/σ). Then:
Sᵢ(t) = S_W((log t − µ − βᵀxᵢ)/σ)
       = S_W((log(t · exp(−βᵀxᵢ)) − µ)/σ)
       = S₀(t · exp(−βᵀxᵢ))
       = S₀(exp(θᵀxᵢ) · t)    where θ = −β/σ

Parameter correspondence:
θ = −β/σ,   S₀ = survival of exp(µ + σW),   σ = scale
The two representations are fully equivalent.
Short Answer 2
Prove that the Weibull AFT model simultaneously satisfies the proportional hazards assumption. Derive the PH form of the hazard and identify the baseline hazard and the covariate effect. Why is this unique to the Weibull distribution?
Model Answer:

Starting from Weibull AFT:
Sᵢ(t) = S₀(exp(θᵀxᵢ)·t) with S₀(t) = exp(−λt^α)
→ Sᵢ(t) = exp(−λ[exp(θᵀxᵢ)·t]^α) = exp(−λ exp(αθᵀxᵢ)·t^α)

Computing the hazard:
hᵢ(t) = −d/dt log Sᵢ(t) = αλt^(α−1) · exp(αθᵀxᵢ)
= h₀(t) · exp(γᵀxᵢ)    where h₀(t) = αλt^(α−1) and γ = αθ

This is exactly the Cox PH form: the hazard is a product of a baseline hazard and a covariate-dependent multiplicative factor that does not depend on t.

Why this is unique to Weibull:
The AFT acceleration produces Sᵢ(t) = S₀(ct) for constant c = exp(θᵀxᵢ). For the PH property to hold simultaneously, we need hᵢ(t) = h₀(ct)·c = φ(c)·h₀(t) for some function φ. This requires h₀(ct) ∝ h₀(t) for all t — which is only satisfied by power functions h₀(t) = αλt^(α−1) (Weibull). No other distribution satisfies this self-similarity property.
Short Answer 3
Explain how model selection works for parametric survival models. Describe both the nested testing approach (using the generalised gamma) and the AIC approach. Give the AIC formula and explain the role of the penalty terms p, 1, and k.
Model Answer:

Method 1 — Nested likelihood testing (via generalised gamma):
The generalised gamma model log T = µ + βᵀx + σW is the most general model considered. It nests:
 • Weibull: ν = 1
 • Exponential: ν = 1 and σ = 1
 • Log-normal: ν → 0
For each null hypothesis, fit both the restricted and unrestricted model and compute the likelihood ratio test statistic: LRT = 2(log L_full − log L_restricted) ~ χ²(q) under H₀, where q is the number of restrictions. Wald and score tests are also valid alternatives.

Method 2 — AIC (for non-nested comparisons):
AIC = −2 log L + 2(p + 1 + k)
 • −2 log L: measures goodness-of-fit (smaller = better fit)
 • p + 1: penalises for number of regression parameters (p covariates + intercept µ)
 • k: penalises for additional distributional shape parameters
   k = 0 (Exponential, no shape par.), k = 1 (Weibull, log-logistic, log-normal — one shape par.), k = 2 (Gen. gamma — two shape pars.)
Select the distribution with the lowest AIC. AIC can compare non-nested models (e.g., Weibull vs log-logistic) where LRT is not applicable.

Short Answer 5
Compare and contrast the Weibull, log-logistic, and log-normal distributions as parametric survival models. In particular, discuss: (a) the shape of their hazard functions; (b) their equivalent representations; (c) their empirical graphical checks; (d) the situations in which each is most appropriate.
Model Answer:

(a) Hazard shapes:
Weibull: monotone — decreasing (ρ<1), constant (ρ=1), or increasing (ρ>1). Cannot model non-monotone hazards.
Log-logistic: hump-shaped when κ>1 (rises then falls), monotone decreasing when κ≤1. Can model acute illnesses where risk peaks then declines.
Log-normal: always hump-shaped (rises then declines toward 0). Similar to log-logistic but mathematically less tractable.

(b) Equivalent representations:
Weibull = AFT + Cox PH (unique! — only distribution satisfying both)
Log-logistic = AFT + Proportional Odds (NOT a PH model)
Log-normal = AFT only (no special multiplicative structure beyond AFT)

(c) Graphical checks (linearisation of KM estimate):
Weibull: log(−logŜ(t)) vs log(t) → linear (slope = ρ)
Exponential: log(Ŝ(t)) vs t → linear (slope = −λ)
Log-logistic: log(Ŝ(t)⁻¹−1) vs log(t) → linear
Log-normal: Φ⁻¹(1−Ŝ(t)) vs log(t) → linear

(d) When to use each:
Weibull: Monotone hazards; when PH model comparison is desired; engineering reliability (wear-out, early failure).
Log-logistic: Non-monotone (hump-shaped) hazards; when PO model is preferred over PH; acute medical conditions.
Log-normal: Similar to log-logistic but with heavier tail; less used due to intractable hazard. Useful when the log-survival time is approximately normally distributed.
